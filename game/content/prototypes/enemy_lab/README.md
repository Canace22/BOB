# 统一敌人试验场

当前覆盖食腐甲、栖污大甲、负壳守卫、膜上捕食者、缠巢鳗与泵庭执卫六类。独立Godot场景，不读写主线存档、不发奖励；角色复用已确认的CombatWhiteboxPlayer与共用战斗内核。素材仍含关键姿势样板，技术通过与用户手感/美术验收分别记录。

**当前泵庭执卫默认是无机关平地Boss技能场**，核心为三连水弹、追击水龙卷、水遁回刺及黄色压囊弱点。右侧撤离窄道和膜泵互动在“场地”菜单手动选择；后文较早泵庭方案保留为过程记录，当前规则以末尾的水术段为准。

## 启动

仓库根设置`GODOT`为Godot 4.7.2控制台程序，然后运行：

```powershell
node tools/godot.mjs run -- res://content/prototypes/enemy_lab/main.tscn
```

## 操作

玩家保持WASD移动、J普攻、K三段、按住I格挡、L冲刺、S+L或Z后跳、空格跳跃、Q/E技能页。60ms组合容错和200ms下一招预输入未改变。

| 控件 | 行为 |
| --- | --- |
| 敌人下拉 / F1 | 选择食腐甲、栖污大甲、负壳守卫、膜上捕食者；F1回到单怪以确认当前敌人 |
| 组合下拉 | 单怪、所选主敌加食腐甲、双食腐甲；双食腐甲时敌人下拉显示实际食腐甲并禁用 |
| 场地下拉 | 平地，或左侧宽处/右侧低顶窄槽。窄处无法跳过重体，需引到左侧 |
| 招式下拉 | 主敌自然选招，或固定其三招之一；混编的第二只保留自然选招 |
| 自动起手 | 关闭后停止新的自然攻击，当前已经承诺的招式正常结束 |
| Enter / 强制起手 | 主敌落地待机时执行一次选定招式；不强制取消当前动作 |
| R / 重置 | 同一配置开启新轮，销毁旧角色、敌人、弹体和反馈，清空控制与输入队列 |
| P / 暂停 | 冻结当前交战状态，不取消后跳或技能；下拉菜单打开时也暂时冻结，关闭后恢复之前状态 |
| . / 逐物理帧 | 已暂停时放行一个物理步，之后保持暂停 |
| F2 / 判定 | 切换角色与敌人的判定框；青色为受击范围，橙红色为起手预览/攻击范围 |
| F6 / 无敌 | 明示调试开关，默认关闭；开启后不能把结果作为难度验收 |
| 击杀对照 | 下一轮将结束方式覆盖为击杀，只用于对照，不改变任何主线角色结局 |

## 显示与首批规则

上方显示玩家动作进度、实际格挡窗口、后摇取消、后跳可用性、命中停顿、组合等待及预输入。下方逐敌人显示招式、阶段、攻击实例与段号、完整时间轴、朝向锁定、可受控状态、护架/玩家所在侧、实际命中与结束原因。二连包含第二次起手，不能把第一下结束读成整招收招。

食腐甲轻体可浮空/倒地；格挡其二连会打断后段，破绽中首次反击额外加2压退，累计6点结束并退开。栖污大甲与负壳守卫不能常规浮空，护架阶段抗普通僵直；翻压可被重击打断，收招可短暂控制。护架正面承受50%伤害，侧后正常伤害；基础1点攻击保留半点余量，不取整成同等收益。浮空重挑最多三次并递减，落地后重置。

自然AI按本招可达距离接近后起手，起手前段可追踪、末段与有效段锁向；不会读取玩家按键换招。默认结束分别为食腐甲退开、栖污大甲退开、负壳守卫失去战力但存活。结束后移除攻击与受击目标、释放实体阻挡；尸体/退败姿态仅是代理呈现。脱战返回不会生成任何奖励，完整复位以R为准。

本轮未实现缠巢鳗、泵庭执卫、封梁卫、老守护者、鳗拖行、正式新美术、主线场景/结算接入或3人难度比较。所有代理参数仍待实际试玩调整，完整清单与判据见[敌人设计稿](../../../../docs/敌人设计与白盒验证.md)。

## 格挡与辨识度调整（2026-11-19）

仅此试验场使用EnemyLabSkills；主线格挡参数未变。I经过原60ms组合等待后，以0.02s起手进入正面防御，点按有效至0.55s，按住可持续防御但消耗架势；松开退出并恢复架势。判定容许身体交叠18px，后方攻击仍会伤害玩家。起手后0.30s内为完美格挡，以独立时间计量，不因持续保持防御帧而永远完美。

对可格挡攻击，普通格挡/完美格挡都会中断当前敌人攻击、取消二连后段并产生收招破绽；完美格挡有更强退缩/停顿。成功时响声、潮环、敌人闪亮、头顶文字和上方反击计时共同提示。成功可立即接J或基础剑技；1.4s内第一次实际命中的目标额外+1/+2且绕过护架，命中一次消费，超时清除。食腐甲既有破绽压退+2仍保留。格挡不提供背面防御、无限空中保护或无条件取消攻击前摇。

三套图集分为扁身横钳/厚背污絮/高螺壳，行走及各招按实际阶段选自己的帧，制作源见[样板记录](../../../../assets/source/enemy-lab-readability-v1/README.md)。4关键帧可以验证招式姿势，不代表已补全流畅动画、专用受击和退场动作。

专项：`--script res://tests/enemy_lab_readability_qa.gd --quit-after 1600`。阶段截图用明确的取帧夹具；长按I挡重体和接J反击走真实按键/自然攻击时间。

## 防御架势与招式特效（2026-11-19）

右上显示防御架势，满值100。持续防御超过0.30s后每秒消耗18；普通挡击另消耗28，大甲推进42、守卫壳推45。耗尽会破防、清除反击奖励并硬直0.65s，1.1s内不能再次格挡；导致破防的那次攻击照常造成伤害。空按维持到耗尽本身只造成硬直，不直接扣血。架势低于25不能起手；松开I且停止防御后，等待0.8s及破防锁结束，以30/s恢复。一直按住I不会在破防后自动恢复。完美格挡不支付挡击消耗并回补12，原迎击和反击窗口保留。

大甲翻压起手期间身体冒红光，不显示地面预警或头顶提示文字，完美格挡也不能挡，需后跳/跳离/走出实际攻击范围；原末段重击打断窗口仍有效。未给其他攻击暗藏不可挡属性。

九招加入真实阶段驱动的程序特效：针钳出手、冲撞拖尾、翻压落地冲击与碎屑，素材复用已入库strike1、dash_slash、ground-ring及projectile位图，不新增角色几何替代物。每敌固定24个特效槽，阶段进入有效段时发出；从已有图集接触帧播放，不重播空白蓄势。暂停、局部停顿、重置和退场均遵循所属试验场生命周期。特效无独立伤害，不额外增加攻击范围。

原生专项：`--max-fps 60 --fixed-fps 60 --script res://tests/enemy_lab_stance_qa.gd --quit-after 2000`，覆盖真实I被推进压破、松开恢复、红色翻压穿防以及实际阶段驱动特效。重置R恢复本轮满架势。

翻压前方宽度由170收至150，与默认贴身站位后跳的实际落点匹配；出招特效直接读取同一攻击范围，仍须在起手阶段及时后跳。

2026-11-19 预警表现收简：删除低扫弧光及所有前摇地环、头顶“不可格挡”提示文字。仅不可格挡招式在敌人位图上叠加红光和轻微边缘亮光，进入有效段、收招、受控、退场立即清除；普通攻击只用各自准备/蓄势动作预警。出手后的冲撞拖尾、翻压落地冲击和原受击/格挡反馈保留。此红光Shader局限试验场，与现有受击闪白共存，不修改主线材质。

## 膜上捕食者

敌人下拉第4项或F1轮换。选中时自动使用“挂膜/遮蔽位”场地：右侧两处挂点、左侧顶盖。其余操作不变；也可用平地，低顶窄槽禁用以免挂点落入碰撞。主敌加食腐甲仍可混编；双食腐甲保持原规则。

自然循环为挂膜待机→前摇锁定→飞行→真实落地→完整反击窗口→物理回挂。斜扑末.40s锁定落点，玩家之后移动不会被追踪；掠过先横穿高处，再实际落地，玩家不必追空中也可反击。重坠只在玩家靠近挂点下方时自然选择，前摇身体冒红光且不可挡；普通扑击可正面格挡。出招没有地圈/额外提示文字，重坠冲击只在实际落地时发出。

落地/回挂初段可短控和浮空；被打断后取消旧飞行路径，脱控落地后重新恢复，不接着飞向旧目标。头顶HUD新增“回挂”阶段与其进度。左侧顶盖下靠左区域是遮蔽位：提前进入会取消未承诺扑击，已承诺的路线不会追进去；遮蔽期间不重新起手。退出遮蔽回到开阔处会重新交战。不要把遮蔽后暂停进攻误认为卡死。

本轮失能采用存活清场，仅作独立白盒结果；正式物种、退场与第六章接入尚未确定，不写主线存档。四关键帧是动作样板，来源见[制作记录](../../../../assets/source/enemy-lab-predator-squid-jelly-v1/README.md)。原生专项：`--max-fps 60 --fixed-fps 60 --script res://tests/enemy_lab_predator_qa.gd --quit-after 5000`，明确区分站位夹具与真实A/D、J、I、F1和R输入。

2026-11-19 捕食者外观已改为用户确认的乌贼/水母融合：半透明伞膜、柔软吸附触腕、琥珀内光，四帧悬挂换握与三招各四关键姿势。旧虫状贴图不再被当前视觉器引用；仅更换图集/枢轴与待机播放，战斗和场地参数不变。制作源见[已确认形象](../../../../assets/source/enemy-lab-predator-squid-jelly-v1/README.md)，最终动作效果待试玩。

## 捕食者受压脱身与水弹

落地仍可短连招、浮空和打断回挂初段，但不再每次命中都无限重开机会。从首次受压起，累计3次可控窗口内的实际命中，或累计1.4s仍被受击/落地阶段留住，会收伞0.38s，然后向远离玩家的一侧喷水闪避0.36s，再物理回挂。这个时钟不因命中重置；回到挂点才重置下一轮。前摇和脱身/回挂期间只防重复控制，仍吃全额伤害，爆发可在离开前打败它；死亡优先，不加血、不瞬移、不反伤。

喷水侧移会在出手时发出1颗可见水弹。目标在收伞开始时记录，不追踪、不会连发；速度300/s、寿命1.8s，单发命中1伤害，22px位图呈现。可以正面格挡或跳开，前摇不冒红光；喷射身体本身没有碰撞攻击。水弹复用既有projectile.png，走原玩家伤害/格挡/架势逻辑，碰墙/到期/施放者战败/重置时消失，已发弹不会凭玩家走进顶盖下就瞬间回收。

HUD逐敌行追加受压次数/时间与水弹发出/命中/被挡计数；时间轴显示收伞脱身、喷水闪避、回挂。姿态复用已确认图集里的收伞与流线游动帧，附少量已有位图拖尾，不新增红光或地面预警。

专项：`--max-fps 60 --fixed-fps 60 --script res://tests/enemy_lab_escape_qa.gd --quit-after 5000`。明确落地站位夹具后，用实际J连打复现压制与脱身，另以实际I/空格验证防守和跳避。

## 缠巢鳗：头尾双端样板

敌人下拉第5项或F1轮换进入，保留前四种敌人。自然选招与固定招式菜单按实际招数生成；原基础两招仍保留，新增潜地突击与吐卵围猎见下。

- 颚部扑咬：0.80s收成S弯张颚，向头朝向短扑0.25s，再收招0.95s。可正面格挡、后跳或离开头端，挡住后可立即反击。
- 回身扫尾：在尾端停留0.35s后选择，0.75s卷尾蓄势、0.25s低扫、1.0s落尾恢复。可挡、跳过或离开尾端；挡尾不将远端头部拖过来。

头尾身份和朝向不随玩家换边瞬间交换；可缓慢正/倒向爬动调整距离，两端不会同时有效。普通攻击仅用动作前摇，不冒红光、不画地圈或低扫弧光。身体本身无持续接触伤害，单次攻击仅结算一次。

长体是一份生命、一个可命中目标，不按身体长度或节数重复扣血，也不整条浮空。收招可短控，反击预算跨hurt持续消耗，连打不重置；预算结束后仍吃伤害，但不能继续普通僵直锁死。HUD显示攻击端和反击预算。实际死亡清场，居民救援/搬巢与拖行均未接入。

形象参考已有blind-eel的软皮牙颚，独立制作12关键姿势（游动、扑咬、扫尾各4），当前为动作样板，尚待用户认可，不称为高帧完整动画。制作与枢轴见[来源](../../../../assets/source/enemy-lab-eel-v1/README.md)。原生专项：`--max-fps 60 --fixed-fps 60 --script res://tests/enemy_lab_eel_qa.gd --quit-after 5000`；单招站位为明确夹具，自然选招另行验证。



## 缠巢强化：潜地突击与吐卵围猎

用户指出头咬/尾扫缺乏缠巢识别，当前核心改为布卵限制落点、潜地换侧围猎。菜单可固定4招，原头咬/扫尾保留作近身辅助。普通攻击仍以动作预警，不加低扫弧光/地圈/头顶文字或普通攻击红光。

**潜地突击**：0.75s低头钻地预备、0.32s入地、土脊沿实际连续路线潜行（速度约720/s，最少0.45s）、0.65s露头张颚，再短扑0.28s，收招1.25s。入地时锁定玩家位置，优先绕到另一侧，边界不够则选择可容纳整条身体的一侧。地下可看见移动土脊，不是瞬移，也不继续跟踪玩家；钻地/潜行期间暂不可命中，露头后恢复受击。出土蓄势无伤害，可走开、后跳、跳避或面向露头位置格挡反击。与玩家重叠时延迟恢复实体阻挡，避免挤墙或卡住。

**吐卵围猎**：鼓喉0.90s，0.65s内连续吐3枚卵囊，目标在鼓喉开始时锁定，三个落点间隔85px。播卵本身没有身体/触碰伤害；0.55s可见爬近衔接后，分别蓄势0.50s、0.42s接两次0.24s扑咬。格挡住任一扑咬会提前进入收招1.30s，取消未发生的后续咬击；卵囊仍需应对，不被格挡远程魔法清除。
