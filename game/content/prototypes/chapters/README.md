# 第四至十二章 · 连续章节白盒

本入口用于集中验收剩余章节，默认从第四章脂库开始。第三章完成后按F也可进入；随后每章到标记出口按F结束，再按一次F继续下一章。第十二章在恢复期后终止，不循环生成敌人。

```powershell
$env:GODOT='F:/Godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe'
node tools/godot.mjs run -- res://content/prototypes/chapters/main.tscn
```

## 操作与进度

WASD移动、空格跳跃，J/I/K/L/Z及Q/E组合沿用已确认的玩家与格挡/架势。F执行附近标记操作；首次范围对白自动出现，F/空格/Enter推进，Esc跳过当前对白。观察段F开始，再F可跳过到同一完成态。可选查看不会冻结怪物。

- R：回到当前阶段检查点，保留已经完成的任务；死亡重试同键。
- F6：只清当前章节，其他章节与正式主线存档不变。
- F7/F8：上一章/下一章验收跳转；只切场景，不伪造前章完成，也不发技能或奖励。
- Esc：暂停；恢复等待所有游戏键松开，避免带入移动。

独立存档 `user://chapters-whitebox/<工作区摘要>-<后缀>-chXX.json`，每章各自保存任务与阶段；不读写正式V6、第一章或第二/三章进度。独立跳入后续章节采用该章既定开场背景，不能当作前章实际通过证据。

## 制作与验收边界

场地已增加独立的[地编参照层](../../../../assets/source/chapter-reference-v1/README.md)：默认显示复用的背景、骨路、支架、住巢、机关与两件新道具候选，可选侧台带单向碰撞。`--no-reference`可关闭参照，恢复原几何调试。它只读任务状态，不拥有剧情或存档；角色、对白触发和章节结果继续由原运行器控制。居民仍有明确标注的白盒代理；老守护者战后身体仅作位移演示，不冒充完整救援动作。正式19房与默认主入口保持原样，正式环境、真人情绪、难度和章节长度仍须验收。

章节敌人显式启用挑战配置：更快的追击、较短的起手间隔和有限连段；末段保留收招，完美格挡和黄色背侧弱点仍能中断后续。玩家伤害、输入与格挡沿用现有实现，原敌人试验场默认参数不变。自动采样只证明实际按键下的行为，不替代真人难度评价。

程序测试分开记录：真实输入全链、显式战斗完成夹具的战后接线、恢复夹具与原生截图。`--fixture-combat` 只检查空间和战后，不证明实战可过；真实路线不设置无敌、生命、位置或解锁。日志/截图只留 game/build/qa/，不入库。检验入口与结果见 game/progress.md。
