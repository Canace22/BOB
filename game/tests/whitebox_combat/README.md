## 启动

在仓库根执行（Godot 路径沿用 `tools/godot.mjs` 的 `GODOT` 配置）：

```powershell
node tools/godot.mjs run -- --windowed --resolution 1280x720 res://tests/whitebox_combat/main.tscn
```

可在 Godot 中打开本目录 `main.tscn` 按 F6。默认入口仍是正式主线；本场景不调用主线宿主，不导入旧档、不读写主线进度。运行日志与快照写在 `game/build/qa/combat-whitebox/`，不提交。默认显示已有逐帧位图，F2切换碰撞与状态调试几何层；当前仍为独立白盒表现。

## 操作与规则

| 按键 | 作用 |
| --- | --- |
| A / D、空格 | 移动、跳跃 |
| J | 现有普攻及二击衔接；本轮未重做连招树 |
| Shift | 开局可用的基础无敌冲刺；白盒不受主线解锁门限制 |
| B | 时机格挡；成功后白盒敌人硬直0.65秒 |
| Z | 后跳，保持面向，朝反方向跃退 |
| Y | 启动现有回旋斩，专测多段技能取消 |
| Enter / F | 敌人单次攻击 / 开关自动攻击；默认自动关闭 |
| 1 / 2 | 低扫 / 长刺 |
| H | 开关敌人起手霸体，比较打断与换血 |
| C | 开关后跳，做同场景对照 |
| R | 重置生命、位置、冷却和敌人；保留模式开关 |
| F3 / F8 | 切换0.15倍慢动作 / 保存当前画面到本地 `native.png` |

后跳复用 `TidePlayer` 的真实输入、受伤和攻击接口，独占退步阶段的运动，取消技能控制器、清空攻击排队与蓄力记录。已扣资源和已开始冷却不返还，已发射弹体继续存在，尚未发生的攻击和多段脉冲停止。后跳自身不增加无敌；空中、受击、死亡、调息和交互期间拒绝发动，后跳不能取消自身。退步速度420px/s、上抛260px/s、重力1750px/s²，落地后0.12秒再用，均为待调白盒参数。

敌人低扫前摇0.7秒、攻击0.2秒、收招1.1秒，攻击阶段第0.06秒采样判定；长刺扩大距离与高度，可以追到后跳。起手黄色、攻击红色、收招/被打断绿色。它复用玩家攻击接口与伤害入口，但敌人自身是可控测试靶，不等于正式尸蟹或Boss已具备相同反馈。固定全场视角用于观察判定，不替代正式居中镜头与复杂地形3C验收。

### 2026-11-16 · 冲刺与格挡后摇取消

用户认可后跳手感，保留其运动参数和强制取消规则。冲刺与格挡改为普通攻击完成有效段、单段技能释放、多段技能最后一段释放后即可接入，不再等旧65%进度门槛；前摇、剩余多段、受击和交互不开放强制取消，仍由后跳承担中途撤招。冷却先检查，通过后才清理原动作与攻击排队，已付资源/冷却保留。UI将B统一标为时机格挡。

本轮11项白盒专项通过，0失败，证据 `game/build/combat-whitebox-recovery.log`；新增真实Input动作验证普攻后摇接格挡、技能后摇接冲刺，以及冷却拒绝不吞原动作、多段末击后开放、不能逃受击。命中定格会暂停角色计时，测多段后摇必须等待最后一段实际发生，不能只按墙钟推算。工程check/test仍单独记录已有章节错误，不据此宣称整体通过。

本轮完整test统计133项通过、0断言失败，但chapter01依赖错误仍在；check仍报相同2处缺图。原生已打开标题 `BOB Whitebox - Recovery Cancel` 的新版，J/B按键入口可用；窗口工具捕获延迟使本轮原生格挡发生在动作结束后，提前取消窗口的证据来自上述Input专项，不把这段原生操作当作提前取消成功。交付时恢复正常速度并重置。

先由用户判断后跳距离、响应、取消自由度和偏转收益，再决定正式接入；不直接扩大为三段普攻、新技能树或正式敌人批量改造。双键码兼容、取消后清理未释放事件，以及“短攻可退、长攻需换应对”的对照是本轮可复用方法；当前白盒参数不直接作为主线定值。
