当前触发方式见[方向派生与组合键](CONTROLS.md)：W+J直接上挑、地面S+J直接横扫；三段A/D+K逐次出招换向，撞击A/D+L，空格专职跳跃，连斩E+J。移动技不需占用Q/E；点按Q/E再选招也兼容。下文3–7是技能设计阶段的历史编号，已不再作为战斗快捷键；机制参数继续沿用。

最新反馈：4的续段窗口从0.65秒延长到每次发动后1.10秒，出手速度不变。21项专项通过（`build/combat-whitebox-chain-window-tests.log`），新增0.83秒停顿仍接第二段、1.25秒停顿结束续段的回归。原三段上限、换向、防御取消关闭续段与首次冷却规则保留。新版窗口标题 `BOB Whitebox - Chain Window 1.1s`。

2026-11-16，`codex/combat-whitebox-backstep`。用户已认可基础操作，本批进入连招验证。定位仍为技能成长与剧情章节驱动，不引入刷装循环。当前仅白盒能力，全数开放用于试验，不代表正式解锁安排或动作美术完成。

## 为什么选剑魂

参考DNF剑魂（国际服名Blade Master）近战技法的用途：起手、移动追击、范围收尾、突进挑起、持续连斩与后跳回斩。官方历史资料可核对[后跳斩、连携、拔刀与破军等技能](https://www.dfoneople.com/news/updates/221/Character-Balance-Update/Male-Slayer/Blade-Master)以及[招式形态](https://www.dfoneople.com/news/updates/1486/Character-Balance-Patch/Slayer%28M%29/Blade-Master)。这些页面用于取证技能职责，不作为当前版本数值标准。

选择原因是可复用现有近战命中、移动、取消和输入能力，快速验证连招；当前不需要武器切换、装备精通或觉醒大招。以下为拾潮者自己的名称、参数和简化动作规则，并非DNF数值复刻。

全部消耗为0，用冷却和出招承诺区分用途；具体资源和成长安排不在本批锁定。技能释放前不允许接其它攻击跳过承诺，单段释放后、多段最后一击后可接下个技法或冲刺/格挡；Z后跳保留强制中断能力。取消保留冷却、清理排队输入，不补发攻击。已有基础攻击和原技能仍可用，没有强制改成三段普攻。

普通目标增加浮空、倒地和短硬直。起手霸体在攻击前摇/有效段抵抗挑空和击倒，保持防御选择价值。连续补挑最多三次、速度逐次递减，落地重置；实际命中集合决定控制对象，不能对范围外目标施加浮空。连击数统计接触次数，不把伤害3记成3连击。

## 试玩路线

1. `3 → 4 → 5`：上挑、单段追击、横扫收尾。`4 → 4 → 4` 为独立的逐次操作练习，可在每次按4时用A/D换向；并不保证穿过目标后继续同向的每段都能命中。每招释放完再按下一招；本批没有新增技能预输入队列。
2. `6 → 7 → Z`：突进起手、站桩连斩，再用后跳中断或撤离；也可在末击后用Shift/B取消后摇。
3. `Z → J`：退出近身时回斩一次，不改变已认可的后跳轨迹。
4. `8`切换三目标，练习横扫覆盖；`9`将主靶恢复为60血，便于长链练习；`R`完整重置并移除额外目标。

HUD显示技能冷却与COMBO计数。所有矩形和颜色均是白盒判定可视化，不是正式动作资产。正式接入仍需匹配攻击发力帧、受击表现及角色素材，再做关卡和镜头验收。

## 验证

独立命令与场景沿用[白盒说明](README.md)。初版7项连招专项加原11项攻防回归，共18项通过、0失败，证据 `game/build/combat-whitebox-sword-tests.log`。初版覆盖：

- 上挑真实浮空、三连位移与三次命中、横扫收尾，完整链至少7点伤害/5次接触。
- 后跳斩一次命中且退距保持，释放按键不补发旧攻击。
- 五段连斩全部命中，最后一击后才能接格挡，冷却保留。
- 突进实际接近并挑起；霸体前摇抵抗控制；群体命中不影响范围外目标。
- 真实技能输入、后跳取消无延迟命中、浮空三次上限与落地恢复。

初版上挑借用了现有正上方矩形，未覆盖面前100px的测试靶；实测后改成前方扫入再挑起，完整连招才成立。这个修复说明技能名称相似不能代替实际范围和衔接验证。

工程check和完整test另跑并保留日志，不以专项结果替代；已有chapter01旧idle/gate缺图仍单列。用户连招手感、常速连续挑战及正式素材呈现待验。

本批完整test统计140项通过、0断言失败，但旧章节脚本错误仍使整体验证不通过；check仍为同样2处缺图错误。原生GPU界面、数字3实际释放/命中/挑空已核对（`build/combat-whitebox-sword-native.log`），数字技能也覆盖逻辑键事件兼容。完整实时连招的手感仍待用户试玩；专项输入与直接请求验证不冒充原生整套连招通过。

## 同日反馈：技能4/6、5/7缺少区别

用户认为两组技能体验相似。修正为4的逐按/换向/最多三段，6的单次近身停步高挑空；5前后范围击退清场，7原地前方持续压制。分别增加手动三段和双侧推开/原地锁定测试，现20项通过、0失败，日志 `build/combat-whitebox-distinct-tests.log`。旧“完整链7伤害5接触”对应自动三连初版；当前简链只按一次4，验证5伤害3接触，另测三次按键，避免测试继续认可被否定的旧行为。防御或后跳取消会关闭4的续段窗口，不能绕过冷却偷第四段。白盒分别用矩形、圆环、厚撞击条和五道斩线区分技能表现，不代表正式美术已完成。

差异版完整test统计143项通过、0断言失败，仍有旧chapter01编译/依赖错误；check仍报同样2处缺图。原生差异版已启动，标题 `BOB Whitebox - Distinct Skills`，启动日志无脚本错误。但实机复核时桌面已锁定，停止UI操作，未宣称新四招已通过原生手感验收；解锁后继续。旧 `Sword Combo` 窗口关闭未成功，复测应认准新标题，不在锁屏下继续操作。
