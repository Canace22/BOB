## 2026-10-28 · 首屏加载优化

用户反馈首屏在引擎加载条停留较久。优化前使用独立 Chrome 上下文实测：冷启动 50.3 秒，同上下文刷新 45.6 秒；Resource Timing 显示引擎已有 HTTP gzip（39.5 MB 解码体积，实际约 10.25 MB），资源包实际仍约 30.1 MB。不能用 HEAD 的未编码大小当作浏览器传输量。

### 改动

- 将全量中文运行字体换为工程文本生成的静态子集：运行导入从约 13.3 MB 降至约 70 KB 源字体，保留完整原字体与 OFL；新增实际字形覆盖测试。
- 15 张场景位图仅改 Godot `.import` 为有损 WebP 质量 0.8，像素尺寸、裁片和碰撞不变，原图不改。查看实机截图确认接地、透明边缘和文字。
- Web 资源包从 30,245,912 降到 5,179,148 字节。导出后自动生成并往返解压校验两个带内容哈希的 gzip 文件，实际启动下载合计 15,202,253 字节（14.50 MiB）。
- 加载器以浏览器原生流式解压接到现有引擎流式编译；用独立 CacheStorage 缓存启动文件并清理过期哈希，只涉及静态资源。加载页显示压缩下载量与“正在启动”阶段。原始文件供没有解压 API 的浏览器回退；缓存不可用仍能通过网络启动。
