# 场景与环境动态制作 · 项目入口

先读取已安装的个人通用 `scene-environment-motion` 主源（以当前技能目录为准，不使用另一台机器的绝对路径）。如果本机没有完整主源，使用仓库内的[项目执行流程](PROJECT-WORKFLOW.md)、[配方库](references/motion-recipes.md)和[执行合同](references/production-contract.md)。

项目执行流程恢复自提交 `b5341956` 中本 Skill 的完整版本，2026-11-04 恢复；配方和合同沿用仓库现有文件。这是可移植的项目后备流程，**不是已找回或同步了个人通用主源**。后续定位个人主源时先比较版本，保留本项目已验证经验，避免维护互相冲突的双主源。

- 场景制作/还原/优化、环境动态或单个环境元素默认使用，不要求用户再次点名。主动识别static/motion/inspect、说明选型，先单件样板再扩展和接入。
- 正式开发位置以根AGENTS和[Godot开发Skill](../godot-game-dev/SKILL.md)为准；已冻结的legacy只作定向参考，不能继续开发历史入口。
- 每批将成功原因、母版/脚本、证据和失败修正写回对应通用配方，项目细参数留在本项目；新迁移未经样板不标validated。
- 结合[素材一致性](../consistent-2d-game-assets/SKILL.md)检查外观；不固定模型/引擎/FPS，不扩展本次范围。只维护Skill时不生成资产。
- 通用主源不可用时查实际安装位置并说明缺口，不声称已加载；本机已查目录未命中时不反复搜索整盘，采用上述有来源的项目后备流程。历史配方的证据仍只证明原案例，新章实例必须重新验收。
