# 从动画或视频取得动作参考

本流程产出姿势、相位和节奏依据。目标角色仍需绘制连续帧；参考素材的分辨率、人物外貌、镜头透视和背景不自动适合游戏。

## 选择与记录来源

优先使用项目已获准使用的连续帧、明确授权动画库或用户有权使用的视频。记录来源页、作者、许可与署名要求、动画名称或视频时间段。公开可观看不等于获准提取并复用；来源仅能作动作观察时，交付中不附原视频或原角色素材。

选视角接近目标游戏、身体清楚、遮挡少、相机稳定的一段动作。发现动作不完整、肢体长期被挡或透视变化太大，换参考比强行补全更可靠。

## 从 3D 动画取得 2D 相位

授权骨骼动画可以通过 Blender 等工具渲染成 2D 姿势参考，不要求目标游戏使用 3D。记录实际动画 clip、相位时间、相机方向与投影；使用固定相机、共享尺度和地面，保留承重变化。

先查看动作是否带根运动。制作原地循环时，可移除整体向前的根位移，但保留骨盆升降、转移重心和身体倾斜。不得逐帧自动居中/缩放，把动作本身归一化掉。

不要只按 clip 总时长均分：先找关键事件，再取相位。走路观察左右脚的接触、下沉、经过、上升；落地观察落前准备、首次接触、缓冲、最低点、回弹与恢复。事件用于检验动作逻辑，不规定最终帧数。相位正确后，依速度变化和目标风格细分时间采样；绘制帧数与播放时长分别确定，不把几个关键姿势机械等时轮播。clip 若缺少某段，应说明缺口或另取参考，不编造它已有完整动作。

例如使用 `Walk_Loop`、`Jump_Land` 时，必须查实际文件和曲线确认名称、时长与可用相位；名称和“CC0”文字本身不构成文件或许可验证。允许复用相位板，不据此声称目标角色已补帧成功。

## 从视频取得关键帧

确认目标时间段，保留源帧时间戳。FFmpeg 等工具可导出候选帧；先粗看动作，再选接触、极值、方向改变和恢复等关键时刻。等间隔抽帧只用于浏览，不保证动作相位正确。记录实际源帧编号和 PTS；目标时刻落在两帧之间时，说明取帧偏差，不能把请求时间当实际采样时间。视频播放帧率、不同姿势数和角色序列的持帧时间是三件事。

视频包含多个动作时，先抽查首帧与动作切换点，确认视频 PTS 如何对应动作局部时间。总帧数多一帧不能证明开头有预热帧；可变帧率素材按实际 PTS 计算，不直接用帧号除以名义帧率。画面上取整后的时间文字、请求时间、解码 PTS，以及经验证录制计划推导的动作时间应分开记录。

相机平移、推近、剪切与遮挡会伪装成角色运动。必要时统一参考的相机位移，但不要抹掉真实身体升降。完整轮廓不可见时，标为不可靠参考；视频插帧也不能凭空保证被挡肢体正确。

抽出的帧只作动作依据。视频人物重绘为目标角色时，要重新核对目标比例、手脚数量、装饰和挂点；不能贴上角色头部或整图拉伸便称作角色动画。

## 将参考变成可绘制说明

为每个相位写：时间/顺序、哪只脚接触、重心位置、手臂与道具姿态、下一帧变化。明确解剖左右，不只写“画面左腿”；肢体交叉时尤其容易互换。

把角色主图和相位板一同提供给绘制工具，注明角色主图控制身份，参考板只控制动作。保留同一画布、缩放、根部和地面约定。生成后逐相位对照，再以实际速度播放；帧数相等不代表相位已经复现。

来源记录应能区分：原角色美术来源、动作参考来源、这次生成或绘制方式、抽帧/拆图工具与参数。只记录实际用过的资料及验证结果。
