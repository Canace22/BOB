# BOB 拾潮者试验：能复用的方法与限制

这是一次已有位图角色的动作试验，不是正式游戏接入案例。主参考为 BOB 拾潮者原图：单圆镜、左胯灯、右手双叉工具；这些是该角色的身份约束。

## 实际流程

使用 Quaternius Universal Animation Library 的 CC0 `Walk_Loop` 与 `Jump_Land`。通过固定侧面相机渲染原始骨骼动作的相位，再以原角色图控制身份、相位板控制动作，参考重绘 2D 连续帧。另从录制的 MP4 真实解码抽帧，记录源帧、PTS 和取样偏差。

落地先做 6 个关键姿势，再尝试 12 个含过渡的非等间隔姿势，补充快速下压和恢复过程。12 是本段动作的试验选择，不能作为其他动作的模板；增加帧数也不自动保证质量提高。

生成器未严格遵守等格排布。保留原图，用显式裁框和裁片内锚点放回共同坐标，整段共用像素尺度。裁片内的锚点数值可因裁框位置不同而不同，不应逐帧按 bbox 缩放或把蹲姿重新居中。

## 验收结论

- 落地的下压、缓冲、恢复可读，角色挂点基本保持；脚掌间距、头盔体积和披风细节仍有变化，只能标为候选。
- 行走的后半段近似重复同一半步，腿部身份没有清晰交替。不同图片、正确帧数与循环播放成功，都不能替代步态验收。
- 非等时长、末帧停止、重播倍速、暂停逐帧和单一时钟通过了真实素材检查；尚未验证正式游戏的落地事件、待机衔接或移动脚滑。
- 深浅背景和游戏尺寸要直接看合成结果。查看工具显示的透明区底色不能证明 PNG 不透明；实际检查 alpha 与合成后的边缘。

视频时间校验发现参考片没有起始预热偏移。30 fps 下三个目标动作时刻 0.04 / 0.19 / 0.65 秒，实际取得约 0.0333 / 0.2000 / 0.6667 秒；这些偏差被保留，而没有改写成目标时刻。
