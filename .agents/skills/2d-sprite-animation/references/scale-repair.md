# 角色尺度修正经验

当角色在固定镜头下忽大忽小、身体忽宽忽窄时使用。以用户指出的具体部位为验收对象，不用画布尺寸、整个轮廓面积或工具成功导出来替代。

## 先定位，再选择修法

1. 在同一显示倍率下比较来源帧、平台处理帧和导出帧，排除自动适配预览造成的假变化。先确定认可的参考姿势及关键比例，再检查过渡帧；不能只对齐首尾。
2. 按角色结构与动作选择至少两组可比较的稳定标记：人形可看头身比例、躯干宽度和肢段长度；动物可看头部、躯干及关节间距；机械角色可看刚性部件尺寸与连接点。只使用当前姿态下可比较的部位，排除摆动附件、武器、披风和遮挡区域。转身和透视变化需按相近姿态判断；软体或刻意挤压拉伸的角色应核对设计规定的变形范围，不强行锁死宽度。
3. 简单的整角色同比例变化可按稳定部位估计比例修正；局部膨胀或结构变化要修绘/编辑问题部位。需要图像编辑时按可用图像工具的规则执行，不为这个特例写一套通用重绘系统。

用局部模板匹配或特征点加稳健拟合辅助测量时，记录参考区域、匹配质量和可疑帧。宽度问题应检查横向尺度，不能只报包含纵向变化的平均缩放。至少用另一组标记或叠图交叉检查；匹配点不足、集中在小区域或发生遮挡时，标为不可靠，不据此自动变形整帧。不同版本的局部特征可能因重绘而改变，因此百分比是估计，不能宣传为精确的角色物理尺寸误差。

## 编辑与整理时保护什么

- 提示明确写“参考指定基准姿势的关键比例与结构标记（填写本角色实际使用的部位）；保留每帧动作相位、结构连接、画风、透明背景和持帧节奏”。只要求“角色大小一致”不够具体。先修问题帧，整图集编辑只在需要跨帧共同约束且分辨率足够时采用。
- 校准前后的画布与构图约定保持一致。允许真实的下沉、回弹和透视缩短；不能为了静态叠图完全重合而抹掉动作。按选定的稳定部位或结构标记估计注册位移，再保留原时间线的身体起伏；不要按每帧最底像素重新贴地。
- **生成图集的格子位置也会漂移**：确认实际行列、每格裁切范围、相邻帧是否串入和最大姿势是否裁切，再做注册。等格布局已确认但像素不能整除时，可用累计比例边界取整；未确认布局时不能平均切格。图集第三行向上错位之类的排版误差不应进入动画。
- 整段统一调整到目标尺度，逐帧只执行有证据支持的注册或修正。记录裁切框、缩放、偏移和顺序；保留生成原图与原始动画。最终 PNG/图集还要重新检查，防止图像库的裁切、合成执行顺序造成额外位移。
- 请求的分辨率不等于实际输出。检查真实图集及每格像素；放大输出不能恢复细节。多轮整图集重绘可能让纹理变柔、肢体形状或动作幅度改变：检查失败时优先回到原高分辨率问题帧修正，不把锐化或超分当作保真恢复。

## 验收与交付

原版和修正版使用同一画布尺度、同一时间轴同步播放。以完整动作为单位观察正常速度，再慢放和逐帧定位；循环检查接缝，单次检查停止和重播。对比工具缺失时补充最小页面即可，不替代 Framecraft 的工程和导出流程。

五个检查场景：

1. 抬臂、展翼或伸展改变轮廓范围，稳定部位的比例仍应合理；不能因外接框变化误缩角色。
2. 攻击、移动或恢复中的非预期比例变化减少，同时保留设计中的承重、起伏和接触关系。
3. 图集跨行后没有额外横跳、上跳、邻帧残片或裁切。
4. 修正版保留原帧序、持帧与总时长；导出、保存后重开仍一致。
5. 尺度更稳定但纹理、清晰度或肢体变差时，明确标为有代价的候选；用户只认可改善时，保留该候选作下一轮尺度参照，不直接替换正式素材。

## 巨蟹实测：2026-11-02

“双钳重砸”原版的画布和透明通道检查通过，但身体宽度仍明显变化。壳体特征的横向尺度估计最大约 +10.3%。两轮内置 image_gen 编辑后，按固定壳体标记注册、保留原 bodyY，估计范围改善到 −2.3%～+2.6%；用户反馈“好多啦”。这些数值仅描述该样例，不作为所有角色的统一合格阈值。

保留 39 个播放帧、24 FPS、1.625 秒。画布边缘无非透明像素，平台 PNG 导出与输入字节相同，工程重开恢复 24 FPS 和单次播放。该样例的末尾待机复用首帧；这是其单次时间线安排，不是所有循环动画都应增加重复首帧。

代价：实际生成图集是 1619×971，单格约 324×324，再统一输出为 512×512；不能称作原 1088×1088 素材的无损修复。纹理变柔，部分肢体与动作幅度改变。后续应以用户认可的尺度为约束，优先恢复原图细节并检查钳子、落脚连续性。

原始产物保存在外部试验目录 `巨蟹双钳重砸_尺度修正版/`，未随本 Skill 入库。复验时先定位 `打开对比.html`、`身体宽度测量.json`、`检查结果.json`、`修正说明.txt` 和 `.framecraft` 工程；这些历史结论不代表当前游戏接入已通过。
