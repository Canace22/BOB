# 连续世界地图概念设计

适用于用户要求根据现有设计与工程，衍生互联地图和连接原画；本分支交付设计，不自动扩大为引擎开发。

1. 分开读取工程真实房间/门点与设计房间/拓扑。标明已接入、章末占位、远侧闩和未制作区域；区域编号不是行走顺序。
2. 将原房ID、边ID、能力门、完成旗标、首次开闩侧作为结构合同。每条边补经过部位、跨屏共同地标、台面衔接与材质渐变。
3. 同时交付整体空间原画、重点区域连续剖面、两侧门边接缝、关键跨区过渡。大图表达连续空间，机器可读门表承担精确连通；AI绘画中的洞和路径不能自行变成新边。
4. 图册在原图上叠加可编辑部位注记；拓扑图另标“非比例、不代表器官位置”。头尾远距用原边内的长过渡表达，不能用版面邻近伪造解剖邻接。
5. 保存英文提示词、原参考角色、输入快照和哈希、原图尺寸、未定稿细节及工程接续指令。浏览器检查图片实载、节点/边数量、连接点击、门槛文本和窄屏。
6. 概念图通过只能证明概念交付与图册可用；共享远景、半屏补底、过门遮镜等接入方法仍需引擎样板，未实测不写成动态成功配方。

本项目已执行实例：`assets/source/world-continuity-v1/`，入口`docs/鲸腹遗城原画集/连续世界设计/原画册.html`。其6图、36房、39边的文件与交互核对不代表已经实现全世界无缝地图。

局部精修实例：`assets/source/xumen-keyart-v2/`。整区器官剖面、七房绘景、拓扑与工程像素分开展示；若生成图把能力门画成可走斜坡，先定向修正该形体，不能只靠提示文字抵消画面误导。真实使用过但后来修订的图仍应作为输入快照保留，避免后续图的参考链指向已变更文件。此批只验证概念交付，不构成分层或环境动态的成功配方。

专用接续实例：`assets/source/xumen-seam-keyart-v1/`。以相邻两房参考联合重绘，按离开/经过/抵达说明同一空间。阅读虚线也要视觉复核：不能穿过实体硬腭或暗示不存在的快捷边；修注记无需重新生成已合格位图。原碰撞坐标只作独立来源快照，不用概念比例推算新路线。

玩家仍看不懂地图时，增加一张默认可见的总布局图，而不是只补更多局部原画。可从工程原点、台面和门表生成技术SVG，主路/回访分色，器官比例另图保留；明确它是布局说明，不冒充正式场景美术。实例：`assets/source/xumen-overall-layout-v1/`，检查过房边数量、原画底图、真实点击、放大与手机图内滚动。

用户要求“总布局的实景样式”时，需另做单张联合绘制的环境全景，先以布局约束关系，再以局部认可原画约束材质、景深和光向；方框、彩线和截图拼接不能代替实景。将房/边注记留在可切换图层，默认显示无字画面；仍明确概念和实机的区别。实例：`assets/source/xumen-real-scene-v1/`，概念、局部返修和图册检查已记录，未作引擎接入。
