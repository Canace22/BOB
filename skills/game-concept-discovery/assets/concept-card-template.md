| 层 | 你的说法（原话 / 我的猜测） | 我提炼的术语 | 状态 |

| D 动态 | <他怎么描述玩家会怎么做> | <术语> | 有 / 缺 / 悬空 |
| A 美学 | <他怎么形容那个感觉> | <术语> | 有 / 缺 / 悬空 |

> 右边那列术语是给我串联用的，他不需要记。

**链条自检**

- [ ] 说得出 D：玩家为了做成这件事，会重复什么动作？
- [ ] 没有跳层：不是“加个按钮，玩家就会孤独”
- [ ] A 落得到场景：不是“要有沉浸感”
- [ ] 反过来也成立：删掉 M，D 还会发生吗？

**断在哪**：<断在中间 / 跳层 / 悬空 / 暂无>
