# 鲸落万物生 · V2 2D MVP

基于 `docs/鲸腹遗城原画集/V2/游戏设计说明.md` 与原画的独立 2D 横版探索原型。采用原生 Canvas 与 WebAudio，无运行时第三方依赖。展示名沿用 V2 的《鲸落万物生》；主角为拾潮者。

这是由鲸口门庭、胃库沼泽、肋骨游廊、肺缘浮庭串联而成的压缩试玩切片：共鸣开路 → 帮助生物 → 改变水流 → 攀网 / 升降 / 摆荡 → 获取浮膜 → 回访高台 → 返回营地。关卡连接和能力门槛为 MVP 重排，不代表原案 14 区域的完整解剖路线。

## 运行

公网试玩：[鲸落万物生](https://canace22.github.io/BOB/mvp-v2/)。GitHub Pages 仅发布当前 V2 版本，无需开发电脑保持开机。Pages 与本地地址各自保存浏览器进度，存档不会自动跨站点迁移。

在仓库根目录执行 `npm --prefix mvp run build:pages` 检查静态产物，执行 `npm --prefix mvp run deploy` 发布到 `gh-pages`。站点首页进入 V2，地图工作台位于 `mvp-v2/scene-lab.html`。线上更新后刷新页面使用新版；下文的自动更新提示属于本地快照服务。

推荐在 Windows 仓库根目录执行，需 Node.js 18 或更新版本；后台运行，不依赖聊天窗口：

```powershell
.\mvp-v2\launch-preview.ps1
```

也可用前台方式（关闭终端会停止此方式启动的服务）：

```sh
cd mvp-v2
npm run publish:preview
npm start
```

浏览器打开 [稳定试玩](http://127.0.0.1:4175/)。当前局域网地址是 [10.11.140.34:4175](http://10.11.140.34:4175/)，IP 可能随网络变化；其他人需处于可互通的内网，主机保持开机。服务仅提供发布的静态游戏文件。各浏览器的存档独立；127.0.0.1 与 IP 地址也属于不同站点存储。

## 边玩边做

- **4175 稳定试玩**：读取 `.preview/releases/` 中已完成快照，页面与资源固定在版本 URL；源码修改不会破坏正在进行的游戏。
- **4176 开发预览**：执行 `./dev.ps1` 或 `npm run dev`，实时读取源码。使用 `GAME_URL=http://127.0.0.1:4176/` 跑浏览器测试。
- 验证通过后执行 `npm run publish:preview`，完整快照准备好后才切换首页。已打开的游戏继续原版本，顶部提示「新版就绪 · 保存并更新」，由玩家选择更新。
- 标题页「直接体验攀爬设施」启动独立练习，不覆盖主线存档；旧 V2 存档可继续。
- 后台服务日志与 PID 位于 `.preview/`，源数据和运行检查说明见 [SCENE_PIPELINE.md](./SCENE_PIPELINE.md)。发布时会复制封面所需原画和独立场景素材，原画关卡图不进入游戏背景。

## 完整试玩路线

1. **鲸口门庭**：向右走，短鸣打开第一道鲸须；快速通过会下陷的舌面，拾取第一枚记忆。第二道鲸须需要长鸣。修复右侧菌席后，在出口按 F。
2. **胃库沼泽**：左侧拾取腐屑，靠近占道尸蟹投喂。再转动胃瓣排流，到低槽收集记忆；从低槽右缘跳上平台，休息并修复营养坡。胃瓣可反向操作，失误后可以再次排流。
3. **肋骨游廊**：沿菌丝网攀上启动台，按 F 开启浮囊。等升降台靠近后跳上，随台升高，再向右跃上骨台。骨环摆近时按 F 抓握；向右摆起后按空格借力跳出。抵达对岸检查点，沿台阶到终点拉杆，完成三项设施后打开肺缘通路。失误落到安全网，可按 F 返回已经激活的设施检查点。
4. **肺缘浮庭**：取得共生浮膜，在下层压力囊充压；按住 Shift 向右浮升，落到中层平台后再次充压。走到平台右缘，再浮升至高台，途中拾取记忆。修复浮膜巢，开启最右侧旧伤裂隙。
5. **能力回访**：经捷径返回鲸口上层，向左拾取初见时无法抵达的记忆，再返回起点的贝壳营地按 F，触发试玩结尾。结尾后可以继续回访与修复。

能力、机关、记忆和捷径会自动存入浏览器本地存储，刷新后可继续旅程；营地与房间入口决定恢复位置。跌落或触碰未排流的危险液面会返回安全点，保留收集与已开启通路。暂停菜单也能主动回到安全点。存档属于当前浏览器与站点，清除站点数据会删除它；旧版原型存档独立保留。

## 生态回访（2026-10-26 迭代）

三处栖息地现在经历「待修复 → 恢复中 → 已恢复」，修复后在实际探索中生长约 12 秒，也可以离开当前区域。打开地图、手记、暂停或结尾面板时停止生长；恢复进度随旅程保存，旧存档已完成的修复保持完成。

| 区域 | 修复前提 | 回访变化 |
| --- | --- | --- |
| 鲸口门庭 · 鲸须菌席 | 长鸣开启第二道鲸须 | 菌席逐渐舒展，食腐虾群循流归来 |
| 胃库沼泽 · 营养坡 | 转动胃瓣排流 | 骨礁双壳逐步附着，在水流中开合滤食 |
| 肺缘浮庭 · 浮膜巢 | 接纳共生浮膜 | 巢膜展开，浮膜幼体在周围漂游 |

HUD 显示已恢复数量与恢复中的地点；按 **M** 查看实际通路、当前位置、各区收集和修复状态，按 **J** 阅读生态记录。未探索区域只显示轮廓。结尾列出你留下的生命，栖息地属于可选修复，尚在生长也能完成旅程；之后可继续回访，全部修复与收集完成时目标会更新。

## 验证

```sh
npm run check
```

完整浏览器测试需运行本地服务器，并备有 **Node.js 20+、Playwright 及 Chromium / Chrome / Edge**。游戏本身不依赖 Playwright。测试优先使用已安装的 `playwright`，其次尝试 Codex 桌面内置包；也可把 `PLAYWRIGHT_MODULE` 指向包目录或 `index.mjs`。系统 Node 低于 20 时，脚本自动尝试 Codex 内置 Node。缺少 Playwright 浏览器时，在 Windows 自动尝试已安装的 Chrome / Edge；也可通过 `BROWSER_EXECUTABLE` 指定浏览器路径。测试使用独立临时配置，不读取日常浏览器资料。

```sh
npm test
```

`GAME_URL` 可指定其他试玩地址，默认 `http://127.0.0.1:4175/`。测试从空白浏览器存储开始，使用实际键盘事件与 `advanceTime()` 确定步进；`render_game_to_text()` 只读取状态，不通过测试接口传送角色或修改能力。

覆盖：6 项原生设施测试、9 项生态测试（前置机制、三态、重复交互、暂停、跨区成长、中途续档、旧存档及完成目标）与 3 项本地快照服务测试；浏览器用真实键盘走四区路线、全部记忆与栖息地、刷新续玩及结尾，并检查未探索地图与手记遮蔽、紧凑屏幕布局、恢复中刷新、面板暂停成长、结尾后继续修复、练习模式不覆盖存档，以及页面不请求原画关卡背景。截图与状态记录输出至 `output/playthrough/`；`result.json` 记录完整通过结果，失败时查看 `failure.png` 与 `failure-errors.json`。
