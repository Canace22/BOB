# 音频专项接续（2026-10-28）

输入：用户确认其他应用正常发声，游戏能发声但音色刺耳/重复、不自然。

实际流程：
1. 原配置启动audio_devices：WASAPI和Realtek设备已恢复；保留先前ERR_CANT_OPEN日志，不修改系统音频设置、不声称找到此前失败的确切根因。
2. 工程和既有EXE+PCK运行Master采集：非零/无削波，用户确认能听到；主观音质失败需返修。
3. 原WAV保存在assets/source/audio-v05-original。用work/refine_audio_v05.py生成11类×3变体及24秒低频滤波噪声底音，保存生成参数、峰值、RMS、SHA256。
4. Godot接入轮换、0.08/0.18秒同类限流、8总声部/3同类声部上限、事件分级音量；保持玩法、碰撞、路线、角色外观不变。
5. 测试variants/cooldown/budget/free/loop，WASAPI重新采集；播放间隔试听，收集用户听感。
6. 导出更新PCK，正常主路/独立重载回归；独立包WASAPI混音复验。更新覆盖表、交付册、状态与ZIP，不以程序混音pass代替用户听感。

失败分支：量化检查失败先修触发/声部/波形，用户仍觉刺耳则按具体音效定向再调，保留当前和旧版本，不循环泛化生成。
