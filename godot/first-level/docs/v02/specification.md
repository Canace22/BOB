# 须门遗港 v0.2 · 玩法与样板房制作规格

版本状态：planned / waiting_verification。2026-10-27，依据现有首关和用户最新授权，在现有工程继续迭代。v0.1已有通过证据仍留存；本文件不是v0.2验收通过报告。

## 范围与继承

工程：G:/鲸落万物生/godot/first-level。引擎固定Godot4.7.2.stable.official.ed1daf0bf，GL Compatibility，Windows键盘，1280×720。继承现有五房主线、原创拾潮者、鲸尸解剖定位和180耐受首Boss，不引用其他本地Demo实现。风格参考《Hollow Knight》的氛围层次、探索节奏和可读性；不复制其角色、建筑、敌人、UI和Logo。

本轮增加：R1-03可往返的高台支路与永久壳闩短桥；一个完整分层动态样板房，样板通过后扩展五房；独立植物、灯、门、水带、垂须、可动物件资产；事件同步的攻击、命中、死亡和机关反馈。正式质量由本轮实机检查决定，不能继承v0.1通过状态自动判定新内容通过。

## 可玩合同

1U=64px；主角站立高度约64px，脚底为锚点。走速204.8px/s，跳速-460，重力1000，土狼时间0.10秒、跳跃缓冲0.12秒。普通跳约1.65U高、2.94U水平范围，所有房间实际运行复验，不只按公式判断。
A/D或方向键移动；Space跳跃；Q短击；R重鸣；F调息；E营地/出口/奖励/机关；L灯罩；Shift为A1贴流冲；Tab地图；Esc暂停；暂停C回营地，F2二次确认新旅程。
短击一段10伤害，起手/有效/恢复0.12/0.08/0.20秒；二段14，0.16/0.08/0.26秒。重鸣24、射程2.4U、耗2蓄振，0.30/0.12/0.40秒。调息站稳1.1秒、耗2恢复1；受击中断。生命和蓄振均4格。短击、重鸣、调息、冲刺遵守现有动作互斥。
普通蟹30耐受；Boss180耐受。攻击必须在有效阶段判伤，同次招式不重复伤害，无默认接触伤害。伤害形状、姿势与效果相互对应；特效不得暗示不存在的射程或无敌时间。
Boss无A1可胜；胜后保存，右侧E获得A1。A1约2.6U/0.22秒，冷却0.8秒，每次离地一次，实体不可穿过。R1-05三处4U沟用跳冲通过。

## R1-03支路与机关合同

既有主平台：P0 x0..7/y14，P1 x8..14/y13，P2 x15..21/y14，P3 x22..28/y12.8，P4 x29..36/y14。
支台U0 x23..26/y11.3，单向顶面；玩家从P3普通跳上U0，停在约x24.5/y11.3脚点。
同点交互顺序：第一次E领取现有永久碎片；提示切换后第二次E开闩。输入需要完整释放/再次按下，不能一次按键同时吞掉两个事件。
机关稳定ID：R1_03_SHELL_LATCH。开启后桥占x28..29U、顶面y12.8U，与P3齐平；从桥向P4下降1.2U；回程从P4跳升1.2U到桥，再返回P3。桥是本房一米级局部通行便利，不宣称跨区捷径，不凭空改变鲸体器官连接。
未开闩时原主路仍可跳过该缝；支路是可选，不会锁死首通。平台/门/桥不得在玩家身体中生成实体；机关动画展开中应定义碰撞生效点，完毕后可站立。永远保持至少一条返回主路的方法。
主代理计划合入game.data.latch；该字段是运行存储映射，稳定机关ID保留在规格与记录中。旧存档缺字段默认为false，已开启状态保存、离房、死亡、退出重载都不回滚；新旅程显式清除。开闩只记一次奖励/事件。

## 层级与事件合同

正式美术先在R1-02形成样板：远景巨大上颚轮廓→中景须列/沉积残迹→可玩平台/敌人/门→近景暗须/植物边框；雾和粒子独立，不能遮住落点、伤害预告、UI。R1-03负责机关与支路样板，R1-04负责Boss反馈回归。
背景视差以相机位移驱动，碰撞仍留在世界坐标。漂雾、浮动生物、尘埃、垂须、灯光为连续环境动态；水波纹响应入水带/接触事件；攻击弧响应有效阶段；命中响应真实命中；死亡响应一次死亡事件；桥动画响应机关状态变更。暂停冻结场景动态；状态重载不重复播放领取奖励。
“刀光”在本IP中解释为骨鸣器挥动的共振弧/尾迹，不能把骨鸣器替换成剑、骨钉或其他游戏武器。攻击效果的存在不自动获得伤害判定。
