# 鲸落万物生 · 须门遗港
Godot 4.7.2 / Windows / 第一个可玩关卡 v0.2。

## 启动
现成可运行包：G:/鲸落万物生/builds/须门遗港-v0.2/Whalefall.exe。exe和同名pck放在一起，无需打开编辑器。
工程入口：project.godot，使用Godot4.7.2导入后F6/F5运行。

## 操作
A/D或方向键移动，Space跳跃；Q短击，恢复后半段再次Q可接第二击；R重鸣（2蓄振）；F原地调息（1.1秒，耗2恢复1，被击打断）；E营地/门/奖励；L切灯罩；Shift为击败Boss并拾取后解锁的贴流冲。Tab地图，Esc暂停；暂停C回营地，F2两次确认新旅程。Alt+F4退出。

## 路线
外伤坡：在壳营地E记录，沿亮顶平台向右跳。
须筛：蟹举钳先退或跳，等收招短击，右门E。
舌台：分开应对两只蟹；高处小台可跳上取一枚永久碎片（本关不凑齐4枚）。再按E拉壳闩，桥展开后支持往返；状态持久保存。向右。
负壳蟹：左门庭E存档。进入软帘战区，跳扫、退砸，半血留意第二扫。胜后去右侧光团E获得贴流冲。
流膜育窝：E清理入口育窝；三个宽沟在台边起跳，空中Shift，落地再下一段。右门E结关。结关Esc可继续探索。

## 保存
营地、胜利、能力和固定奖励自动保存；退出会从上次营地继续。%APPDATA%/WhalefallFirstLevel/save-v1.json；备份.bak。不要拿save-qa.json当玩家档。
制作账本和接续入口：.production/state.json、RESUME-v02.md。审查和真实运行证据：docs/production、evidence。
本版是5房首通可玩版本；有限关键姿势动画、重复地形、程序音效为当前质量边界。A2/A3回访、后续区域、手柄和最终美术打磨不在本轮。
