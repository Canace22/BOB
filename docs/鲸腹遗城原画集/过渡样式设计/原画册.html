T01 / E01 主路

颌骨斜拱 · 外伤坡 → 须筛

脚下是一条延续的下颌骨，斜向骨拱把两个房间束在同一结构里。蓝色远景从拱下贯穿，不在房间边界重新开始。

分层与连接

  • 远景：共同的斜向骨架，水色保持一致。
  • 中景：斜骨拱、鲸须、少量附生物。
  • 可玩层：平缓起伏的连续骨路；不能另贴一块矩形桥。
  • 前景：暗珊瑚只覆盖地形下沿和两角，落脚面保持可见。

接入前要锁定

斜骨拱是中景结构，不能压住通行净空。原E01两端脚底高度须在局部定稿时锁定。

T02 / E02–E04 材质家族

骨膜渐变 · 须筛 → 深腔

用同一条骨路和连续的上颌轮廓，把开阔蓝水逐步收成组织褶皱中的入口。材质和光照在一段距离内变化，不在一条竖线上突变。

分层与连接

  • 远景：同一斜骨地标延续到收窄入口。
  • 中景：鲸须逐渐稀疏，骨膜与褶皱逐渐增多。
  • 可玩层：连续下颌骨与组织皮层，表面亮度克制。
  • 前景：右下暗部承接深腔；不以黑块遮掉接头。

接入前要锁定

这是过渡语汇样板，不是E02、E03、E04三处相同布局。顶部蓝域作为水下负空间，后续单边定稿需明确内腔封顶；右侧暖光需落实为封闭菌灯。

T03 / E33、E35 上行家族

骨壁生台 · 水平路 → 上行支路

平台从同一骨质支柱和组织纤维上长出，厚度、伸出方向与附生物疏密各不相同。玩家能先看见上层入口，再读出逐段攀升的路线。

分层与连接

  • 远景：同一斜骨跨过上下两层，维持空间方位。
  • 中景：竖向骨壁、附着纤维和入口囊体。
  • 可玩层：有支撑、不同轮廓的骨质台面；不再排成同形薄板。
  • 前景：右下暗骨框景，不能盖住起跳端与回程落点。

接入前要锁定

路线线条仅示意阅读顺序，跳距和上下层高差未锁定。接入时应将支撑及外形贴合现有碰撞，不能直接照概念图重排平台。
