# 场景过渡样式

本页先定视觉结构，不接入引擎。完整说明、原图和后续合同见[制作源](../../../../assets/source/xumen-transition-style-v1/README.md)。

- 颌骨斜拱：开放主路用连续下颌路面、斜向承重骨拱与同一远景衔接。
- 骨膜渐变：在一段距离内逐步改变鲸须密度、骨膜材质和光照，不在竖线上突变。
- 骨壁生台：上下平台具有同一根部和不同轮廓，以骨质支撑解释通路。

[打开图册](原画册.html)。图中路径只示意阅读顺序；工程入口/出口脚底、512像素间距、现有跳距及能力门仍需单边局部定稿。原件未包含可直接播放的动画或拆件。

[无缝接入设定](无缝接入设定.html)已经规定：E01先做联合重绘样板；四段主路保持原564px碰撞顶面，两侧各纳入256px重绘；两条支路保留全部平台位置。完整制作、分层、生命周期和验收约定见[详细规格](无缝接入设定.md)。这些是新样式的接入合同，仍需制作与实机验证。
