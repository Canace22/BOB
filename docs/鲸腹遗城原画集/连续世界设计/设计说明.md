E25/E31/E32；60–70m与15–20m为既定设计估算，非实机测量。

## 衔接原则

1. 主路径是R1→R3胃枢，胃枢分支进R2肺心，获得原P/A3后去R4；不按区域编号强排线性长廊。
2. 每条边有器官来源、一个跨屏地标、连续台面、材质渐变和原开闩侧。
3. 保留胃肠回折捷径、椎旁上下路合流、耳区返程和六个选修口。
4. R5头耳段与尾段分居两端，E25/E31用长过渡说明距离，不能把两幅设计图当相邻房。
5. 七房门的局部像素不直接等于统一世界坐标。连接带需后续灰盒、静态和动态验收后才算实现。
6. 后续E02先做样板，逐边推进；不改变原能力门与V6进度。
