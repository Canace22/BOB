Original prompt: 根据这个概念设计，做一个 mvp 版本给我看看

## 实现范围
- 独立原生 Canvas 网页游戏，保留全部原画与提示词。
- 三段可玩探索：鲸口门庭、肋骨穹顶、心室潮泵。
- 核心循环：跳跃探索 → 共鸣改变环境 → 找回记忆 → 开启潮泵出口。
- 使用原画营造氛围，运行时绘制角色、平台、机关与粒子；合成环境音。
- 先实现可玩流程，再用真实浏览器验证键盘操作、完整通关、失败恢复、暂停与窄屏。
