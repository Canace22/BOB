# 鲸腹遗城：当前游戏方向

用户于 2026-10-28 明确的方向。它说明整体设计意图，不等于全部已实现，也不自动扩大当前原型范围。工程与已验收状态分别见[架构](architecture.md)和[进度](../game/progress.md)。

## 已确认方向

- **类型：** 战斗 + 收集探索，参考《空洞骑士》的体验方向。
- **引擎：** Godot；正式开发位于 `game/`。
- **美术：** 按[原画册](鲸腹遗城原画集/README.md)及[全局风格](../assets/art-style.md)。鲸体是巨大环境，主角小小的；当前 Boss 选用背多层巨大贝壳的搬壳母蟹，体量关系参考林克面对岩石人。
- **武器与道具：** 主角使用叉；斗篷作为路上可收集的道具。当前素材已画出的斗篷，不等于收集获得或能力系统已完成。
- **主角能力：** 普攻、普攻二段；共鸣改变周边地形并增加路线；收集物品；声波吸引鱼群并指挥鱼群攻击。
- **收集图鉴：** 物品可承载小怪、Boss 的背景故事与「万物生」主题；人类垃圾类收集承载生态环境信息。
- **暂不考虑：** 击败鱼类 Boss 后骑鱼到上方关卡出口。
- **尚未定义：** 小怪的具体招式、收集数量/分布、斗篷能力、鱼群指挥细节。实施相应模块时再定，不以本方向文档补写正式内容。

## 当前母蟹原型选择的部分

先做主角持叉普攻与二段、移动跳跃、镜头、巨型母蟹读招/躲避/反击和快速重试。方案见[母蟹 Boss 战原型](鲸腹遗城原画集/母蟹Boss战原型.md)。

原型仍可复用已有重击、治疗作为手感对照，但它们不是用户本次确认的完整技能树；现有伤害型重击也不代表「共鸣改变地形」已经实现。冲刺仅作为可切换的对照条件，基准战斗必须无需冲刺即可获胜。

共鸣开路、物品与垃圾图鉴、斗篷获取、鱼群吸引/攻击在后续模块中分别实现和验收；本轮不为它们批量造内容，不实现骑鱼出口。
