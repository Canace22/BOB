# 19房连续世界与流式加载

## 记忆袋返程与跌落（2026-11-21）

记忆袋在舌台正上方，两房分别通过须筛的不同出口连接。贯穿世界的地形母版会画出下方舌台，只有沿须筛下层右路进入舌台才会激活蟹台和敌人。

每个物理帧先按当前房底计算跌落界限。房底以下，只沿当前房相连的通道折线延伸有效范围，横向余量取一块连接平台的宽度。最近一次站稳的房外台阶也提供短距离下落余量，玩家可以向侧面跳离再回到竖井。记忆袋下层回收台旁失足会扣一格生命并回到原台，可用已取得的浮游升回左侧入口岸。键盘回归见[跌落专项](../game/tests/whalebelly/fall_recovery.gd)。

## 后跳离台的坠落回收（2026-11-23）

后跳独占移动，不经过普通角色移动尾部的底界检测。原来只有落地才结束后跳，离台后会持续下坠。现已在后跳移动后调用同一底界回调：主线扣一格生命并返回最近落脚点，生命耗尽仍走正常死亡；普通角色保留原有规则。回位前退出后跳，不改变连通竖井的有效下探范围、存档或章节状态。

回归见 `game/tests/test_backstep_void.gd`；原生真实 Z 键离台、普通跌落、跨房回收及末格死亡证据见 `game/progress.md` 本批记录。新增动作分支若独占运动，也必须保留地图越界处理，不能只等落地结束。

## 玩家镜头与随身光（2026-11-18，当前本地）

喷气孔上层的世界外缘限位会同时限制横向和纵向镜头，角色仍可继续走动，因此会进入右上小地图的遮挡区。按用户最新要求，正常镜头现在始终取主角全局坐标，外缘也持续居中，固定缩放1.0；此前2026-11-17的软限位约定退为历史。地图外仍显示现有连续远水，不新增画外地形。

`player_light.gd`复用台账中的`UNDERWATER-SOFT-LIGHT.png`与`fx-particle-soft`，等比缩放、加法合成。2026-11-18按用户反馈返修：保留原画纹理，用疏密两层缓慢变化的明暗调制光束；56个细悬浮粒子和12个柔散射粒子使用`CPUParticles2D`，世界坐标模拟、固定数量、预热与生命周期渐隐。光束和颗粒在背景之上、实体地形之下（绝对Z=-1），角色局部补光在角色之上，避免照白平台或拖着整片亮点移动。没有新增位图、动作或玩法碰撞。

光源按玩家全局坐标更新；明确读档/位置夹具造成的大距离跳转才重启粒子，普通连续移动不重启。Shader读取显式暂停时钟，粒子节点可暂停；原图、分层和截图全景隐藏并停住装饰光效。小地图以同一视口坐标比较角色轮廓，重叠时淡到8%，离开后恢复。实机GPU专项为`tests/whalebelly/player_light_qa.gd`，覆盖实际粒子像素、内部流动、平台下方渐隐、真实移动/跳跃、暂停/恢复与房间重载；技术结果与用户审美确认分别记入[进度](../game/progress.md)。

专项`game/tests/whalebelly/camera_outer_edge_qa.gd`覆盖首房左端、封闭右端、支路顶端、截图平台真实移动/跳跃、GPU补光、地图避让及暂停恢复。镜头误差在实际渲染帧完成后取样，不能把`process_frame`发出、节点尚未处理时的旧中心当作最终画面。当前执行结果、证据与限制见[进度](../game/progress.md)。

## 运行组织

- `game/src/campaign/room_stream.gd`负责后台资源请求、邻房准备、冻结/唤醒、活动房切换和远房卸载。桌面使用Godot后台加载接口，只在资源完成后取场景，每帧最多准备一个邻房。无显示Dummy后端曾出现并发压缩纹理空RID，改为按帧串行准备；该分支不改变桌面游戏的后台加载。
- 主角始终位于常驻ActorFrame中。切换房间坐标架并反向调整主角局部位置，世界位置、速度、输入、技能控制器、冷却、生命和蓄振保持。安全点、跳跃起点、重生点和锚环目标一起变换；不重挂主角，避免触发退出树时的技能销毁。
- 邻房准备时在同一同步准备段临时绑定房内上下文，创建原有敌人、动作资源、环境和机关，随后恢复活动房别名并逐节点冻结。包括显式ALWAYS/PAUSABLE子节点、敌人碰撞和环境音；纯环境视差/呈现可独立更新。普通跨界唤醒已准备内容，避免在接缝处首次加载Boss图集。
- 当前房和邻房是驻留核心；近距离旧房延迟回收，离开的远房释放场景。永久能力、奖励和Boss状态仍由V6字典负责；远房卸载后普通敌人按原规则重新生成。退出时显式收回待完成请求，停止UI与连续效果，再释放常驻主角和音频。
- 门条件仍来自原房间数据；Boss状态查对应房间的击败ID。未加载、加载失败或条件不满足时有实体门，并显示原因。活动房的条件门才阻挡其出口，避免共用路口被远房的未加载门封死。

后台接口依据[Godot后台加载说明](https://docs.godotengine.org/en/stable/tutorials/io/background_loading.html)。取未完成的后台资源会阻塞，因此正常跨界不这样做；显式读档/重生可以接管并等待自己的待完成请求。

## 空间与美术

### 前景与敌人颜色（2026-11-18）

须门七房的 `Foreground/OriginalNearBone` 继续使用原入库位图，静态前景只保留既有视差。`foreground_clearance.gdshader` 在低亮度处补入局部水下散射色，高亮处退出。2026-11-18用户继续反馈平台下黑斑后，同机位隐藏图层确认问题来自近景：`FRONT-BOTTOM-PAD.png`含完全不透明、RGB约`(2,1,2)`的暗部，不是导入丢失透明度，也不是静态平台母版。水色默认调整为`(0.14,0.30,0.35)`，独立`foreground_opacity=0.55`统一减弱近景遮挡；Alpha只在原轮廓、落脚避让和流式淡边结果上乘强度，不新增可见像素。平台骨孔的原有明暗保持。这是现有位图的运行调色与合成，没有新素材或新动作。

蟹类的 `hit_flash.gdshader` 直接使用fragment的 `COLOR`，其中已经包含贴图采样与CanvasItem调制；再次乘 `texture(TEXTURE, UV)` 会将颜色与Alpha平方，导致待机也发黑、边缘变薄。主线与白盒的同类Shader同步修复。流式呈现会复制材质并追加边缘参数，`TideEnemyFeedback` 因此每次更新实际精灵当前的材质，不能继续只写安装时保存的旧材质。

GPU专项 `game/tests/whalebelly/resource_color_qa.gd` 检查正常颜色/调制/半透明、受击亮度与Alpha、前景调色前后Alpha一致、七房实际资源及蟹类实时材质。使用本地GPU与独立QA存档运行：`node tools/godot.mjs run -- --resolution 1280x720 --max-fps 60 --fixed-fps 60 -s res://tests/whalebelly/resource_color_qa.gd`。截图、报告只在 `game/build/qa/resource-color/`，不作为新的素材制作源或用户审美签收。

黑斑专项为`tests/whalebelly/foreground_patch_qa.gd`，同样使用原生GPU与隔离档：核对真实黑色源像素、透明轮廓、用户机位改前/改后/隐藏近景对照、七房实时材质与截图，以及真实D/空格/Esc。量测只针对左侧装饰的压暗，不代表删除平台内部阴影；18项通过，当前机位压暗余量约11.5%，平台顶面对照差为0。证据仅在`game/build/qa/foreground-patch/`，整体审美仍由用户试玩确认。

2026-11-16：连接的通用细台外观已由[18边联合补绘](../assets/source/seamless-continuity-v1/README.md)替换，新增共享远景、厚路基、4张竖井去台深景与精确定位的独立承重台根。旧细台只保留不可见碰撞职责，完整路段不再用它做正式外观。补绘与原静态层通过世界坐标所有权交接，保护原房核心；新对象均为静态2D位图，不含新生物动作。下文140px台阶尺寸仍是物理合同，当前视觉来源以补绘批次为准。

`streaming_layout.gd`按稳定ID安排世界原点，原房间矩形不重叠；主线横向，须筛两条支路、肺心和尾槽分层。原门锚点保持，连接使用`streaming_corridors.gd`的已入库平台位图等比拼接，水平采样110px，竖井左右错位95px、相邻步高不超过110px。单向平台可从边缘走下，竖井首末级避开水平接段，保证双向可走。

远景由`stream_water.gd`和`stream_backdrop.gd`的单一世界绘制面负责，使用[六区完整连续远景](../assets/source/continuous-backdrops-v1/README.md)，同时拥有水体和器官结构。每区固定世界锚点、统一0.25视差，采样等比1.5，不随活动房、驻留或卸载重建；区域之间按全部19房的固定世界矩形连续混合。镜像在Shader中计算，过滤使用clamp，避免折返点细线。旧纯水底、套件器官远景、须门Far与旧口腔深景停止覆盖此层。
