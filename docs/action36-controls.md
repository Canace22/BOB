# 拾潮者36动作：逻辑映射、操作与参数

本文件描述已接入正式主场景的36项动作与技能。逐项来源、AI外观复核、实机证据及保留缺陷见[资产覆盖表](action36-asset-coverage.md)、[最终复核](../assets/source/tide-picker-action36/final-review.md)和[工程进度](../game/progress.md)；不代表用户已认可美术。五秒源视频长度不参与游戏技能计时。

## 接入与职责

默认 `game/content/whalebelly/main.tscn` → `CampaignPlayer.tscn` → `campaign_player.gd`。`tide_player.gd` 保留物理、旧状态、输入兼容、伤害及AnimationTree；`tide_skill_controller.gd` 扩展技能时间轴，`tide_skill_catalog.gd` 保存参数，`tide_skill_input.gd` 解析组合键，`tide_skill_hits.gd` 负责命中和弹体创建。`action_visual.gd` 将明确的旧状态/新技能ID映射至位图图集；不再次运行旧跑步控制器。`tide_world_effects.gd` 管理世界坐标特效、历史残影与位图绳。

以下“复用”指已有玩法逻辑，“新增”指本批扩展；二者均可能换用本批动画。旧ID `A4_parry` 实际是叉鸣弹，`A3_anchor` 实际是下刺；不以历史名称推断功能。

## 按键与正式解锁

左右：A/D或方向键；Ctrl+方向行走；K/空格跳跃；J/Q攻击；L/Shift冲刺；U潮术；I重鸣；O潜隙；P治疗；B偏转；T探潮；V蓄力长冲；E交互；G锚定；W浮膜。W同时作为“向上”组合键，施法锁定窗口抑制浮膜运动。

F9是原有会话练习开关，临时开放能力；再次按F9恢复正式能力、拾取、敌人进度和检查点快照。F10仅在练习模式切换基础/升级潮术，便于分别检查基础冲刺/叉鸣弹/上涌/下砸及升级版本。正式流程升级后替换基础版本。练习不写正式能力进度，验证必须用隔离存档。Esc暂停；C地图；Tab切换镜头；H操作说明；死亡菜单按R返回检查点（不再自动复活）；F5/F6沿用原手动存档/读档；1～7沿用房间预览功能，不能当作正式通关证据。

解锁代码：**基础**=无新增门槛；**冲刺**=`host.has_ability("dash")`，击败负壳守卫的现有关卡奖励；**浮膜/锚定**=现有 `float`/`anchor` 奖励；**舌台**=`host.collected["R1-03"]`；**章末**=`host.completed`。不新增存档字段，不改变旧能力与房间ID。

## 物理与输入基线

CampaignPlayer保持最大速度265px/s、加减速1800px/s²、重力1050px/s²、终端850px/s、跳高约154.7px、短跳约100.6px、二段跃速度399px/s、土狼/跳缓冲各0.12秒。壁滑上限212.5px/s、壁跳水平318px/s、锁向0.15秒。碰撞为28×65胶囊；显示高按房间原参考限定80～110px。角色尺寸不按特效外框改变。

攻击/技能新输入统一进入tp_*，旧主场景键同时触发现代映射时不二次请求。跳跃缓冲与技能缓冲沿用0.12秒。死亡、受击、交互、暂停与切房清除蓄力跟踪及待执行输入；恢复后必须重新按下，避免旧长按自动发射。角色本体物理由一个CharacterBody2D控制，视频位移不改变碰撞。

凝流长冲的24帧本体按明确阶段读取：0–13为按住V的蓄力，达到0.6秒后停在第13帧；松开且请求成功立即进入14–22飞行段，按既有1.5秒物理时长推进。撞墙或自然结束以第23帧显示最多0.10秒退出尾帧，不延长技能锁定或控制速度；新动作、移动输入、受击与输入锁立即覆盖尾帧。释放检测使用已跟踪的按住状态与当前松开状态，避免物理帧错过短暂释放标记。正常取消直接进入目标动作，不能回到蓄力帧。

J蓄力派生采用同样的跟踪释放判定。回归使用真实 Input 按下/松开和物理地面、墙面：长冲左右的阶段与位移、J长按释放仅一次、V/J输入锁后恢复仍按住再松开不误发，以及受击后松开不误发。测试使用临时动画分段配置隔离待同步资源，不构成新图集在GPU上的外观验收。全套46项通过，日志见 `game/build/qa/action36/tests-crystal-phases-final.log`。

## 事件、效果与生命周期

新技能用单调elapsed跨越事件点；released标志防重复，脉冲while消费所有跨过的时间点，每段共享目标ID去重。旧近战补了跨帧首次生效，避免低帧率错过窄窗口。新技能释放默认停水平运动并限制空中下落，移动型技能按各自配置接管。动画只是跟随物理状态与事件，不能反向控制物理。

近战用hurt_rect/既有Campaign敌人接口，can_receive_hit过滤无效目标。基础横击继续保持Boss已有180水平范围，普通敌人125；本批未重新平衡Boss。径向新技能当前采用包围矩形判定，不能当成精确圆形。`attack_id`每次新请求递增，单段hit_targets防重复，多段在各脉冲重置。

弹体优先从动画配置orb/shadow_orb的sockets.muzzle发射；挂点坐标按target_height/reference_height换算，X只按技能锁定方向镜像一次。缺挂点时回退角色前26、碰撞高65%的旧位置。方向初始化后固定；扫掠矩形覆盖一帧行程，射线先裁到世界墙，目标按距离处理；基础第一有效目标消失，升级每目标一次；到期、撞墙、受击、死亡或施法者离树清理。偏转成功事件从parry的sockets.guard播放已有弹光位图闪光，缺配置回退角色前45、显示高65%的位置；打开偏转窗口本身不产生成功闪光，每次动作成功一次，取消时回收。反射敌弹需显式加入`tide_hostile_projectiles`并实现`reflect(actor,direction)`；现有普通敌人没有该接口时只验证格挡接触伤害，不能宣称已有全敌弹反射覆盖。

世界特效只使用已入库位图：dive/dark_dive在真实land事件用对应fx图集发力段后半；scan在技能release、基础heavy在旧animation_tag的heavy:release事件使用对应fx图集。三类环均从当时真实脚底发出，记录发出时朝向，世界位置与朝向不跟随角色后续移动或转向；命中以目标hurt_rect中心播放小型弹光位图，属于复用闪光而非新创作命中动画。残影采样实际身体Sprite的纹理、offset和全局变换，每.045秒且位移大于18px才生成，持续.18秒。红索由tether位图沿真实挂点贴图铺设。最多20个短期特效：下砸环.24秒，扫描/涨潮环持续至释放动作原恢复期结束（至少.1秒，标准初值约.38秒）；清理不移除正式场景资源。受击、死亡、交互、切房清理世界临时节点；暂停由场景树冻结。残影无伤害判定。

本体局部FX与世界FX按动作排他；离体弹体、下砸环、扫描环、涨潮环、红索及世界残影不再叠同一源本地FX。源层无法干净拆分时仍须记资产缺陷，逻辑去重不能证明源本体已无烘焙特效。

## 可照做的主场景路线

使用隔离存档启动正式入口。出生地先左右走跑、Ctrl慢走、点按/长按跳跃，向敌人J两连击与W+J上挑；空中S+J尝试真实命中反弹。受伤后落地P，观察一次扣费与完成回复；在治疗期间被碰撞检查中断。按Esc停住后恢复，确认未把蓄力松开补发。继续现有正式路线获得冲刺，再验证Shift与冲刺中J、长按J松开、S+松开、地面V长按松开撞墙退出。门前E或已配置自动门切房，死亡后检查营地复活与原能力保留。

另开隔离练习会话F9；F10在基础/升级组间切换，逐项对左右方向的U、上+U、空中下+U、B、T、O、I、G、W验证。水面、通行门需独立最小场景提供真实节点条件；完成后回到同一共享角色的正式场景回归。测试结果、性能和录屏只依据实际运行记录，不由本说明推定。
