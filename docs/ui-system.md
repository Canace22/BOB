- 主线参数以 `CampaignPlayer.tscn` 为准（`campaign_profile.gd` 是独立参数场的镜像）：生命 5、资源 99、常用消耗 33，调息每次恢复 1。实际已有三段资源，保留数值与规则，不采用设计稿四格/两格消耗。HUD 资源数值始终显示，分段表示可支付次数。
- 角色 stats_changed/cooldowns_changed/died 等信号、主线 enemies 字典是实际数据源。Boss 当前上限 10；交互读取奖励、营地、门与通行节点。
- 主线 V6 文件位于 user://whalebelly/；营地恢复生命并记录检查点，原功能不恢复资源。原死亡自动回检查点，新增归潮界面只延迟返回到用户确认，恢复内容仍由原 respawn 执行。

- 共生模块无解锁、装备、存档或效果实现。本轮营地展示真实休息与保存状态，共生两槽明确未开放，不添加虚假模块及战斗效果。
- 当前实际输入为 TideInput 动态注册键盘；未见主线手柄或触控 UI。项目遗留 map action 与当前 Tab 镜头/M静音冲突，因此新增 C 地图并保留原键位。没有现成重绑定界面；本轮不新增整套重绑定。
- 初始 Git 无已跟踪修改，三个未跟踪角色制作目录与本轮无关，保留。

## 执行与验收合同

先 HUD/暂停/设置，再真实地图/营地/标题/归潮。工具：Godot 4.7.2 CLI、Node、实际 Chromium。接口按主线宿主注入，不创建第二份游戏状态。保留旧 tide_hud 供独立参数场。

证据目录 game/build/qa/ui-system（不提交）。测试使用 QA 文件并禁止旧档导入；新增设置使用独立测试路径。技术检查、真实输入、GPU截图分别记录。测试失败定位返修，不改玩法迎合测试。

## 已实现

- `game/src/ui/campaign_ui.gd`：UI 根、页面层级、焦点恢复、暂停与按键释放保护。世界暂停时 UI 继续处理输入；关闭菜单清除缓冲并等游戏键释放，防止补攻击。
- `campaign_hud.gd`：菌叶生命、99/33 蓄振分段与精确数值、消耗/不足/冷却/未解锁提示、实际交互目标、当前存活 Boss、浮膜余压及区域名淡出。
- `ui_pages.gd`、`ui_settings_page.gd`：真实存档标题、覆盖确认、暂停、地图、营地、归潮与帮助。返回标题后继续读取最近检查点。
- `ui_campaign_data.gd`、`ui_map.gd`：只读当前主线数据；地图表达房间连接而非碰撞几何，未知留白，不提供虚假完成率或传送。位置三角、营地壳形、条件菱形同时配文字。每个区域一页，都有鲸体底图：须门遗港用鲸头特写，其余四区共用全鲸剖面图，房间节点按所在部位摆放，坐标是底图上的比例位置。
- `ui_preferences.gd`：数值辅助、高对比、减少镜头晃动/冲刺缩放、实际总音量及静音；独立 cfg 持久化，危险提示保留。
- `ui_save_access.gd`：V6 校验、临时文件写入和备份；新旅途覆盖前保留 `.before-new`。存档仍由主线管理，UI 不自行改生命和战斗参数。
- `ui_style.gd` 与 `game/art/ui/`：骨白/菌青/琥珀主题、按钮状态与 SVG 母版同步；中文真实字体 Regular 400。

## 启动、操作与限制

仓库根执行 `node tools/godot.mjs run`，或用 Godot 4.7.2 打开 `game/project.godot` 并运行默认场景。标题选择新旅途或继续；Esc 暂停/返回、C 地图、E 营地交互、H 帮助，归潮界面使用不透明黑底；Boss 未击败时 R / Enter 重新挑战（本房入口，双方满血），另有返回检查点按钮；普通死亡 R 返回检查点，Tab 保留原镜头切换。

共生获取/装备/效果与持久化后端不存在，所以仅接入实际营地休息与不可用说明，模块解锁/装备回归不适用。未新增整套手柄、触控和按键重绑定；已有输入不删除，相关专项本轮未验证。重绑定后提示测试未验证；普通提示读取 InputMap 而非复制演示稿键位。无现成分辨率/全屏设置界面，本轮保持工程窗口适配。

源码、Pages 发布版本及线上验证记录见 [工程进度](../game/progress.md)。用户审美认可与本轮 AI 技术/外观复核分开，不宣称用户已验收。
