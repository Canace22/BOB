# 鲸落万物生 UI 系统

## 营地休息面板（2026-11-18，本地）

实际F交互由主线完成回血、补盾和V6检查点保存后，再打开`camp`；UI只读取结果，不承担恢复或写入。休息页使用最大620×500的居中局部面板，隐藏HUD，保留周围场景。首页只留房间名、壳形图标、“在旧壳中，让潮声平息。”和简短恢复／保存结果，数值与规则放进详情；恢复结果用菌青，写入失败单独以琥珀提示，不把生命恢复误写成保存成功。未拥有护盾时不声称“护盾已恢复”。

“继续旅途”默认获得焦点，按钮完整出现在可视区域；“休息详情”为次级入口，显示实际生命／护盾／蓄振、原有恢复规则、跌落例外与已获得护盾来源。未收集物品和未开放的共生槽位不展示。详情返回恢复原按钮焦点，从游戏重新休息则重新选中继续；详情切换不恢复生命、不修改蓄振也不重复保存。Enter确认、Esc返回／离开，沿用按键释放后恢复操作。

实现为`ui_camp_page.gd`，共享容器由`WhaleUIPages.layout()`统一重置尺寸、偏移、字号与装饰，切回暂停和对话时恢复各自布局。新增原生GPU专项`game/tests/whalebelly/camp_ui_qa.gd`检查实际F、Tab、Enter、Esc与移动输入，以及1280×720／960×540、保存失败状态和对比设置。当前验证与证据见[工程进度](../game/progress.md)；下文早期全屏营地及未开放槽位记录属于历史验收。

## NPC普通对话框（2026-11-18，本地）

NPC及刻痕读文继续使用`conversation`页面和既有正文分支，显示改为底部居中的半透明面板，逻辑画布上最大900×260，底部留24px；遮罩只覆盖面板区域，场景与上方生命/蓄振保留。对话期间收起下方技能、路线提示及地图/暂停按钮，避免透过背景干扰阅读。高对比设置使用不透明面板，正文自动换行，过长时在正文区域滚动；关闭按钮右对齐，默认获得键盘焦点，Enter或Esc返回。

沿用世界暂停、按键释放后恢复与焦点管理；暂停、标题、地图等其它页面恢复全屏布局。`WhaleUIPages.layout()`统一处理页面切换和视口尺寸变化，避免对话框的偏移、标题字号和装饰状态污染菜单。`kit_conversation_qa.gd`按当前F键验收，NPC跨房缓存用“不能跨房交谈”验证，不能继续假设所有旧NPC都立即释放。本轮实机证据与边界见[工程进度](../game/progress.md)。

## 当前交互与解锁提示（2026-11-18，本地）

`interaction_prompt.gd`替代原先随主角或门位置绘制的17号裸字：提示固定在下方中央，20号正文配独立的琥珀按键框、深色底和一次短暂淡入强调，不再持续呼吸发光；常规短提示约50px高，长文案换行，底部避让Boss与技能栏。营地、拾取、圆环和浮游沿用原有优先级和范围。按键读取InputMap，当前正式交互为F。离开范围、死亡、菜单或转场时隐藏；原有左下方路线指引保留。

连续地图的实体门也使用同一提示牌，不再每两秒发送左上角17号小通知。玩家距当前房间的阻挡碰撞面150px内，持续显示比普通交互更大的琥珀色受阻原因；需要能力时，下方文字从实际房间的敌人`grants`数据推导获取地点，浮游和贴流冲沿用已有首区获取指引。比如胃枢强流门显示“需要潮压 / 前往肺心潮庭 · 击败血巢潮群”。受阻时隐藏操作键；离开、满足条件或加载恢复后立即收起或恢复正常交互，菜单、死亡和转场仍隐藏。检测距离依据实体碰撞形状，横门和竖门都可解释；相邻未激活房间的门不抢提示。专项入口为`game/tests/whalebelly/blocked_prompt_qa.gd`，本轮结果见工程进度。

`unlock_banner.gd`读取主线已有`ability_unlocked`、`reward`、`level_complete`事件及单调递增序号，不解析通知文案，也不改存档和获取条件。按用户对遮挡与游玩节奏的反馈，撤回原先居中大横幅与7秒停留：现在是生命/护盾与小地图之间最大430×72的两行提示条，显示名称、关键操作和“H 详情”，约3.5秒后淡出，仅保留一次短亮线。角色轮廓进入提示条时自动淡到12%，离开恢复，避让中心战斗区域。完整的已获得能力/遗物操作可随时在H帮助页重看。多项奖励排队，同一当前/待展示ID不叠加；暂停/菜单期间保留阅读时间，启动或读档不重播旧事件，新旅途清空旧提示。

两组件均不接收鼠标、不抢焦点、不暂停操作；高对比使用不透明底色，“减少动态”关闭入场位移和亮线展开，保留文字、角色遮挡退让及淡出。复用现有UI图标、主题与嵌入字体，没有新增场景美术。原生专项入口为`game/tests/whalebelly/interaction_prompt_qa.gd`、`unlock_banner_qa.gd`；本轮证据与限制见[工程进度](../game/progress.md)，不能用下文历史Web结果代替。

## 启动、操作与限制

仓库根执行 `node tools/godot.mjs run`，或用 Godot 4.7.2 打开 `game/project.godot` 并运行默认场景。标题选择新旅途或继续；Esc 暂停/返回、C 地图、E 营地交互、H 帮助，归潮界面使用不透明黑底；Boss 未击败时 R / Enter 重新挑战（本房入口，双方满血），另有返回检查点按钮；普通死亡 R 返回检查点，Tab 保留原镜头切换。

共生获取/装备/效果与持久化后端不存在，所以仅接入实际营地休息与不可用说明，模块解锁/装备回归不适用。未新增整套手柄、触控和按键重绑定；已有输入不删除，相关专项本轮未验证。重绑定后提示测试未验证；普通提示读取 InputMap 而非复制演示稿键位。无现成分辨率/全屏设置界面，本轮保持工程窗口适配。

源码、Pages 发布版本及线上验证记录见 [工程进度](../game/progress.md)。用户审美认可与本轮 AI 技术/外观复核分开，不宣称用户已验收。

公网部署已成功且版本/下载清单匹配；独立浏览器冷启动900秒仍只下载126.9/147.5MiB，超时未进入游戏，因此公网交互未验证通过。已通过的26项浏览器结果来自本地最终导出，详见工程进度与online/report.json。
