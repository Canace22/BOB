# 世界观数据库

供创作和开发查阅《鲸落万物生》的基础设定及主线提案。[打开在线页面](https://canace22.github.io/BOB/lore/)，默认进入人物卡片库。

左侧切换人物、组织、世界规则、地点、章节、战斗、待定事项等分类；顶部搜索覆盖全部条目正文，支持按设定状态和原稿来源筛选。点击卡片阅读完整内容，底部关联项可跳往对应人物、地点、战斗或章节。“查看原文位置”定位到来源标题，“复制条目链接”方便分享，原始文稿页可下载 Markdown。`/` 聚焦搜索，`Esc` 清空搜索并退出输入；条目侧栏支持上下键移动焦点、Enter 打开。

## 内容从哪里来

- [世界观与人物设定初稿](世界观与人物设定初稿.md)：基础世界规则、主要人物和组织，标为“基础初稿”。
- [主线叙事初稿](主线叙事初稿.md)：十二章正文、腔室、战斗安排和配角原文摘录，标为“叙事提案”。

本批收录 58 个条目，包括 8 位人物、12 个地点及12章。人物与章节关系按原文提及建立；新增配角条目只摘录原文，不补写人物背景。地点与战斗条目是章节中的不同查阅入口，不能将条目总数当成独立设定或游戏完成量。两份原稿都未整稿审定，年轻弟子保留可选；章节提案不代表已实现。

## 修改与预览

先修改上面的 Markdown 原稿，再运行：

```sh
node game/pages/lore/serve.mjs
```

浏览器打开 http://127.0.0.1:4191/BOB/lore/ 。服务启动时构建一次；运行期间修改原稿后，另运行 `node game/pages/lore/build.mjs` 并刷新页面。

页面源码在 `game/pages/lore/`，生成的数据、原稿副本和页面在 `game/build/lore/`，不手改生成文件。构建依赖 Node.js 18+，不需要安装前端框架；该目录通过 `.gdignore` 与 Godot 资源导入隔离。

解析依赖原稿现有的二、三级标题：世界观按小节拆分，叙事按章节保留全文，再从“腔室”和“战斗安排”提取交叉入口。增加角色索引时维护 `build.mjs` 中的配角名称列表。改变标题层级后，应复核条目数量、原文位置与关联关系。

## 发布与检查

```sh
node tools/deploy-pages.mjs --lore-only --build-only
node tools/deploy-pages.mjs --lore-only
```

第一次命令仅构建，第二次通过独立检出 `.pages-dist/lore-publication/` 正常推送 `gh-pages`。只更新 `/lore/`，不导出或替换游戏包。`lore/build.json` 保存源码提交和两份原稿的 SHA-256；发布后应与本地产物核对，不能仅以 push 成功判断上线。

每次检查这五组操作：人物卡片与两种筛选；全文搜索及无结果清空；十二章、详情和关联跳转；原文行号、下载及分享链接刷新；桌面和390px手机布局、键盘焦点与加载失败重试。验收截图和临时脚本保留在 `game/build/lore-design/`。

视觉按本次用户参考采用白底、浅灰蓝工作区、图标导航和圆角卡片，主色固定 `#009cff`。Kimi K3.1 Pro 提供布局建议，页面代码和验证由 Codex 完成。该工具目前用于查阅；内容通过原稿维护。
