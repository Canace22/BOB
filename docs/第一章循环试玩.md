## 2026-11-18 · 首次试玩反馈后的修订

首版玩家反馈判定为未通过：护食警告没有行为支撑，跳过内侧灯会漏掉通行和战后剧情，折井方向缺少因果，出口只提示未制作而没有通行，最后表现为卡关。此前预设路线过关不能替代这条真实游玩路径。下面列出的旧版验证数字仅作历史记录；当前变更以本节为准。

| 反馈 | 修订与可观测结果 | 本轮验证 |
| --- | --- | --- |
| 两怪之间没有风险、攻击性弱 | 护食接近速度由42提高到185px/s，两只领地重叠，第二只在更早的接近范围激活；保留0.7秒前摇，有效段真实前冲并扩大可见钳击覆盖。危险来自实际命中，不按站位直接扣血 | 接近不防守会被真实扫击打中；中间站位夹具两侧均朝向玩家并发起攻击，实际造成伤害 |
| 跳过灯后剧情丢失 | 跨过聚食区整段边界即记录通过，无上界、无窄框落地要求；敌人撤回后在安全落地时自动接战后对话，即使越过灯也补播 | 连续向右并跳过旧灯落点区域仍触发战后交流，完全不回头 |
| 水声与折井没有因果 | 主角先指出低鸣来自脚下空腔，询问下行路；补巢者指出可见骨拱通向下层折井，主角决定追查低鸣与封路 | 对话四句依次给出来源、询问、路线、行动意图，待玩家复测是否自然 |
| 空地边界与向右下行目标矛盾 | 将骨拱位置、交互范围、标签和目标统一；从骨拱继续向右或按F会实际切换至折井入口，不再让玩家追逐画面外的下降路 | 自动向右过门与F过门均实际抵达R1-02的折井入口占位场景 |
| 最后没有去处 | 入口到达对话后显示“已抵达折井入口”，提供重新试玩与返回须庭；Esc也可留在入口活动 | 重玩清空本次叙事状态重播开场，返回按钮回到已完成遭遇，不要求再打 |

折井入口复用现有R1-02作为位置和到达验证，不代表第二章主体或专属场景美术完成。警告、剧情、目标与真实可走路径必须一致；后续不能再以“未接入”通知替代一个被指引要求使用的出口。对话结束等待松键时增加明确提示，避免持续按移动键被误以为控制失灵。

新增专项 `chapter_loop_regression.gd`：护食8项、跳灯不停走/到达/重玩15项通过；新版地面战斗及F过门24项、原对话34项通过；全量202项功能断言通过但全局命令仍受旧原型脚本缺图阻挡。已查看跳灯后战后画面、折井到达和完成界面。地面驱动会在到内侧途中自动推进已弹出的战后对话，因此断言检查实际完成事实，不再要求在固定坐标恰好停在某一对白页。

两怪夹击站位为单独夹具，明确写入测试注释；自然地面/跳灯路径仍使用真实输入，不注入伤害、敌人压力或能力。后续体验接受仍需玩家重新试玩，不用技术断言替代本次反馈。

## 怎么试玩

```powershell
$env:GODOT='F:/Godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe'
node tools/godot.mjs run -- --windowed --resolution 1280x720 --max-fps 60 res://tests/whalebelly/chapter_loop_play.tscn
```

窗口标题为“鲸落万物生 · 第一章循环验证”。每次打开从开场开始，只写工作区隔离的QA存档，不导入真实主线存档。失败用原死亡菜单重试，会回到遭遇前的检查点，保留已经完成的对话。正式19房与既有对话试玩入口保持原状。

移动A/D，跳跃空格，J普攻、K三段、I格挡、S+L后跳；其余技能仍用底部Q/E提示。对话F/空格/Enter继续，Esc跳过。

首次试玩先不看下节的路线解答，让玩家自行理解画面与对白。结束后再问：

1、进入聚食区之前，你觉得要做什么，为什么要进去？

2、刚才有什么打法或路线是你自己选择的？哪里觉得只能换血或不知道怎么应对？

3、到内侧之后发生了什么？你接下来想去哪里、想知道什么？

记录原话，不先告诉玩家预期答案。首次试玩时不遥控玩家，不在旁边补讲目标；卡住时先记录位置、时长与尝试，再决定是否给提示。试玩者可以跳过对白，之后也应能从目标与空间恢复方向。

## 样板实际包含什么

| 阶段 | 可玩行为与结果 |
| --- | --- |
| 开场 | 自动对话建立追歌和寻找居民的动机 |
| 居民警告 | 走近第一盏标记灯自动交流，说明两只聚食者、上路观察及内侧目标；设置遭遇前检查点 |
| 接近与观察 | 两块等比复用的骨台提供上路视线与跳跃路线，地面可以直接接近；敌人不在开场远程追击 |
| 遭遇 | 第一只先激活，向内走或压退第一只后第二只加入；两只活动范围分开，保留换位空间 |
| 攻防 | 复用现有尸蟹读招、扫击、受击和真实碰撞。玩家可后跳、格挡、反击或抓空隙跳过 |
| 非击杀退却 | 累计受到3点压力后回到聚食处，保留生命；重击也不会误写死亡或Boss奖励 |
| 通行结果 | 跨过聚食区右侧边界即记录通过，安全落地后自动交流，不要求清怪、指定招式或Combo；未受压退的敌人也结束追击 |
| 战后 | 补巢者回应玩家已通过、敌人退回食物处；玩家追问低鸣，得到折井路线与封锁线索 |
| 片段终点 | 进入有标签的骨拱实际抵达折井入口占位房，完成界面明确收束；第二章主体尚未接入 |

正面压退与上路突破均是允许的方案。上路能避战不自动视为漏洞，需要观察玩家是在读懂威胁后主动选择，还是根本没发现战斗。后一种情况应调整空间和提示，不能仅为保证战斗发生就加清怪锁门。

撤回入口可重置未完成遭遇；已经取得通路后，折返或显式重建不会强迫再打一次。片段不发装备或永久技能，避免奖励把“我想继续了解”这一动机遮住。

## 证据与实际验证

`tests/whalebelly/chapter_loop_qa.gd`以真实键盘事件顺序走通开场到终点，主路线没有修改玩家坐标、敌人血量、能力或无敌。路线结束后的显式重建是独立重试夹具，不算自然通关。

- 地面路线25项通过：读招、后跳、真实J压退、存活撤退、内侧目标、战后对话、下一线索与重建。
- 上路路线20项通过：骨台真实落稳、观察位置、跨间隙、敌人存活时突破、同一战后目标。
- 失败/回退分支14项通过：主动靠近且不防御时真实扫击可造成死亡，检查点重试保留对话并重置遭遇，撤回入口也可重新接近。没有用脚本直接扣玩家生命模拟敌伤。
- 新增单元测试验证大伤害不误杀、撤退不重复触发、未激活目标不受损。
- GPU检查了观察骨台、受击与压退、内侧灯、战后对话和终点画面。产物仅在`game/build/qa/chapter-loop/`，日志在`game/build/chapter-loop-*.log`。

驱动首版在第二只碰撞体旁持续按住跳跃，没有产生新按下帧，且随后在无对话时按Esc打开了暂停；修正测试驱动的松键及页面条件，地面路线以实际压退第二只通过，上路单独验证真实跳跃。未改玩家跳高或战斗参数来迁就路线。

check/test均执行。最终全量断言202通过、0失败，但全局命令仍被独立旧chapter01原型的两处缺图及关联脚本错误阻挡；快速无头退出偶发资源警告仍在。桌面地面/上路专项未报脚本错误，不把这些结果写成全工程通过。

## 玩家验证仍待完成

运行证据只证明循环可执行，不证明动机、选择和节奏成立。当前没有获得3位首次玩家的反馈，也没有将脚本过关秒数当成人类游玩时长。

先按第一章设计稿的5条假设收集反馈。若玩家只看任务字、没有理解为何深入，优先改对话与线索；若多数玩家始终连按普攻且不需要换位，优先改敌人时序和空间；若战后没有新的期待，优先改回应与目的地关系。尚未验证的假设不以增加敌人数或拉长路程补齐。


### 2026-11-18 · 战斗容错试用

聚食怪新增低扫、冲撞、二连钳，头顶显示招式或破绽。先观察是否低扫可跳、冲撞会扑空、二连第一下后不能放心抢攻。招式复用尸蟹现有动画；这仍是短循环样板，章节时长未扩写。

共用输入增加60ms组合窗口：可试先点J再点E，或先点J再点W；窗口内结果分别为连斩和上挑，不补发原普攻。已有Q/E页或方向组合直接出招。下一招缓存200ms，仅保留最后一次输入；后跳立即强制取消，资源和冷却规则照常。主线和独立白盒使用同一输入修改。


### 2026-11-18 · 后跳反序修正

后跳仍是S+L，Z为直接后跳。修正移动中先按L会提前触发撞击的问题：L和A/D+L都保留完整60ms组合等待；窗口内补齐S立即后跳，支持S→L、L→S以及左右移动中使用。命中停顿中也优先识别后跳。超过窗口且已结算的L不会被迟到S改成后跳。移动、空格跳跃、Z直接后跳和Shift备用冲刺不增加等待；已有Q/E选招按原规则执行。

本轮读招更新：头顶金条累计压退（6点撤退）；细青条显示起手/破绽剩余时间。破绽内首次命中额外加2点压退，成功格挡会让怪物直接露出破绽并中止二连。两只怪首次起手错峰0.35秒。招式表现复用已有图集且跟随真实阶段时长；输入参数保持已认可版本。
