# 章节对话头像

共享 `WhaleDialoguePanel.present(speaker, text)` 在左侧显示当前发言者的紧凑头像，右侧保留姓名与逐字正文，按钮仍在框底。名字和头像一起换人；叙述、记录、鲸声以及未知标签会清除上一张头像。头像不拥有暂停、任务推进或存档状态。

`game/src/ui/dialogue_portraits.gd` 以明确的显示标签别名映射稳定角色 ID；新正式内容也可直接传入 ID。现有 `负壳守卫（上层）` 与 `负壳守卫` 同属 `shell_guard`，住户、迁居者和搬运者分别使用已有三种轮廓。余索与贝驮仍保留各自身份，不拿它们代替负壳守卫或补巢者。

头像用 `AtlasTexture` 裁取已经入库、已同步的角色 PNG，运行按角色缓存一次，不新增或重绘素材。七张章节人物、主角待机首帧，以及负壳、泵庭、封梁、老守护者的各自静态角色图均保留原比例。老守护者使用去除多余叉杆后的待机图。裁片已逐张按现有源图检查头部、触须与壳盔，没有用随机圆形或文字首字母伪装人像。

面板宽度仍沿用原有上限 760 像素。头像随面板宽度使用 64–112 像素方形槽，等比留边；正文高度按扣除头像后的实际宽度估算，长文保持可滚动。窄窗缩短按钮文案，不改变 F、空格、Enter 继续和 Esc 二次确认跳过的行为。非人声隐藏头像槽并归还正文空间，未登记人名继续显示名字和正文，不套用上一人的脸。

后续添加有名角色时，在 `SPEAKERS` 中显式登记别名，在 `PORTRAITS` 中指定已入库纹理和裁片。新增旁白、刻字或回声标签须加入 `NON_PERSON`，不能因为无头像而为鲸声新增一个活体 NPC。通过图片而非对白关键词辨认角色的逻辑不进入任务或战斗代码。

本批静态核对图为本地 `game/build/qa/dialogue-portrait-crops.jpg`，涵盖 14 个角色。运行回归入口是 `test_dialogue_portraits.gd`：实际位图/边界和缓存、各章发言标签覆盖、换人/清除/逐字/跳过与小窗三组。原生 UI 截图夹具 `dialogue_portraits_qa.gd` 输出正常、640×360 和 480×360 窗口截图；它只证明共享对话框呈现，不代表实际章节路线或人物场景站位通过。工程检查、完整回归及正式剧情实际输入验收由主整合任务统一记录。
