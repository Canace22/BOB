# 第四至六章白盒设计

本批实现供[连续章节运行器合同](chapters-whitebox-contract.md)消费的 JSON，不覆盖正式19房。叙事依据[主线叙事初稿](主线叙事初稿.md)第四至六章及[世界观与人物设定初稿](世界观与人物设定初稿.md)。所有台面、标记、巢基与膜片均明确标为几何白盒；不作为正式美术、人物动作或玩家审美验收。

运行数据：

- [第四章](../game/content/prototypes/chapters/ch04.json)：脂库调查、有限试流与回收压壳。
- [第五章](../game/content/prototypes/chapters/ch05.json)：缠巢鳗必战、死亡收束、搬巢及居民去留。
- [第六章](../game/content/prototypes/chapters/ch06.json)：外海取证、三片采样比较、脆膜封护与缓引水位标记。

## 空间与操作

每章从左向右推进，底层地面连续，脚线统一 y520，任务点 y480。第四、六章的可选遭遇位于 y310 上层薄台，任务点和敌人锚点 y270；三级台阶每次抬高70。底层观察位与敌人直线距离大于140，不战斗也能进入下一阶段。上层为可选岔路，不放必需壳样、记录或出口。薄台须由主运行器按单向平台处理，玩家可以在下方通行；不能把台阶下方填成碰撞墙。

玩家走近目标后按F；对白可Esc跳过，观察可F直接进入相同终态。任务要求和事实都以稳定ID记录，不靠说话人、物品显示名或对白正文判断。checkpoint只给R恢复，不作为阶段瞬移。

第五章空槽按主运行器平移敌人原试验场坐标处理，敌人锚点 x2180、预警点 x1800。完整战区约 x1480–2480；环闩只是定位代理，不能暗示已经实现自动夹杀或独立环境伤害。必战阶段只能由缠巢鳗死亡完成，走到右端也不能越过阶段。

## 第四章：空下去的脂库

| 阶段ID | 实际操作与结果 |
| --- | --- |
| ch04_01_arrival | 在供养牌前听看守说明采集越走越远，拾潮者只请求检查窄口。 |
| ch04_02_survey | 供养牌取拓必做；底层放纤维看回流或登上废采沟二选一。profile0野怪只占上层，可不触发。 |
| ch04_03_agreement | 负壳守卫以监看身份到场；三方约定先抬巢、只留小缝、水位超过第二线即收口。 |
| ch04_04_limited_flow | 在避流架协助居民抬巢后，才能在限流闩卡入旧壳。 |
| ch04_05_tides | 五秒压缩数次潮汐，记录污絮减少、稀少新附着及胃室回信；没有刷新敌人。 |
| ch04_06_keep_limit | 沟底仍空、下游承受能力未知。拾潮者收回部分压壳后，才封存少量样片和许可拓片。 |
| ch04_07_exit | 沿下游撞击声与旧排流刻线进入第五章。 |

调查完成不等于看守接受全开。正面结果有边界：新附着仍养不起整片聚落，不能为它写扩大开口奖励。负壳守卫不重复决斗，共同扶壳只是本次有限合作。

## 第五章：搬不走的巢

| 阶段ID | 实际操作与结果 |
| --- | --- |
| ch05_01_find_family | 补巢者指出幼体附着在巢基，鳗已多次绕环返回。 |
| ch05_02_prepare_refuge | 查看幼体附着处，确认不能硬拆；随后带居民退到厚壳后，战斗场移到无住巢的空槽。 |
| ch05_03_eel | 复用profile4完整战斗，ending为kill，必经且不允许从出口跳过。 |
| ch05_04_after_battle | 主角手臂仍抖，补巢者准备整段搬走；留居者、迁居者各自说明安排，没有胜利奖励或全体拥护。 |
| ch05_05_carry_base | 抬整段巢基，途中绕开并保留留居者拴绳，再将巢放到迁居接力架。三处任务连续向右，不回原地取物。 |
| ch05_06_exit | 肋间只能过轻巢，重巢仍需撑架；拾潮者去肺缘核查水况。 |

去留属于居民自主决定，玩家的任务是协助搬运且不侵占留下者的系点。现阶段只以位置交互、文本与稳定任务状态代理搬运，没有制作可抓取物理巢基、幼体动画或真正环路追逐。这些不另列为通用程序需求。

## 第六章：外海仍在流动

| 阶段ID | 实际操作与结果 |
| --- | --- |
| ch06_01_patrol | 看守明确指出低灯、遮蔽位与采样水路，玩家知道不战斗路线。 |
| ch06_02_outside | 底层遮蔽位或上层暴露台二选一，并核对旧流向刻痕、近年封片和脂库拓片。profile3捕食者不锁观察；撤回底层可离开暴露区。 |
| ch06_03_place_samples | 同一段路上，分别向强流口、稳撑背面避流口和封闭内槽固定等大壳样，各自刻号。三项无互相前置，可任意顺序放置。 |
| ch06_04_tides | 五秒压缩低潮、涨潮与数次附着观察，收回三片样片。强流与脆膜风险同时保留。 |
| ch06_05_mark_limits | 比较甲无附着、乙新菌丝与小生物、丙污絮后；给两处脆膜系红绳，最后清理稳撑避流台并画缓引窄线。 |
| ch06_06_echo | 回声只有古鲸感官片段；看守没有因此接受主张，而是核实样片、红绳与巡视记录。 |
| ch06_07_exit | 带全部样片及限制图前往泵庭，看守留下继续观测。 |

采样不以捕食者死亡、退却或上层观察为前置。观察段离开后，敌人和弹体须由运行器安全回收。只有两处红绳点都完成才开放缓引水位标记；这一步没有拆主封片或真正开启外海冲流。

## 本轮检查与待验

本批只做数据与文字，不运行Godot、修改共用战斗或字体。静态检查内容：JSON可解析、stage及task ID唯一、依赖存在且无环、required/any存在、next顺序、关键profile/ending及目标位置落在地图范围、文档相对链接、git diff空白问题。

主运行器集成后应实测以下五条路线：

1、第四章完全不上层，从底层观察完成调查，抬巢后开小缝，观测后收口并前往第五章。

2、第四章上层遭遇后R恢复或回到底层，仍可完成同一调查；新阶段不留敌人或投射体。

3、第五章鳗未死时走到右侧不能跳关；击杀后不可重复敌对，搬巢段仍完整，并保留居民两种决定。

4、第六章不开战完成遮蔽观察、三片采样、两处封护与缓引标记；可选观察不成为隐形前置。

5、第六章主动登台触发捕食者，再撤回遮蔽位；R恢复、跳过观察和跨章后，任务状态与样片比较结果一致。

字体覆盖、真实键盘可达性、完整战斗难度、存档与跨章恢复由主Agent合并验证。当前文档不宣称这些项目已通过。对白已按humanizer检查，删去口号式收束，保留人物具体的用水、住巢、职责和搬运动作；没有新增未经证实的可复用制作配方，因此不另改共享Skill。
