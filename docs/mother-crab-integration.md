# 主线母蟹 Boss

R1-04 的简化负壳守卫已替换为之前独立训练场的母蟹。正常穿过前三房即可遇到它；击败后获得冲刺并打开右侧出口。旧档如果已经击败守卫，会继续保持通路开放，不会强制重打。

## 操作与读招

- 低横扫：跳起避开，等收钳后反击；横扫收招保留 1.3 秒。
- 单钳下砸：后退离开范围，或在抬钳末段用 `I` 重鸣打断，触发破防。
- 冲撞：提前后退，等前冲结束后反击。第二、三阶段会组合招式；逼到边缘时取消无法后退躲避的下砸追击。
- 护壳时显示“弹刀”，伤害较低；收招和破防时显示有效命中。阶段转换依生命的 65% / 35% 触发。短击回资源仍按现在主角的规则结算。

沿用训练场 300 点生命与伤害比例；主线的 1 点短击在母蟹结算中对应原训练场 10 点。这个换算只影响母蟹，普通敌人与角色面板参数仍沿用主线。

现有地形、主角脚本、技能参数、攻击范围、资源消耗与回资源规则全部保持原样。适配集中在 Boss 侧：受击代理向现有技能提供壳边锚点和完整受击区域，读取现有弹体命中记录区分近战与远程。主角无需增加新攻击接口。

## 来源与实现

来源为 `codex/crab-boss-prototype` 的 `581397ab52394900f7f4d99a54f6456aa0897af0`。选择性迁入三招、阶段连招、护壳/破防、V3/V4 位图及制作源。没有合并旧主角、旧 HUD、训练场存档或整个旧工程。

主线模块在 [`game/src/campaign/boss/`](../game/src/campaign/boss/)，保留主线敌人字典与 `R1-04:0` 击败键。死亡后先解除实体阻挡再播放退场，奖励、出口和 V6 存档仍由主线宿主负责。母蟹沿本房连续地面取高度；低侧台保留给玩家，宽壳不被侧台边缘卡住。

七张身体图集和两张位图效果经 `manifest.json` 同步；原件和根位置测量保存在 [V3](../assets/source/crab-video-v3/README.md)、[V4](../assets/source/crab-video-v4/README.md)。继承已有关键帧漂移和动作衔接限制；技术验证不等于新的美术认可。

## 验证入口

在仓库根目录运行 `node tools/godot.mjs check` 和 `node tools/godot.mjs test`。`test_campaign_crab.gd` 覆盖唯一目标、护壳/反制/远程、攻击范围与角落连招、奖励和旧档重载。

`game/tests/whalebelly/crab_campaign_qa.gd` 从正常房间出生点用真实输入战斗；`campaign_route_test.gd` 覆盖连续到达、Boss 与出口。Web 使用 `game/tests/web_campaign_crab.mjs`，只读状态驱动键盘，使用独立浏览器上下文。具体已执行结果和线上版本见 [工程进度](../game/progress.md)。
