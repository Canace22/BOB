# 第三章游戏循环设计 · 被冲走的家

2026-11-21。独立白盒提案，承接已认可的第二章流程；不覆盖[叙事原稿](主线叙事初稿.md)，不等同正式19房主线接入。

## 动机与人物知情范围

主角跟随折井住户进入胃室，遇到正在替亲族补巢的补巢者。先看到发灰菌床、卷边幼丝和回流污絮，才谈起水路。补巢者想赶开不让人靠近浅槽的大甲，没有知识或权限授权来客改水路。鲸歌仍是主角深入的私人动机，不作为居民的判断依据；本章对白不再让其他人认可该声音。

战斗结束后，旧瓣裂缝持续漏水，局部污絮排走、槽底露出，给主角一个可见但不完整的依据。他检查的只是眼前出口，没有检查另一端回水。玩家需要先查看，再独立按F撬开；击败敌人、推进/跳过对白都不自动开瓣。这是原稿固定的故事转折，未制作另一条避免事故的完整分支，不把它包装成玩家自由选择结局。

## 可玩顺序

| 段落 | 玩家动作 | 反馈与下一步 |
| --- | --- | --- |
| 来到菌床 | 首次走近主动交流 | 补巢者忙着固定巢片，亲族收留折井住户；幼丝卷边，种过两次仍失败 |
| 查看浅槽（可选） | 到槽口F观察，或继续向右接近大甲 | 污絮绕回菌床；观察补充局部信息，不作为战斗触发前置 |
| 低坑交锋 | 污絮翻动预警后遭遇栖污大甲 | 复用已验收的伏击、顶甲推进、抬甲翻压；战斗在废弃低坑，住户不在伤害范围 |
| 观察旧瓣 | 大甲退走，到旧瓣F查看 | 裂缝正在排水，局部改善；敌人结算不打开水路、不解锁技能 |
| 主动开瓣 | 松开对白按键后，再F撬开 | 先有约2秒排水改善，再出现折返回水；约5秒后才呈现菌床受损、居民上台 |
| 事故与救援 | 观察8秒演出，可F跳过 | 救援者重新压住旧瓣、先撤住户；无护巢倒计时、QTE、第二批怪或技术上可赢的假目标 |
| 捡回与固定 | 回左侧浅滩F捡旧壳，再到住巢F固定 | 沿实体台阶返程；只保留一次短取物与固定，不做重复跑腿；菌床损失保留 |
| 去脂库问人 | 修补后沿右侧台阶到出口 | 补巢者只指出来水经过脂库，并让主角去问看守，没有原谅、奖赏或诊断整个供养系统 |

## 对白样段与humanizer复核

> 补巢者：嗯。换了两回菌种，还是这样。你看，刚长出来就卷了。
>
> 拾潮者：水里全是絮，排不出去？
>
> 补巢者：从底下又绕回来了。那槽里还窝着只大甲，靠近就扑人。

事故后不借老守护者发表世界观演说，只问刚才的动作：

> 老守护者：谁动的旧瓣？
>
> 拾潮者：我。刚才水往外流，我以为……
>
> 老守护者：你往另一头看过没有？
>
> 拾潮者：没有。
>
> 补巢者：下面那片壳还能用。替我捡回来。

修补时道歉得不到即时安慰，补巢者仍在安排手头的事：

> 拾潮者：旧壳已经托稳了。菌床是我撬开旧瓣后冲坏的，对不起。
>
> 补巢者：请再把旧壳右边的系绳勒紧。下一次涨水的时候，住巢还会晃。

初审删去“这是你的责任”“供养失衡”等作者解释，改为具体水流和实际处理。复核保留补巢者办事时的短句，但不让每个人都说同样的任务提示；进入时聊亲族、战后忙于保住巢片、最后才回答去向。救援对白以眼前住户为对象，不把事故写成老守护者等候主角犯错的说教舞台。

## 运行和验收边界

入口见[胃室白盒说明](../game/content/prototypes/chapter_three/README.md)。第二章完成对白后在出口按F继续，或直接开本章。复用已有玩家、格挡/架势、组合容错、栖污大甲和对白面板；场地、水路、居民、补巢者及救援是标明的几何代理，老守护者复用旧位图姿势，未补新正式美术或动作。

存档独立 chapter-three-whitebox，沿用工作区摘要与试玩/测试后缀。R按事实回安全点，F6只清本章。事故中退出，恢复到居民安全的事故后交流，不播放半截水灾，不重复开瓣。维修前出口有可见实体隔断，目标始终指回受损住巢；维修后实际移除碰撞。章节成长与技能奖励本轮不扩写。

验证要分开：脚本能否按键完整推进、读档/跳过是否一致、玩家是否相信主角的判断，以及事故是否产生牵挂。白盒时长不当作正式章节时长；未制作第四章、完整水体模拟、正式救援动画或永久分歧结局。

试玩修正：忽略槽口F直接走近大甲也应触发0.8秒伏击预警和交战。回水观察为可选信息，不以未看对白冻结敌人；旧进度停留evidence阶段也直接适用。

2026-11-22逐句审改：先说明菌床供食、新菌丝遇回水卷曲，再由居民说明栖污大甲占住槽口、使他们无法查看排水口。主角为了查清脏水淤积，先赶甲再查旧瓣；回水查看仍可跳过，必要动机已放在首次交谈。事故后返程时居民已获救，巢片托扶和捡壳先交代接手者，修壳完成在对白结束后落盘。旧壳记日子的刻痕为第九章回访提供前置；不保留无用途的披风纤维。完整每句依据见[章节逐句审校](章节逐句审校.md)。
