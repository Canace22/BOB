证据边界：本轮按播放器实际画面、烧录字幕、页面说明与关键片段分析，未逐帧穷尽完整视频；音效条目按作者可见分类归纳，未独立测量或听辨原始音轨。下文参数是本项目试调建议，不是视频作者给出的标准值。

## 一次命中的统一流程

真实碰撞/范围判定 → 目标结算是否接受伤害及受控 → 生成一次命中结果 → 统一驱动命中呈现。

命中结果只带此次需要的数据：攻击实例/脉冲ID、攻击者、目标、近似接触点、来向、轻重档位、目标材质，以及普通命中/霸体承伤/格挡/击杀等结果。它不自行决定伤害、无敌、击退许可或敌人硬直。

- 空挥不出命中闪光、不播放撞击音、不停顿；挥空音仍可在出招时出现。
- 命中被拒绝时，按实际结果显示无效/格挡等反馈，不冒用“有效伤害”的全套表现。
- 接触点来自已有判定几何的交会位置，标为近似；不在命中时做GPU读像素或伪称像素级碰撞。
- 同一攻击实例、同一脉冲、同一目标只结算一次反馈；合法多段各自保留脉冲身份。
- 一刀多目标各自受击，但攻击者停顿、群体音量和大特效应限额，不按目标数量累加。
- 复用现有命中入口与WorldEffects运行能力，统一收口；具体模块拆分在接入时按现有边界确定，不平行堆第二套伤害系统。

## 第一轮建议试调

以60fps为计时基准；以下仅为白盒调参起点，需按实际动画和目标尺寸验证。

| 层 | 普通轻击 | 重击/终结段 | 约束 |
| --- | --- | --- | --- |
| 双方命中停顿 | 先试2帧，约33ms | 先试3–4帧，约50–67ms | 同步相关攻击/受击动画、位移与AI计时；UI和音效继续。首次接入选择唯一计时归属，避免与现有停顿重复 |
| 敌人受击姿势 | 明确启动一次hurt逐帧，迅速恢复 | 更显著的受力姿势，按已有许可倒地/挑空 | 命中呈现计时独立于AI状态，不逐击无限刷新硬直 |
| 命中亮度 | 约2帧短闪，再快速回落 | 峰值略强、回落略长 | 保留轮廓和材质，不用整段白色覆盖 |
| 普通目标受力位移 | 原地反应或总计约4–8px短后退 | 约12–24px，按连段接触距离限制 | 是候选总位移，不是每帧瞬移；先确认不会把下一击推出范围。Boss/固定目标允许不移动 |
| 接触处特效 | 一个短促、小范围、沿来向的命中峰值 | 大一档，碎屑/扩散可更明显 | 不覆盖角色武器与受击姿势；与挥砍拖尾分开 |
| 音效 | 挥空与命中分离；命中有短清晰的攻击峰值 | 增加适量低频/材质层 | 按肉/壳/金属区分；复用少量变体并限制同时发声，重击不等于单纯加响 |

多段技能的中间段比普通单击更克制，末段再强调；不能五段都用最长停顿。群攻使用一批次的强度上限，不五个敌人就冻结五倍时间。

## 敌人类型与已有规则

- 普通软体：可有明显受力姿势和较轻位移。
- 尸蟹等硬壳：短促硬质接触、壳面命中点和已有hurt动作；不照搬几何小人夸张挤压拉伸，变成橡皮玩具。
- 霸体敌人：接受伤害仍有局部闪光/材质反馈，身体与AI按原规则继续，不伪造被打断。
- Boss/固定目标：用受击姿势、局部反馈表达重量；不为“通用”强制平移整个Boss或重置技能。
- 击杀：明确的死亡过渡与收尾反馈，优先保证敌人状态可读。
- 地面普攻站定继续保持。攻击者的“撞到东西”主要通过姿势停顿表达，不能重新加入主角滑步后坐，破坏刚确认的操作。
- 正式角色/硬体生物新增受击动作仍需逐帧位图；Shader闪光、贴图驱动粒子等仅为辅助，不冒充动作素材已制作。

## 验证顺序与验收

先固定同一个敌人、同一段普攻、同一伤害和距离，录正常速度对照。每次只改一层，保留开关和原始计时证据。

1. 普攻空挥/命中：命中那一帧，接触点、双方停顿、敌人姿势、闪光、撞击音一致；空挥不会冒出命中反馈。
2. 轻击/重击/五连：有清楚层级；中间段不断被长停顿打散，末段足够明显。
3. 连段距离：轻退后下一段仍能接触；一刀多目标不重复延长攻击者停顿、不叠爆音量。
4. 霸体/Boss/格挡/死亡：结果与真实战斗规则一致，有反馈不等于强制打断；无效伤害不会伪装成普通命中。
5. 连续实机与取消：普攻站定、冲刺/格挡后摇取消、后跳白影、弹体存续、暂停/死亡/重置清理正确；不开录制时复测帧时间，避免重现纹理回读卡顿。

建议实施顺序：统一有效命中结果和接触点 → 同步停顿与敌人受击/短闪 → 材质音效和命中FX → 分档、限额与对照调参。震屏、大冲击波、飘字和连击分数暂不列为第一轮必需项。
