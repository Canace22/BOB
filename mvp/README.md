# 鲸腹遗城 · 可玩原型

根据这套 18 张概念原画制作的三关 2D 横版 MVP，用来体验「跳跃探索 → 共鸣打开通路 → 找回鲸的记忆」这条核心玩法。

需要 Node.js，无需安装依赖。在 `mvp` 目录打开终端，运行：

```sh
npm start
```

也可以运行 `node server.mjs`。随后打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，点击开始按钮。终端需保持运行；按 `Ctrl+C` 停止服务。

同一局域网内的手机或电脑，可以打开 `http://这台电脑的局域网IP:4173/`。请使用 `http`，并保留端口 `4173`；其他设备上的 `127.0.0.1` 指向它自己，不能用于访问这台电脑。

**发布到 GitHub Pages**

在 `mvp` 目录运行 `npm run deploy`：先对初版和新版（`../mvp-nightmare`，需已 `npm install`）做语法检查，再把两版游戏和用到的 4 张原画打包，强推到远程 `gh-pages` 分支，结束后打印新版访问地址。线上初版在 `/mvp/`，新版在 `/nightmare/`，站点根目录跳转到新版。不会改动 `main`。首次发布若未自动开启 Pages，请到仓库 Settings → Pages，选择 `gh-pages` 分支 `/ (root)`。只想看打包结果、不推送：`npm run build:pages`（输出在仓库根的 `.pages-dist/`）。

**操作**

`A / D` 或 `← / →` 移动；`空格` 跳跃，空中再按一次可二段跳；`E` 共鸣；`M` 地图；`J` 手记；`Esc` 暂停或关闭面板；`F` 全屏。右上角音符按钮切换声音，声音在首次开始游戏后启用。

**完整路线**

1. **鲸口门庭**：向右跳上舌面台阶，靠近发光的「鲸须琴弦」按 `E`，打开鲸须屏障。继续向右，触碰金色记忆泡，在最右侧出口按 `E`。
2. **肋骨穹顶**：靠近「回声骨桥」按 `E`，让断口出现可行走的桥。避开水母，跳上右侧高台收集记忆，再前往最右侧出口按 `E`。
3. **心室潮泵**：沿台阶向右，分别靠近三枚凝血阀按 `E`。收集第三枚记忆，三阀全部打开后，在最右侧出口按 `E` 查看结局。

每关一枚记忆，触碰即可收集，按 `J` 阅读；记忆不必集齐也能通关。共鸣有短暂冷却，离机关太远不会激活。掉落或生命耗尽会回到本次游玩最近激活的机关旁；尚未激活机关时回到区域入口。

机关和记忆会自动保存在当前浏览器中。刷新后点击「继续上次的旅程」，从已保存区域的入口继续，保留已激活机关和已收集记忆。精确站位不会保存；重新开始会覆盖原进度。

**实现与范围**

原画提供场景氛围，Canvas 绘制角色、平台、机关和粒子；关卡数据定义落脚点与目标，共鸣改变通路状态，WebAudio 合成深海环境声和操作反馈。修改时先调关卡数据，再验证跳跃与机关，最后检查画面和声音。

本版已实现三关、机关、记忆、危险与重生、地图与手记、存档及合成环境声。18 张原画中只选取三个区域做成可玩关卡，其余区域、四阶段生态演化和复杂 Boss 尚未实现。

**保留目录结构**：原画位于 `mvp` 的父目录，运行时会直接读取。不要单独搬走 `mvp`、改动原画文件名或把图片搬散。

**验收操作**

1. 移动并连续跳跃：空中最多再跳一次，落地后恢复；平台间能正常跨越。
2. 从头走完三关：远处共鸣不激活机关，靠近后激活；第三关缺少任一阀门时无法通关。
3. 收集三枚记忆：计数逐一增加，手记显示对应文字，重复经过不重复计数。
4. 激活机关后故意掉落：回到该区域最近的共鸣落脚点；刷新并继续后回到区域入口，机关和记忆保留。
5. 打开地图、手记与暂停面板，确认角色停止移动；返回后继续操作，并检查全屏、声音开启与静音。
