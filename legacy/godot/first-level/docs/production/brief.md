# 首关制作范围

用户2026-10-27明确要求按game-production-pipeline实际完成第一个可玩关卡，Godot。
以V5.2为设计依据，首关是须门遗港首通段R1-01~05：安全走跳、蟹敌教学、两敌选择、首Boss、授A1与跳冲练习到胃枢入口。不是把全游戏或后续A2/A3回访房计入本轮。
目标为Windows键盘可玩、1280×720兼容渲染器；2–3人制作范围，中文HUD。不得复用旧本地Demo实现，不修改图册及旧工程。
保持30cm拾潮者：单镜头盔、青披风、左灯、U形骨鸣器。120m巨鲸为幻想，口腔上颚鲸须，咽后变为纵向肌褶。画面有独立背景、碰撞地形、角色、雾/粒子、UI。
基础走跳/两段短击/重鸣/调息/灯罩/交互；首Boss可无冲刺战胜。180耐受，扫击/壳砸/半血二扫，有预告与恢复。胜后E取A1，永久保存，R1-05三段4U沟需跳冲，离地一次冲刺。坠落恢复、归零营地、开闩和唯一奖励不重复、暂停、地图、重新开始。
完整性包括Windows工程及可运行交付、操作说明、技术/运行/动态/视觉/音频/性能证据、制作账本与下一指令。AI审查不是人工审美签收。
原Wan序列有身份变形，不直接当作验收资产；优先用独立透明原画和可驱动动画，不依赖带水印Ludo样片。
允许新生成必要分层资产，使用内置imagegen；不调用未授权付费外部服务。发布、全游戏、联网和手柄适配不在首关范围。
发现原R1-01数据出口在左与walkthrough向右矛盾：实现采用正文向右结束教学，记录为必要门位修正，不改变世界拓扑。

阶段：P00范围→P01环境与合同→P03灰盒循环→P04美术动画→P07集成存档→P10综合验收→P11独立交付。
