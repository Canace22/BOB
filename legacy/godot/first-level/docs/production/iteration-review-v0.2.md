# 首关迭代评估与下一轮制作建议

评估日期：2026-10-27。基线：须门遗港 v0.1，Godot4.7.2，R1-01至R1-05。审查者：AI agent。本轮为评估与制作方案，不修改游戏实现、不重新生成资源、不改变已通过账本。建议项不是已经交付的功能。

## 当前结论

制作账本P00至P11均保持passed，范围为首通闭环与技术验收。独立包完成五房/Boss/授能/结关，21项边界夹具通过；不代表真人手感、音色审美和完整探索内容已定稿。原审查记录见qa.md、art-review.md、integration.md。现有土狼时间0.10秒、跳跃缓冲0.12秒、受击无敌、营地恢复和坏档备份已经实现，不重复列为新增需求。

以下区分“代码/证据确认的现状”“体验假设”“建议设计”。本轮没有新增真人试玩或重跑性能测试。

## 五房具体迭代

1. **外伤坡**：把按键列表拆成就地教学，保留安全试跳；用红结、裂口和远处上颚表现入口。加一个从主路能看见的小藏点，建立“观察有回报”。
2. **须筛**：用单蟹和安全观察台教预告；候选加入原设计中的剪须虾迁行，先单独展示预告与避让，再与地形组合，不在新手第一次交战时叠加全部危险。这里作为整关视觉和战斗样板。
3. **舌台**：利用现有高低台形成“下层战斗快路/上层探索支路”；让玩家能分开引敌，拿碎片后通过短路回主线。先测试敌人是否被地形无意卡住，不靠增血量增加难度。
4. **负壳蟹**：优先修正三招动作与判伤解释，再调半血第二扫节奏。明确可安全调息的收招窗口；保持无冲刺可以战胜。战后留下负壳与通行红结，强化迁徙叙事。
5. **流膜育窝**：将三次相近跳冲安排为“安全体验→略高落点→明确着陆空间的组合”，一次只引入一项变化；育窝增加短因果交互。可选回访捷径先评估解剖连接，再落房间，不凭空把口咽接到远处器官。

## 适合2–3人团队的批次

- **v0.2 操作与战斗样板**：I01、I02、I03必要反馈、I05核心动作；样板选须筛的一只蟹与一组高低台，Boss三招作为关联回归。先统一判定，再定动画，避免边改尺寸边批量出图。
- **v0.3 探索与场景样板**：I06的一条支路/一个捷径、I07二选一、I08、I09一个完整样板房。通过后复用到其余房间；此时升级地图显示。
- **v0.4 试玩打磨**：真人观察、战斗资源取舍、主观试听、无截图性能采样、设置与发行资源整理。

以上是工作分批，不是未经验证的工期承诺。保留v0.1可运行包。每批使用独立迭代账本/计划，依据技能流程归档旧账本，不直接修改旧计划或把旧通过结果改成新内容已通过。
