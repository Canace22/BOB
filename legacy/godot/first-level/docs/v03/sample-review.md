版本：v0.3 / Godot 4.7.2 Compatibility。审查者：agent。以最新张口全景及七房坐标图为基准。

实际截图：evidence/v03/scenery-release/R1-02-middle.png；入口特征对照 R1-01-left.png。运行房间有独立远海/须幕/可玩舌台/近景，图片不是铺一张全景作为整关。静态碰撞与可见台面分别制作。

返修：第一轮截图入口吻端出画、地形孤立，已调整入口镜头和补充组织承托面；中景没有在食管/颅侧放鲸须。首次运行发现装饰ShellHinge同名造成孤立节点，已生成独立节点名，后续退出无该错误。

限制：复用角色/敌人的连续动画仍为原有版本；地形模块可继续做更多手绘变化。场景是依据局部房卡还原，不是把压缩全景按像素放大，因此镜头跨度与概念图不同。未取得用户人工审美确认。
