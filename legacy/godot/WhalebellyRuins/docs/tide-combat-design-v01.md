# 拾潮者：基础攻击与三组技能设计 V01

日期：2026-10-29。状态：设计提案，未修改运行逻辑、伤害、输入或存档，未追加视频生成。依据《空洞骑士》公开玩法资料、项目角色设定及当前CampaignPlayer实现制作。资料读取不是读取游戏安装包、提取动画或复刻官方逐帧参数。

## 设计依据与角色表达

《空洞骑士》的普通攻击积攒SOUL，施法和治疗消耗同一资源；蓄力骨钉技提供另一种进攻选择。向下攻击反弹同时用于战斗和平台移动。这里只提炼距离、方向、资源与风险的分工。[战斗资料](https://hollowknight.wiki/w/Combat_(Hollow_Knight))、[骨钉反弹](https://hollowknight.wiki/w/Nail)、[法术、移动与骨钉技](https://hollowknight.wiki/w/Spells_and_Abilities_(Hollow_Knight))。

角色依据：[全局美术](../../../assets/art-style.md)、[世界与共鸣设定](../../../docs/鲸腹遗城原画集/V2/游戏设计说明.md)。拾潮者是约30厘米的两栖探索者，低重心、蹼足蹬伸，象牙壳头稳定，青披风跟随转身。骨鸣器是短柄U形双叉共鸣工具；输出表现为敲、拨、点与叉间压波。菌灯始终密封、无裸火；左髋灯提供暖色能量反馈，骨叉释放克制的灰青压力纹。红绳是随动系绳，不自动扩写成绞杀鞭；锚环继续使用既有探索设备。

战斗循环：短击命中 → 菌灯积蓄共鸣 → 选择攻击或调息 → 利用位移重找位置。UI可将“魂”改称“共鸣”，底层soul字段暂不改。探索中的基础照明、必要机关短鸣不消耗战斗共鸣，避免无怪可打时卡住路线；不新增杀怪经验奖励。

## 基础攻击：三方向、短动作

以下所有时间、伤害与帧数都是本项目初始设计值，尚未实机调参。画面按12FPS制作；表中帧从1开始，物理与判定继续60Hz。动作片段是非循环短动作，不把参考视频6秒片长直接作为攻击时长。

|动作ID / 名称|动作设计|12FPS节奏与事件|战斗定位|
|---|---|---|---|
|atk_side_a / 扣潮|右肘贴近侧肋，骨叉短收；后脚蹬地、髋肩前送，叉口向前扣击；前腿微弯缓冲，肘收回戒备。移动时主要改变上身，避免每次都强制跨步。|4帧/0.333秒：F1–2短收与蓄劲；F3扣击有效，t=0.167–0.250秒；F4回收。F4允许跳跃/冲刺取消。|默认J，伤害1；命中一次回11共鸣。无伤害递增。|
|atk_side_b / 回拨|上一击后右肘回拉、腕部小角度翻转，叉口从前向内回拨，身体轻微反扭；同一右手持续握持。|同为4帧、同一有效窗口，与A交替。按下一次J才出下一击，不能自动播放两次攻击。0.5秒未续击复位A。|只是普攻第二种姿态，不构成长连招或额外硬直锁。|
|atk_up / 挑潮|髋部下沉，右肘从胸前向上送，叉口越过头前方后朝上；左手向侧下方平衡，头壳不被骨叉穿过。|4帧/0.333秒：F1–2收叉；F3上挑有效；F4回收。|↑+J，地面和空中可用；伤害1，补足上方盲区。用↑箭头避免占用W浮游。需新增方向判定。|
|atk_down / 点潮|在自然下落中收腿，右手将叉口朝下，左手短暂扶柄；命中时手臂缓冲、身体反弹，双脚再展开。|4帧核心：F1–2转叉；F3向下有效；F4按命中分支播放回弹或回收。飞行轨迹由物理驱动，不写死自动起跳。|空中S+J，伤害1，命中敌人或显式可弹跳表面才反弹。不是主动加速坠地。|

普攻的“快”来自短预备与及时回收，“有力”来自蹬地、腰胯传递、清楚终点与约2–3个物理帧的命中停顿；不能靠全身拉伸或大范围白光遮住动作。A/B视觉交替不强制玩家站桩。挥空不回共鸣，同一次挥击同一目标只结算一次。

当前主关卡melee_reach=125、角色常见显示高94px，直接表现为短叉触碰会显得判定太远。制作时先画出明确短压波，并用debug碰撞验证波前覆盖真实有效范围；需要缩短判定时另做手感调参，不能仅靠动画缩小范围。Boss适配路径也需单独核对，不能直接套演示场数值。

## 第一组：骨鸣攻击

### S01 迎珠 · 叉鸣弹

- 用途：直线中距离点射，解决不适合贴身的目标；继承现有U键迎珠。
- 动作：骨叉竖收胸前 → 左指短促拨动叉臂 → 灯芯闪亮、能量沿红绳向握柄汇聚 → 右手向前送叉，叉间挤出一枚扁椭圆水压珠 → 肘部后坐回收。
- 首版：6帧/0.5秒；F1–2预备，F3释放，F4–6恢复；33共鸣，伤害2，沿用约583px/s与1秒CD作为起点。弹道接触实墙终止；不回共鸣，同一目标只击中一次。释放后才允许恢复段取消。
- 视觉：灰青半透明珠，琥珀色短核心，两个细小环纹；不做火球、黑色幽灵或大面积刀光。
- 探索扩展：只触发具有对应标签的远端共鸣器；不会随意破坏背景。
- 参考关系：借鉴Vengeful Spirit的前方弹道职责，动作、载体与形状按骨鸣器重新设计。

### S02 重鸣 · 涨潮环

- 用途：敌人贴近时的高承诺解围，继承I键重鸣；不是挥一次大斧。
- 动作：两膝外压、左手托住叉柄 → 将骨叉横收腰前，叉臂向外张开视觉间隙 → 双手向前下方顿送，身体由压缩到蹬伸 → 叉间产生近圆形压力环向周围扩张 → 披风滞后一拍掀起再回落。
- 首版：8帧/0.667秒；F1–3压缩，F4释放，F5余振，F6–8回收；33共鸣、伤害2、半径70px、2秒CD。每敌一次伤害，不能每帧重复结算；预备与恢复可被打断，取消时机在F7后。现有0.1秒armor属于代码现状，需专门确认其含义，不自动宣称无敌。
- 视觉：两道灰青压力环扩展，近身范围与真实伤害同步；暖灯只亮一下，避免全屏闪白。
- 可选升级：上倾释放成为“鲸息”，压力集中在头顶，适合对空；作为后续形态，不在首版多加按键。Howling Wraiths是向上及周围攻击的参考，不把它错误描述为纯全向AOE。

## 第二组：潮压机动

### S03 贴流冲 · 掠潮

- 用途：快速调整站位与穿过短空隙，沿用L/Shift。
- 动作：上身前伏、叉贴肋向后收 → 后蹼足猛蹬 → 身体拉成低平前进轮廓，披风沿背部收拢 → 前脚探出、后腿回收制动。骨叉不得指在脸前遮住去向。
- 画面：2帧起势、2帧滑行循环、2帧落地收势。实际冲刺仍按原800px/s、0.2秒、0.7秒CD起步；动作时段不强迫绑定整张序列时长，滑行结束切收势。
- 首版无伤害、不耗共鸣。当前实现已有冲刺全段无敌并可穿敌、不穿墙；本设计沿用并明确记录，不因参考Mothwing Cloak就误称普通冲刺必然无敌。
- 可选后期冲鸣：蓄力后冲刺再释放窄向压波，另做输入、成本和动画，不默认为冲刺附送伤害。

### S04 坠潮 · 沉钟

- 用途：主动落下攻击脚下敌群，与免费的点潮反弹明确分开。
- 动作：空中收膝 → 双手把骨叉竖在胸前并转向脚下，披风张成短钟形 → 身体向下加速，叉尖略低于双脚 → 接地屈膝、肘部吸收冲击 → 地表展开扁平压波 → 起身回稳。
- 首版仅空中S+U触发；33共鸣。2帧准备、2帧下落循环、4帧落地恢复；触地事件释放压力波，不能固定“第几秒落地”。空中碰敌伤害1，落地波伤害2；同一目标同次施放累计上限2。
- 前摇可受击；主动下降及触地后0.1秒设候选保护窗，恢复后可受击，需实测。前摇扣费，中断不返还；落地前不能重复施放，取消不刷新保护。无地面时按常规坠落/危险恢复规则结束，不能生成悬空落地波或免疫掉坑。
- 只击破设计标记的脆弱壳层，不破坏普通平台；首版不开新必经门，防止改变已验收路线。
- 参考关系：Desolate Dive提供“耗能主动落地冲击”的职责；点潮则继承普通下攻反弹的职责，两者不得共用自动起跳动画。[下砸资料](https://hollowknight.wiki/w/Desolate_Dive)

## 第三组：菌灯生存与探索

### S05 菌息 · 合灯调息

- 用途：以暴露站位换治疗，沿用P。
- 动作：稳住双脚，骨叉竖立贴近身体 → 左手护住密封灯罩，身体微蜷 → 灯内光点慢慢聚拢，呼吸压低 → 完成时温和亮起，角色舒展回戒备。灯不离开挂点，不出现火焰或灯笼无限拉长。
- 保留1.5秒地面引导；制作2帧进入、4帧呼吸循环、2帧结束，循环时长由计时器控制。受击中断、消耗不返还。
- 平衡提案：每次33共鸣恢复1格生命。当前主场景heal_amount=5，意味着最多一次补满5格；降至1是明确的新建议，本轮未改。必须同时验证Boss窗口与营地补给，不机械照抄其他游戏。
- 参考关系：Focus提供“治疗与攻击争夺资源”的选择。[Focus资料](https://hollowknight.wiki/w/Focus)

### S06 照见 · 骨音探潮

- 用途：读取环境线索、显露记忆骨纹，呼应拾潮者原本的观察与修复身份。
- 动作：身体侧收、抬头观察 → 左手转动灯罩外环，光束收窄 → 右手骨叉缓慢朝前，敲出一次轻鸣 → 灯光扫过已有骨纹，线索以轮廓与节奏回应 → 收叉，灯恢复基础照明。
- 建议0.75秒启动，显示标记持续约2秒；首版不耗共鸣、无伤害、无硬控、无无敌，不揭露所有未到区域。只作用于authoring标记物体；必要提示不要求先打怪充能。
- 输入待探索交互方案确定，作为独立能力槽；不挤占W浮游、G锚环与E短按交互。探索状态允许移动打断，不做长演出锁。
- 参考关系：从Dream Nail的读取/进展用途得到启发，具体输出为鲸骨回声与生态观察，不复制梦境入口设定。

## 资源、规则与现状边界

共鸣沿用99上限/普攻命中+11/主要释放消耗33作为首轮测试基线。因此单次单目标命中约三次能换一次技能；多目标命中如何回能需单独验收。法术、冲刺、环境提示与照见不回能，必要探索功能不消耗共鸣。当前受击扣33共鸣的惩罚先记录保留；若治疗改成1格后压力过大，应单独比较取消受击扣能的版本。

## 动画制作与验收合同

先做普攻A、点潮、迎珠、重鸣四个样板，测试后再做B/上挑、坠潮、菌息、照见。贴流冲可与现有动作迭代一起做。每个动作交付无特效本体和独立效果层；先确认右向，再处理左向持叉、灯与系绳镜像问题。

短攻按12FPS真实游戏节奏制作，攻击有效帧必须清楚；不把均匀慢放的6秒展示当成快攻。重技能允许慢起快落，但应有可读的受击风险。视频参考若需6秒，可安排独立的正常速度演示与慢速观察片段，标注各段时间，不能混入游戏运行序列。

沿用完整原画比例和统一根锚点；每个动作先量头壳/双手/双脚/骨叉/披风的总运动范围，再定画布，禁止每帧自动放大外接框。横扫和冲刺推荐横向宽画布，跳跃及下砸需更大纵向范围。上一批3:4视频即使写了45%占画幅仍发生裁切：下一轮需用留白充分的起始构图和关键姿势约束，不能只重复同一句“完整入画”。

上一批[攻击视频](../../../assets/source/tide-picker-attacks-v01/README.md)用途：横扫只参考腰胯与披风随动；举叉重劈作为大幅蓄力资料，不直接用作短击或涨潮环；跳起下刺作为坠潮的空中/落地资料，不能代替点潮反弹。这些源片有裁切与持物漂移，保留candidate。

验收用例（待实现后执行，本轮仅设计审阅）：

1. 持续移动中短击、挥空、停手、转向、跳跃/冲刺取消；A/B不能自动多打一击，命中与画面压力纹一致。
2. 上挑只覆盖上方；点潮命中/挥空分支不同，普通地面不反弹；与G锚环无输入冲突。
3. 三次有效普攻补一份33共鸣，技能不自行回能；零能量时探索基础功能仍可完成。
4. 坠潮触地、落敌、掉坑、斜坡、薄平台与换房中断；一个施放不能重复结算落地或永久无敌。
5. 正常角色约94px下检查所有朝向、明暗底、最大动作幅度、灯与握柄连接、源片裁切、暂停及事件时序。伤害范围图与特效轮廓同时截帧。
