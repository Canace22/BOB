# 须门遗港 v0.2 · 统一美术与动态规范

状态：planned / waiting_verification。本文件定义制作和检查标准，不声明资产已生成或效果已通过。

## 原创风格依据

优先沿用V5.2口角外伤坡、须筛和咽后流膜育窝原画及现有拾潮者形象：单镜圆盔、青色短披风、琥珀共生灯、红绳、双叉U形骨鸣器。参照手绘2D探索游戏的深度、明暗与节奏原则，保持原创角色、建筑、敌人、地图、UI和Logo。不得出现白色小骑士、虫族圣巢、骨钉、鹿角站或直接近似轮廓。

基色：深靛水域#0D2530、灰蓝组织#365563、低饱和珊瑚组织#8B635F、旧壳骨灰#B7B4A0、琥珀提示#E8B65A。可走顶边与敌预告亮度高于装饰，前景暗但不能盖掉主角动作。笔触保留墨线与哑光颜料颗粒；不要每件物体都高光锐化，避免失去空间主次。

先选R1-02完成“静帧风格板→独立模块→实际尺寸样板→镜头移动与战斗录制”再复用到其余房间。现有源图可作风格依据，不把一张完整场景截图直接当整关可玩背景。

## 空间层级

| 层 | 内容 | 建议初始视差 | 读性限制 |
|---|---|---|---|
| FAR | 巨型上颚/口腔深水；咽后用食管纵褶 | 0.15–0.30 | 最低对比，不画可站顶边 |
| MID | 须列、沉积遗迹、巨型组织褶 | 0.45–0.65 | 细节密度低于可玩层，不伪装成平台 |
| PLAY | 地形、角色、敌人、壳门、灯、机关 | 1.0世界坐标 | 顶边与碰撞一致；伤害预告清晰 |
| FRONT | 局部暗须、植物、裂壳边缘 | 1.10–1.20 | 主角/落点/敌预告附近减密或淡出 |
| FX | 雾、尘、生物、共振弧、命中、波纹 | 按归属层 | 保持粒子预算；UI在独立CanvasLayer |

视差系数为样板起点，需要实际镜头边界验收；不要重复叠加相机偏移。巨大鲸尸尺度通过跨屏连续组织、远近须列尺寸递减和主角比例建立，不把局部房间画成普通石洞。水带表示局部水流/水层视觉，不擅自增加浮力、游泳或窒息规则。

## 尺度、命名与母版

运行1U=64px，主角约64px高，推荐4倍母版制作但最终按引擎真实大小检查。图像按原始生成/source、修整母版/master、运行/runtime分别保存，来源清单记录参考、工具/模型、任务ID、提示词、版本、尺寸、alpha、锚点、SHA256、实际引用。未知来源明确unknown，不伪造。

建议命名：wf_r1_<room-or-shared>_<layer>_<category>_<variant>_v02.png；动作采用wf_hero_<action>_<facing>_<frame>_v02.png；场景同名.tscn。路径建议为assets/runtime/v02，最终实际路径以实现资产清单为准。本命名是新资产合同，不强制破坏已通过的旧文件名。

| 类别 | 交付 | 锚点与边缘 |
|---|---|---|
| 地形 | 中段、首尾、转角/破口独立PNG及对应场景 | 顶面基线；碰撞不由图像自动推断；侧缝/底部alpha无硬矩形 |
| 植物/群落 | 植株或小簇独立PNG，至少一近景/一可玩边缘变体 | 根部底中；摆动固定根部，不整株漂移 |
| 灯 | 壳灯外壳、发光区域分层，场景含光源 | 挂点或底座二选一并记录；透明边无白晕；无火焰替代微生物灯 |
| 门 | 门框、门扇/须帘、状态标记分离 | 门槛中心；开闭动画不拉伸门框；出口碰撞/触发独立 |
| 水带 | 可平铺水体纹理/法线或程序材质，波纹独立 | 水面基线；边缘连续，禁止遮住落点；物理作用另立合同 |
| 垂须 | 从上颚垂落的独立丝束及绑定/摆动参数 | 顶端固定点；不能在食管区域错误使用鲸须 |
| 可动物件 | 阻流壳、壳闩、桥段分别PNG/场景 | 壳物底中；闩轴心；桥铰点；视觉运动与碰撞时序一致 |
| 角色/敌人 | 独立动作姿势或合格序列，不烘焙进场景 | 脚底、受击中心、武器作用点；左右侧灯与骨鸣器结构一致 |

所有透明素材检查暗底、亮底、正常缩放和运动中边缘；不要保留AI伪棋盘、黑底、邻图碎片。放大原画审核不能替代游戏内64px级检查。

## 动态效果与事件

以下均为本轮待制作/待验证要求。程序实现可采用Shader、绘制、粒子、AnimationPlayer或节点曲线，但必须在Godot中实际运行；保存源脚本与参数，不能只交视频。

| ID | 效果 | 驱动/暂停规则 | 成功依据 |
|---|---|---|---|
| FX01 | 背景视差 | 相机位置；按层倍率；暂停保持 | 横纵移动与镜头极限无露边/漂移 |
| FX02 | 漂移雾 | 低频平移与淡入淡出 | 不盖落点/预告，房切换无残留 |
| FX03 | 浮动生物 | 小幅周期漂动/有限路径 | 生物与背景有独立层，非敌不误导伤害 |
| FX04 | 尘埃/海雪 | 稀疏漂移、深浅大小分层 | 数量受控，不在HUD上闪烁 |
| FX05 | 须门垂髫摆动 | 固定顶端，小幅相位差 | 只在口腔适用；碰撞与装饰分离 |
| FX06 | 灯光变化 | 琥珀色平滑呼吸/灯罩开关 | 开关与实际光照状态对应，无剧烈闪烁 |
| FX07 | 水波纹 | 接触/落地等已定义事件 | 对应位置与时刻，离房释放 |
| FX08 | 骨鸣器共振弧 | 攻击有效帧触发，轻重区分 | 不改变武器IP；无视觉有伤害、无伤害却延伸误导均需修正 |
| FX09 | 命中反馈 | 真实命中事件 | 闪色/冲击/短停可辨，不重复计伤 |
| FX10 | 死亡效果 | 单次死亡事件 | 过渡与复活衔接；退出/重试无残余攻击 |
| FX11 | 机关动画 | 壳闩false→true，桥展开 | 动画后碰撞正确；重载恢复终态，不重复奖励 |

不要提前假定Glow或HDR2D在当前Compatibility路径可用；采用经过验证的PointLight2D、渐变贴图或局部光晕，记录实际方案。当前没有默认SpotLight2D节点。震屏/闪光如新增应可控，不能用强闪代替战斗信息。

## 样板完成门槛

一个完整样板房需要同时交付：独立四层资源、可玩地形/门/灯/植物/水带/物件、原创角色/敌人、事件驱动效果、真实镜头与战斗录屏、资源来源及未完成项。通过静态图、动态、碰撞、边界、暂停/切房、性能和实际听感分别验收；不可用时明确未验证，不拿另一类证据代替。
