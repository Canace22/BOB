# BOB · 全局美术风格规范

这是整个 BOB 项目的美术指导，适用于初版 Canvas 2D、新版 Three.js 2.5D，以及后续场景、角色、道具和其他美术资源。各版本采用同一套视觉语言，按各自镜头和技术条件落地。先看下方基准图，再按制作规则检查新资源。文件存放与运行状态见[资源管理](README.md)。

## 风格一句话

**深海生态暗童话：以手绘质感表现巨鲸遗骸中的微小生命，用深蓝暗部、象牙骨架和克制的生物光，营造幽深、巨大而仍有温度的探索世界。**

“深海生态暗童话”是本次对既有设计的概括。已有依据是 [V2 设计说明](../docs/鲸腹遗城原画集/V2/游戏设计说明.md)与[生成提示词](../docs/鲸腹遗城原画集/V2/生成提示词.md)，不是新增题材。V2 是参考资料的来源，不是本规范的适用范围；已有原型与全局目标之间的差异应在各版接入时逐项处理。两版原型尚未完成统一美术验收。

## 形状、材质与画面

| 项目 | 制作规则 |
| --- | --- |
| 整体画法 | 水粉与数字绘景式手绘质感；大轮廓明确，细节集中在近景和交互处。转为 3D 时保留概括形状与哑光质感，具体着色方案通过实机样片确定。 |
| 空间形状 | 骨骼形成长弧、拱架与多孔台地；软组织形成褶皱、囊体、悬膜与拉伸连接。地形应能看出器官来源。 |
| 骨与壳 | 象牙、灰白、灰绿；磨蚀、多孔、局部附生。粗糙漫反射为主，避免全身光滑塑料感。 |
| 软组织 | 暗红褐与灰紫为局部底色，强调柔软、折叠与薄膜透光；避免用大面积血浆表现气氛。 |
| 生态 | 菌膜、藤壶、虾群与漂浮颗粒依附环境生长；疏密沿水流与营养分布变化。发光只占局部。 |
| 镜头层次 | 前景偏暗，形成框景；中景承载角色、平台与机关；远景降低对比与细节，用水雾表达深度。 |
| 可读性 | 先看清脚下、缺口、交互物与目标，再补纹理。装饰亮点不能抢过关键交互；前景不能遮住必须判断的平台边缘。 |
| 情绪 | 以尺度、幽暗、遮挡与缓慢运动产生不安；以小生命、暖灯和生态恢复保留温度。 |

## 配色与光照

以下色值为本次整理的**制作起始建议**，不是原画精确取色，也不是已经锁定的引擎参数。实际颜色需在灯光和游戏镜头下复核。

| 色彩 | 建议起始值 | 用途 |
| --- | --- | --- |
| 深海墨蓝 | `#081923` | 大面积暗部与远海 |
| 灰青蓝 | `#294B54` | 中景皮肤、环境过渡与水雾 |
| 象牙骨白 | `#C5C1A6` | 骨架、面罩与路线轮廓 |
| 克制青绿 | `#72B6AF` | 局部菌膜、生物光与流向线索 |
| 暖琥珀 | `#DDA45D` | 密封菌灯与局部视觉焦点 |
| 暗珊瑚红 | `#944F4A` | 红绳、组织与区域性点缀 |

保持冷暗大面和少量暖亮焦点。不同器官可以调整主色，但延续相同的明暗层次与材质语言。青绿既可能是生态也可能是线索，红色也可能是组织或装饰；不能仅凭颜色判断安全、危险或可交互。危险用形状、运动、颗粒等共同预告，机关状态至少改变轮廓或运动。

水下光源使用密封菌灯、生物光和微弱环境散射。原画中夸张的光束与流动仅表达方向，制作时检查是否误读为浅海阳光、雨或重力瀑布。

## 角色与道具识别

拾潮者的全局角色基准取自既有 V2 原画中的幻想两栖小生物设定：约 30 厘米、约三头身；圆润象牙白面罩、一个圆形深色观察镜片、深青短披风、左髋琥珀色密封菌灯、右手 U 形双叉骨鸣器、珊瑚红绳。左右按角色自身判断。

上述识别特征应贯穿三视图、动作图、模型和远景小人物。披风的最终长度、灯具挂点与尺寸仍需在正式角色制作时定稿；A03 的细节丰富度不要求在游戏小尺寸下全部保留。缩小后至少保住白面罩、青披风和暖灯三个色块。

道具优先采用骨、壳、膜与纤维构造，让外形解释功能：双叉用于共鸣，囊体表现压力，薄膜表现弹性。新道具必须同时给出静止、可用和触发后的状态，沿用现有关卡设计，不因制作美术扩展机制。

## 避免偏离

- 鲸体保持须鲸识别：鲸须、双喷气孔、水平尾鳍；具体空间与幻想边界以 V2 设计说明为准。
- “遗城”的空间感来自骨架、器官与生态层叠，避免泛用石砌城堡、人类街镇或骑士装备。
- 不使用裸火、全场霓虹、高饱和杂色或满屏同等强度的发光点。
- 不把骨鸣器画成三叉戟或战斗武器，不用真实人脸替代拾潮者面罩。
- 分镜里的重复人物表示先后动作；游戏背景交付时移除示意人物、箭头与版面边框。

## 制作时怎么使用

1. 明确目标版本、资源用途与实际游戏镜头；选择上面对应的基准图和已有实机参考。
2. 将本规范的轮廓、材质、颜色和角色约束写入制作简报，再添加本资源独有内容。既有[生成提示词](../docs/鲸腹遗城原画集/V2/生成提示词.md)可作为起点。
3. 先检查缩小后的剪影与明暗，再增加细节；单张漂亮不能替代放进场景后的协调性。
4. 按[资源管理](README.md)存放和登记，按[接入 Skill](../.agents/skills/bob-art-integration/SKILL.md)验证运行画面。

## 验收与当前状态

每次交付选用以下五项检查，分别记录结果：

1. **同屏协调**：与基准图或已认可实机画面对照，新资源的材质、明暗和细节密度是否一致。
2. **角色一致**：检查三视图与动作中的镜片数、叉数、披风和挂点，缩到游戏尺寸仍可识别。
3. **路线可读**：在实际镜头下检查脚下、平台边缘和目标；灰度查看时仍能区分主要层次。
4. **状态可读**：关闭声音并弱化色彩后，仍能从形状或运动辨认机关变化与危险预告。
5. **接入有效**：检查加载、比例、遮挡、碰撞及动作；验证路径不会因美术覆盖而误导玩家。
