## 美术来源与动作合同

原画主源：`assets/source/whalefall-v5-2-complete/`；复用位图保持`assets/runtime/sprites/<id>/base.png`来源。本轮另用内置Imagegen制作两张1536×1024图集，4列2行、单格384×512，原件在`images/`，生产提示词见[prompts.md](prompts.md)。运行件在`assets/runtime/sprites/completion-19-v1/`，不通过程序绘画替代角色资产。

- 鸣贝：脚线在每格y393，pivot为(192,393)，身体宽约340px；按tell/act/recover切帧，全部八帧已在真实AI中出现。故障回退沿用原静态图，仅作故障显示。
- 幼体：身体尾膜八相位循环与群体路径分开；固定六个实例，暂停冻结，读档恢复实际ending状态。首稿外缘柔光返修后仍有轻微光晕，运行90px尺度已复核，不宣称完美Alpha或用户已认可。
- 心肌、骨壁、菌床、壳营、居民是静态绘画；水流、门态、膜类与群体使用已授权程序驱动，贴图来自台账。

图集技术接入和用户美术签收分别记录；当前仍为候选美术。无Boss难度终验、跨设备性能保证或新增音频交付。

## 复跑与资源保护

在仓库根运行`node assets/source/completion-19-v1/apply-recipes.mjs`（幂等内容配置），然后`node game/tools/build_world_rooms.mjs`；新素材先登记`register-assets.py`再生成。图集不缩小，静态fallback单独用`fallback_max`。同一输出纹理的各消费者必须使用相同缩图规格，生成器会拒绝冲突；声壁前态使用`before_max:1280`，与远景引用一致，避免错误放大。已有Windows/Linux Lanczos输出可能像素不同，不能为本轮两张新图全量重制旧运行PNG。本轮同步后已恢复12张非本轮重绘的旧PNG；后续同步应先比较旧资源，避免以重采样差异冒充美术改动。

新增中文后按`assets/source/noto-sans-sc/README.md`重建字体，并只同步字体/本轮新增项。运行证据和依赖仅放`game/build/qa/completion-20261114/`，不入游戏包。保持真实存档不变，各专项有独立QA档。

## 验证入口与限制

- `node tools/godot.mjs check`、`test`：脚本/资源导入及当前105项单元测试。
- `tests/whalebelly/completion_19.gd`：18项真实场景检查；显式房间位置/进度夹具，检查资源、八帧、潮压水流、三槽与幼体；不是自然取得能力的证据。
- 同上加`-- --motion`、引擎`--fixed-fps 60`：每两个物理帧捕获一张，输出鸣贝180帧、幼体池/归海各90帧，按30FPS编码为连续实机短片。仅检查动作和路径，不用于性能统计。
- `tests/whalebelly/kit_conversation_qa.gd`：物理E/Esc/Enter、居民间移动、暂停与松键恢复、旧房对象释放；解锁骨音文字为只读布局夹具，不发放能力。
- `tests/whalebelly/world_skeleton.gd -- --endgame`：原输入走后段三Boss及导流闸，先验证实际伤害再使用明确无敌夹具测流程，不宣称难度通过；`-- --reload-endgame`顺序验证新进程恢复。
- `tests/whalebelly/doorways.gd`：首区14门与营地回归。用正常时钟运行；无界固定FPS加速时音频排空计时不是墙钟，曾报告退出音频引用，正常时钟复跑无错误。
