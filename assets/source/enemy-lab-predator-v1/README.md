# 膜上捕食者动作样板

用于统一敌人试验场ED-05，具体物种仍为候选，不表示正式剧情形象定稿。内置image_gen参考已入库大甲图集的线条/手绘材质，独立绘制紫灰三角体、上抱膜钩肢、薄膜与细腿，不借蟹变形。

原图membrane_hunter.png，1536×1024透明RGBA，4×4共16个关键姿势：首行为挂膜/换握/回挂；其余三行为斜扑、贴膜掠过、收肢重坠的准备/蓄势/有效/落地姿势。完整生成提示保存在prompt.txt。不是16帧行走动画，也不是已通过用户审美验收的流畅动作。

atlas.json保留16个Alpha≥32主轮廓区域，加4像素余量，不改原始像素。统一参考高度214、名义根X192、各帧最下支点为pivot；运行等比缩放到85px高，不逐帧等高拉伸。原图、runtime和game文件SHA256相同。合并运行索引在../enemy-lab-readability-v1/atlas.json，实际新图的源路径在各记录source字段。

静动分工：角色肢体和招姿用本套位图；红光为试验场本体Shader，只用于不可挡前摇。挂点、遮蔽顶盖和地面仍是标明的白盒几何调试设施，不是正式环境美术。正式膜面尚未制作，本轮不扩环境生产。

可用动作已接入真实起手、锁定飞行路线、物理落地、可控窗口和回挂。回挂复用首行换握样板，尚无专门高帧数飞行/受击/失能动画；失能存活仅白盒结果，不决定正式死亡/逃逸。实机证据在game/build/qa/enemy-lab/hunter-*，仅本地保留。
