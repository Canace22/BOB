# 连招、转阶段与胜利特效 V1

为母蟹独立训练场补充 8 组透明序列帧，共 32 个绘制相位。玩家、母蟹的身体动画与伤害数值不变。借鉴清楚、克制的冒险游戏提示节奏，采用 BOB 的骨壳、生物光与配色；没有复制《塞尔达》的素材或文案。

## 源与导出

- `originals/player.png`、`originals/crab.png`：内置 image_gen 生成原件，真实尺寸 1254×1254，保留 Alpha。完整提示词见 [prompts.json](prompts.json)。生成前查看训练场实机截图并按[全局风格](../../art-style.md)编写简报；截图未作为图像输入传给模型。
- [export.py](export.py)：按已查看的等格边界 `[0,314,627,941,1254]` 裁片，统一加 `(3,3)` 留白至 320×320；无逐帧包围盒缩放，不重绘、不生成补间。
- 各动作 `platform/projects/*.framecraft/`：实际 Framecraft 工程；`platform/exports/*.zip` 为平台实际导出。每个工程保存后重开并核对 PNG 字节、帧数及帧率。
- [export-checks.json](export-checks.json)：明确裁框、公共锚点、Alpha≥32 的边界及像素哈希。游戏图集为 `assets/runtime/fx/combo-v1/*.png`，1280×320、横向四帧，公共中心 `(160,160)`。

复跑：`python3 assets/source/combo-vfx-v1/export.py /path/to/installed/sprite-workbench`，需要已运行的 Framecraft 8765 服务与其 Node 依赖，再运行 `node tools/godot.mjs sync-art`。透明阈值与锐化均为 0，原尺寸保留软边。帧表按真实输出裁切，工具默认 `loop:true` 不传给游戏。

## 实机播放

| 序列 | 使用位置 | 时长 / 画布宽度（世界像素） |
| --- | --- | --- |
| short1 / short2 | 玩家轻击下扫 / 回挑，命中窗口启动 | 0.20 秒 / 100 |
| heavy | 玩家重击，空心共鸣弧 | 0.28 秒 / 160 |
| hit | 母蟹有效受击（近战和远程），固定世界接触点 | 0.24 秒 / 80 |
| short2 / heavy 复用 | 母蟹护壳弹刀 / 触发破防 | 0.16 秒 / 48；0.45 秒 / 155 |
| sweep | 母蟹低扫地面痕迹 | 0.32 秒 / 220 |
| slam | 母蟹下砸骨屑 | 0.40 秒 / 260 |
| charge | 冲撞每移动 42 像素产生一团尾尘，最多三团 | 0.38 秒 / 160 |
| resonance | 开场、二阶段、三阶段 / 玩家胜利 | 0.48 秒 / 145；0.90 秒 / 220 或 295；1.60 秒 / 190 |

母蟹连招最后一段仅将地面效果放大 8%、透明度从 0.48 提至 0.60，不增加伤害范围。母蟹尘屑置于身体后层，进入下一段前摇即清除；二阶段为青绿小圈、透明度 0.42；三阶段为琥珀大圈、透明度 0.58，胜利为 0.72。玩家轨迹透明度 0.64–0.72，接触爆点最高 0.85；母蟹打中或碰到护盾时也在玩家受击体边缘溅出小片琥珀壳屑；攻击取消、受伤、冲刺和重试清理轨迹。所有播放继承世界暂停/顿帧，命中爆点不跟着目标滑动。

阶段提示在既有提示区域内只显示短阶段名，下一招恢复原躲避提示。胜利在既有顶部 HUD 内显示“潮声为你回响”“做得好，你找到了破绽”，失手则给出下次反击建议并播放一小簇消散的冷色微光。保留胜利耗时和 Enter 重试，无虚构道具奖励。

## 验收边界
