# 连续世界设计原画 · 2026-11-04

依据现有V5.2的36房39边及当前R1七房工程，衍生6张连接导向概念原画。浏览入口：[连续世界原画册](../../../docs/鲸腹遗城原画集/连续世界设计/原画册.html)。

- `images/`：6张内置image_gen生成的正式概念原图，不直接进入Godot导出。
- `prompts.json`：每张完整英文提示词、原参考路径和用途。
- `generation.json`：生成工具及默认原件位置；工作区内副本为正式交付。
- `inputs/`：地图拓扑、解剖位置、房级设计、当前工程七房门点快照，哈希在`connections.json`。
- `connections.json`：36房、39边、门槛、开闩侧、跨屏地标、材质过渡和接缝合同。新连接带在既有边内部展开，不新增边或房。
- `art-manifest.json`：原图尺寸、SHA256和逐图视觉结论。

工程入口为`game/project.godot → content/whalebelly/main.tscn`。七房的门点与目标出生点属于不同局部坐标，不能把画面直接拼为同尺碰撞地图；R1章末/远侧闩仍是原占位。R2–R5是已有设计，不能称为本轮实现。

本轮仅做新原画与制作设计。图中器官经过构图压缩，不作为医学剖面或碰撞测量。角色只作比例示意，正式角色身份继续以全局规范和已接入主角为准。

## 复跑与接续

在BOB根目录运行`node tools/build-world-continuity-book.mjs`重建图册和逐边文档，再运行`node tools/verify-world-continuity.mjs`。默认复用首次输入快照，不覆盖后续手工原画；设计源变化时新建版本并核对39边差异。

后续优先制作E02接缝样板：复用须筛/舌台合格原件，补连接侧坡、共同颌骨远景和前景遮镜，保持能力/存档ID。真实启动、双向过门、摄像机边界和角色落脚验收通过后再扩展E03/E04。0.5屏补底、共用地标坐标、切房时钟相位均为待实测的建议。

## 视觉复核与边界

已查看6张实际生成图：器官分区、首章主路/上层口袋、三段连续台面、腹腔到椎旁上/下合流、耳头/尾根分离可见。精确房间连通以清单为准，原画不是逐像素路网验证。

03图的横膈通行破口与食管裂孔仍偏概括；05图的耳骨周围尺度经过艺术压缩、下幅三槽闸形状未逐槽工程定稿。可用于宏观衔接讨论，进入对应房间美术生产前需依合同补局部节点图。新方法未经过引擎样板，不写成通用Skill已成功配方。AI视觉审查不等同用户美术定稿。
