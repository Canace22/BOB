本次继续同一个 Godot 4.7.2 工程；原图定构图，MP4定局部运动，GIF仅参考分层镜头关系。

## 打开与编辑

- 场景总入口：`godot/WhalebellyRuins/scenes/environment/motion_preview.tscn`，F6。固定镜头，**C** 切换小幅镜头运动，**空格**暂停。角色保持展示姿态。
- 单类效果：`scenes/environment/element_gallery.tscn`，F6，左右键切换5组效果、空格暂停。
- 主关卡：F5；R1-01继续共享`xumen_reference.tscn`。既有角色移动时镜头平滑跟随；Tab切换全景/跟随，其余房间沿用旧逻辑。
- 独立动件：`scenes/environment/elements/*.tscn`，Inspector调节period/phase/amplitude_px/intensity；素材在`assets/motion_elements/`。布局在`xumen_reference.tscn`。
- 布局母版：[master/editable-layout.svg](master/editable-layout.svg)（同目录PNG不可搬散）；动画母版是Godot分件场景、Shader和鱼帧图，SVG只记录静态布局。垂须动画母版现为../baleen-blender/blend/baleen-painted-animation.blend。

## 实际制作内容

100个元素/装饰簇/发射器合同；48条逐鱼实例，各12帧摆尾图集；6片固定根部与4组Blender垂须帧动画；4植物、4垂藤；4个气泡发射器共36实例；3束光、1灯、1层顶部背景水面；连贯前景与遮挡补绘。静态洞顶、道路、侧壁、洞口和装饰继续保留原图像素。

鱼：原图裁切后注册根点，Godot原生重采样制作12时相尾摆，身体尺度不变；区域缓游与边缘淡出回收是独立路径逻辑。不是手绘逐帧，也不是整簇图片横移。
垂须：当前为Blender导出的4组72帧/12FPS/6秒动画；6片固定根部不动。植物仍使用独立透明贴图与根部权重Shader。制作与验证见[Blender垂须母版](../baleen-blender/README.md)。
水面：提取原底图顶部(350,0,740,150)，独立透明蒙版与10秒局部折射，z=-55；垂须、洞顶、中景骨架遮挡水面。原CAUSTIC-01/02已退出运行场景，旧贴图留作制作历史。光束和灯继续独立变化。
前景：独立整片暗色框景，避免3块分开运动时接缝裂开；小幅镜头保留裁切余量。远、中、可玩、前景有不同视差响应。

## 重建与接续

先运行`BOB/tools/build_motion_elements.py`准备输入，再用固定Godot执行`--headless --script res://tools/motion_elements/export_assets.gd`原生导出；随后`build_motion_elements.py --assemble`组装、Godot导入、补充运行`--headless --script res://tools/motion_elements/extract_water_surface.gd`生成水面资产；运行`tests/motion_elements_qa.gd`与`tests/motion_loop_render.gd`。不要用旧reference_environment生成器覆盖新装配。
该流水线保留原件、生成底图、SVG遮罩、PNG母版、JSON坐标和元素场景。后续美术修正按ID定位，独立预览通过后回总场景复测。

修复记录：原生导出类型推断修复；收窄前景补绘范围；同步转身改为持续游动；垂须增加透明余量并把侧壁像素归固定根片；修正焦散alpha重复乘法导致动态过弱。
