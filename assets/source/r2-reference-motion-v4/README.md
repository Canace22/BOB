## 复跑与经验

当前配方仍是`game/content/whalebelly/world/recipes/R2-03.json`、`R2-04.json`；新增reference_background、background_schools和framing.motion均是视觉字段。生成仍用`node game/tools/build_world_rooms.mjs`；四件图片选择性sync，避免全量重采样旧素材。`import-assets.py`、`prepare-layout.py`为本批制作脚本，继续人工编辑后勿盲目覆盖。`make-preview.py`编码已录制帧，`verify.py`只读校验并写QA结果。

复刻应先匹配器官大形、红蓝分布和光向，再分离需要运动的对象；全图水波不能代替分件。采样附肢动作时冻结群体位置，采样群体路径时单独看位置，避免把贴图平移说成游泳动作。暂停树中直接切相机做截图时，必须同步Parallax偏移和camera scroll；否则会出现正常游玩没有的空角，不能为修测试夹具而错误移动背景。固定预览要锁定viewport相机矩阵，主动force_draw以免全暂停场景停止调度重绘，并显式释放逐帧Image；最终48项含相机矩阵固定检查，退出无资源错误。新时钟的登记和默认关闭让新房增量制作不接管其它房的既有动态。
