# 本批返修与适用边界

1. **旧图层被重新显示**：房间文件隐藏旧图还不够，主入口`update_layers`会覆盖。修正实际入口的可见性所有权，确认`World`中原演员/碰撞仍显示，替换的总图不显示。
2. **扩边缺底/条纹**：RGB原图与RGBA画布格式不一致使原生`blit_rect`失败；统一格式后填充。扩边只供内部镜头余量，按原画范围裁切显示，避免窄画幅两侧露出重复像素。
3. **水光矩形边界**：复制矩形水片再改变亮度会显出四角。改为独立柔边水域蒙版驱动远景材质，水体仍只有一个像素所有者；不把整幅场景UV扭曲。
4. **柔性选区夹入硬物**：矩形+色彩选择不够。用原图层/演员所有权和锚环排除区剔除硬物，再按手工根线固定附着端。记忆袋台底长支撑属于静态簇，独立保留，不强制变形。原件和SVG/根线均保留，不重新生成合格主图。
5. **循环误判**：对比整帧时，角色待机/敌人继续变化会污染结果。环境单件循环对比冻结无关演员，保留实际图像对照；整体播放另验，不因像素闭环就声称审美通过。
6. **旧回访巡航不适配现控制器**：旧脚本每帧先松跳，无法表达长按、二段与浮游；到点过早或自动过门也会误判。现`chapter_branches.gd`保持输入和落点恢复时序、用门事件区分真正过门与死亡回档，并在需要时先走外侧跳跃通道。没有调整玩法、门槛和碰撞来迎合测试。旧失败保存在`revisit.log`、`branches.log`，新37项在headless及原生GPU均通过。
7. **性能数据被截屏/导入停顿污染**：逐房验收中的采样只作诊断。独立预热后、不录制/不读回图像的性能样本单独保留，和R1-01基线比较；不把录制速度当游戏FPS。
