# R1 后续六房 · 分层场景与环境动态

以现有七房设计、原图与运行数据为准。本批只补齐R1-02至R1-07的环境分件和动态，保留R1-01已认可表现、角色、地形、门、机关和能力限制。

顺序：02须筛 → 03舌台 → 04负壳蟹 → 05流膜育窝 → 06上层回访 → 07记忆袋回访。06的旧显示名“喷气孔上层”沿用稳定房间数据；其解剖位置按设计修订为颅侧旧伤/鼻道外侧，不新增鲸脑玩法或呼吸机制。

## 文件与工具

- `chapter.json`、`master/<房间>/elements.json`：逐件ID、区域、层级、方法/备选/理由、动态、碰撞、声音及恢复规则。静态装饰按连续簇记录，不要求每根珊瑚都运动。
- `originals/`：原图、原去角色图与既有远景原件；原来源不覆盖。
- `generated/`：内置imagegen清理画死的鱼和圆形气泡，保留平台与器官；生成记录在`generation-record.json`。不是将生成成功当作场景验收。
- `master/<房间>/*-mask.svg`：可编辑选区。原像素由Godot原生SVG/Shader/纹理工具拆分；未程序绘制替代地形。
- `master/<房间>/*-layers.ora`：分层OpenRaster母版，可由Krita等打开；本批采用文件工具打包，没有声称人工用Krita重绘。
- `assets/runtime/sprites/r1-chapter-scenes/`：带透明通道的静态层、柔性簇、灯及水域蒙版；每层16px边缘余量、动件12px透明余量。
- `game/content/whalebelly/environment/chapter/`：可编辑场景；主关卡房间实际实例化。旧碰撞和演员节点保留，旧静态总图隐藏。

## 制作与取舍

先静态分层，再接入动件。每个动态像素只有一个绘制所有者：从静态层剔除柔性物/灯的原像素，再用独立资产还原；远景补底处理其暴露区域。鱼/气泡烘焙副本清理，旧程序鱼群/气泡关闭。

柔性物首选12×24网格 + 手工附着根线/固定带 + 向末端延迟的周期曲线；保留裁片纹理，水流幅度克制。按静态层、演员掩膜与锚环排除区去掉夹入的硬物；历史ID“R1-07-BALEEN-4”实际是台底支撑，独立保留为静态件。备选Krita逐帧/分段骨骼；大扭转和遮挡不在微动网格的能力内。鱼沿用既有32相位游动图集，身体帧和24秒局部路径分开；背部小鱼低对比，不新增鱼类或玩法。气泡复用透明位图池，预热分布、边缘渐隐、固定上限。灯只调暖色发光部分；水光由独立水域蒙版和材质作用于远景，不移动地形，也不在道路上画波纹。

全房间只有一个可暂停环境时钟。旧主场景仍管理玩法；舌台承重膜的位图下沉绑定原机关数值，避免只动碰撞或只动画面。前景响应相机，保留现有跟随开关，不绑角色位置。

## 接续与验收

以`game/progress.md`记录的当前房间和阶段为准。证据仅本地：`game/build/qa/r1-chapter-scenes/`。AI技术验收、实机静帧/播放审查与用户审美分别记录。房间加载/镜头测试不冒充整条路线，主线另跑原连续输入路线。

本批已完成六房本地接入。`pipeline-state.json`保存通过状态、证据与已验收文件哈希；`runtime-index.json`登记64个RGBA导出；`node tools/audit-r1-chapter-scenes.mjs`可只读核对原碰撞、门、资源绑定和同步。修改母版/根线后将对应房间置为待复验，不整批重发图像生成。当前技术通过不等于用户已审美定稿；完整Web包体另有发布问题。

导出：`Godot --path game --script res://tools/export_chapter_environment.gd -- R1-02`（指定房间）；随后 `node tools/assemble-r1-chapter-scenes.mjs R1-02`、素材同步及实际GPU验收。已有合格资产不重复调用imagegen。`build-r1-chapter-scenes.mjs`仅建立初始规格，后续不要重生成覆盖编辑母版。
