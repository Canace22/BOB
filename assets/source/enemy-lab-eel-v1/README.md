# 缠巢鳗头尾动作样板

参考现有 `assets/runtime/sprites/blind-eel/base.png` 的软皮、牙颚与灰紫手绘材质，使用内置 image_gen 生成1536×1024透明图集。完整提示见 generation-prompt.txt；原始生成图和runtime/game副本保持相同RGBA。不是对已有鳗做精确抠图。

4列×3行共12个关键姿势，依次为游动四帧、扑咬准备/蓄势/出手/恢复、扫尾卷尾/抬尾/扫出/落尾。以384×341格取样（末行342），共同pivot X为192，Y按原画腹侧落地支撑线登记（222～236），避免扫尾行整体悬空，统一0.8倍呈现，横向约280px，身体不因每帧包围盒缩放。源Alpha零值区保留原隐藏RGB，不以生成预览背景判断透明度。atlas.json登记每格Alpha32包围盒，游戏中另核对接地、尾端判定和头部朝向。

这是两招四关键帧动作样板，非高帧流畅动画，也没有拖行动作。状态candidate，待用户实机认可；未替换主线敌人。
