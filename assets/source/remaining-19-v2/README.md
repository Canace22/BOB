## 创作边界与经验

余索、贝驮仍为静态驻留交谈角色，没有新造行走、理索或递物动画；已有鸣贝／幼体八帧不是本批新制动作。原画洞壁／拱肩／垂带可继续细化，本批利用真实原图和现有分件建立层次，不声称逐像素还原所有原画建筑。候选与历史差异见reviews，不能把审查建议当成已实现。

验证经验：远图从透明器官切片换为完整绘画时应替换同源层；整房全景和跟随镜头要分别配准覆盖范围。台腹在局部跟随镜头可能完全在画外，应先用全景GPU差分证明渲染，再用游玩镜头检查遮挡，不能把“当前镜头像素差为0”直接判为素材失效。居民截图避免玩家与NPC站同一点，使用仍在交互半径内的分开站位，才能辨认身份／工作位。
