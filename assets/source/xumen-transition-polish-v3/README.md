# 须门过渡结构再精修 V3

[当前图册](../../../docs/鲸腹遗城原画集/须门遗港精修设计/原画册.html#real-scene)。2026-11-06，在六处接缝V2基础上，解决淡出悬空的骨梁、上下层矩形空白和多层透明混合。

本批4张新补绘＋2处既有画面的随形收边；5次内置imagegen调用，其中E02首次意外添加横梁，保留候选后定向去除，未把它作为新路线接入。不是6张新画，不是游戏功能更新。

| 接续 | 处理与保留 |
| --- | --- |
| E01 | 斜梁末端实接左侧骨柱；下方低位主路与原高台保持 |
| E02 | 高低两层接口整理，远骨退后；删除生成意外带入的中间横梁，保持开敞空间 |
| E33 | 仅截取新画中上层底部与须筛洞顶之间的封闭承重组织；沿用V2清晰的上行阶台，不重画整条攀爬壁 |
| E35 | 仅补记忆袋下壁与舌台上方的非可玩结构带；记忆袋四环、三落脚台、两沟和奖励由原图保留 |
| E03/E04 | 复用V2原件，不新增生成；以拱口和组织轮廓控制叠合边缘 |

新增骨壁是封闭的非可玩填充，不增加房间、门或捷径。七房六边、主路径、核心平台和原角色/敌人保持，原房PNG没有覆盖。大方图生成件只提供结构区像素，不能整张替换原房。

输入为实际V2浏览器组合截图，位于 inputs/；原始输出复制到 images/，生成记录及完整英文提示词见 [generation.json](generation.json)。模型名未公开，未新增第三方付费调用。尺寸、完整哈希与复用关系见 [art-manifest.json](art-manifest.json)、[input-manifest.json](input-manifest.json)。

母版为 ../xumen-reference-panorama-v2/原图保真全景.svg，保留所有房图、V2层和本轮6层；specs.json记载世界视口和随形路径，render_polish.py生成约10个世界像素的边缘羽化，不做整场景模糊或地形变形。V3上层大画补绘曾因覆盖过宽降低阶台清晰度，后缩到结构带，保留V2阶台。

图册支持“本轮结构精修”开关对照上一版，以及原拼接对照。静态审核与限制见 [acceptance.md](acceptance.md)。本批不进入运行资源清单，不代表Godot接入、动态或通行验收。

恢复：先读 progress.md，再运行 register.py 和 ../xumen-keyart-v2/build_atlas.py；验收命令 `node assets/source/xumen-transition-polish-v3/verify.cjs`。capture.cjs仅第一次保存参考，已有输入不会覆盖。不得重新生成合格房间。
