# 缠巢鳗 · 潜地与布卵动作样板

参考 `../enemy-lab-eel-v1/nest_eel.png` 的身份和材质，用内置 image_gen 生成1536×1024透明16格补充图集。完整提示在 generation-prompt.txt；原始PNG、runtime与game副本保持相同RGBA与SHA256。不是对旧图精确抠帧。

前三行各4关键姿势：钻地/隐入土脊，露头/蓄势/扑出/恢复，鼓喉/蓄卵/吐出/回气。第4行是4个独立道具：完整卵囊、鼓胀裂膜卵囊、胀裂碎膜、土脊；不能将4个道具计为鳗的连续动作。补充动作仍为12个关键姿势样板，非高帧完整逐帧动画，状态candidate待实机认可。

角色帧按384×256取样，统一0.8比例、X枢轴192，Y按腹侧/泥面接地线登记，不逐帧等高缩放；与原头尾12帧共存。atlas.json登记Alpha32包围盒与prop独立区域。完整和鼓胀卵使用同一比例（完整高度30px），胀裂是独立特效按实际96px攻击宽度呈现，不能把它当同体等高缩放。原Alpha与透明区隐藏RGB均保留。

土脊随真实地下路线移动；卵按抛物线落地，最后0.55s换裂膜图，落地1.25s胀裂。它们是入库位图由程序驱动，不是程序几何绘制。正式环境场景与真正幼体动画未制作，本批不涉及拖行/居民剧情。
