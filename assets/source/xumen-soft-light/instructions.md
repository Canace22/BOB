# 光束棱角定向修复
输入：用户圈选图、BEAM-01/02/03与ENV-DEPTH/UNDERPAINT；Godot4.7.2唯一工程。
1. 实际渲染旧版本与隐藏光束版本，在相机偏移±128px下定位多边形接缝。
2. 还原被旧光束裁片切开的背景，保留前景与中景视差。独立制作透明柔光素材，不包含骨架/洞壁/须丝。
3. 接入独立光效场景，缓慢变化、柔和收尾，不平移背景纹理。
4. 运行镜头两端、隔离光效、暂停循环与原环境回归；录制实机视频、重新打包并启动。
5. 保存源图、母版、运行资源、来源和限制，更新原交付页并提交本批修改。
工具：Godot原生图像处理、内置imagegen制作独立绘画光效、FFmpeg编码。生成失败保留记录，不无限重试。
