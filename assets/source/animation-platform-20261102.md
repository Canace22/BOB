## 登记与验收范围

本批登记在 [资源台账的候选批次入口](../catalog.md#动画候选与平台处理)，保持 `not-integrated`。`catalog.json` 当前单件样例以静态图片、尺寸、单张文件及接入状态为中心；本批包含带已知缺陷的动画序列和平台工程，暂不把它们登记成已接受或已接入的静态资源。游戏清单、正式加载器和现有静态素材未被本批替换。

已执行的技术检查包括：

1. 原时间线、PNG 数量、文件顺序、FPS、画布与公共根部换算。
2. 实际平台 API 输出与 PNG ZIP 逐帧字节核对，图集 Alpha 和可见颜色核对。
3. 平台工程保存后重新读取，恢复帧数、播放模式和压缩结果。
4. 全帧透明边缘、空帧保留检查；对代表帧记录仍存缺损。
5. 双钳重砸及左右玩家候选的真实 UI 单次停止、重播、关键帧点选和原图/处理结果对比。

这些结果证明文件与播放控制可用，不能替代用户对动作自然度的判断。完整左右动作与游戏接入完成后，还需按实际按键检查进入/退出、受阻、转向、攻击命中时点、回待机及碰撞对齐。

## 复用方法

平台调用脚本与参数已保存在两批源目录，详情见各批次 README。动画主流程继续使用全局 `2d-sprite-animation` 技能及其 Framecraft 工作流；本项目素材技能只保留入口，不复制平台规则。已有姿势的压缩/导出与新姿势制作分别记录。
