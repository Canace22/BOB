旧整幅裁片在新的纵横比中会露出矩形边与烘焙水色。因此框景按等比扩展预留相机余量，原中景的侧壁下沿渐隐，透明边缘软化；没有拉伸原画。前景不再仅剩最底部的一条暗线。它在没有行走遮挡的区域保留完整近景，在真实平台附近做局部透明避让。环境像素与碰撞职责分开。

鲸须继续用原帧图集或固定端网格。R1-02、03、04、07上方动件按原export-map坐标与13列根线配准；育窝、喷气孔的旧路面垂藤改挂在实际新平台下方。原R1-07低处第四片鲸须属于旧道路，未悬空复制。鱼群、气泡沿用已有素材和统一可暂停时钟。

修复了`ChapterPinnedBitmap`的根线设置：原来恰好有13个值时没有传给Shader，现在真实传入。新增回归直接检查Shader收到的根线，避免仅有导出参数、实际未生效。
