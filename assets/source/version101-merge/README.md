# Version1.0.1 合并资源来源

本次将 `codex/combat-whitebox-backstep` 整支合入 `Vesion/V1.0.1`，以主干七房新布局为默认，重新制作连续母版。

主干三个阶段提交仅带 `game/` 运行副本，27条manifest源路径缺失。本批严格逐字节复制其已提交PNG回manifest所列源位置，逐条见 `recovered-runtime.json`。这些是可复现同步的运行像素恢复，不是原始分辨率原画或未提供的制作工程；不将其它未跟踪的原工作区资产带入。

新制作的母版与22张重绘另见 [world-terrain-v2](../world-terrain-v2/README.md) 和 [world-seam-repaint-v3](../world-seam-repaint-v3/README.md)，其中保留新输入、提示词、候选与哈希。验证结果记录到 [game/progress.md](../../../game/progress.md)。
