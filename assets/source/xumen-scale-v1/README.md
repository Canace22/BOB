# 外伤坡 · 巨鲸尺度

用户指定须门遗港地图左端的外伤坡（R1-01），希望鲸显得巨大、主角显得微小。本批只改该房间的背景、镜头与右侧门表现。

## 制作与接入

- `oral-depth-original.png` 是内置 imagegen 新绘的口腔远景，完整提示词见 `generation.json`。原图 1672×941，运行副本为 `assets/runtime/sprites/xumen-scale-v1/oral-depth.png`，清单等字节同步。
- 大颌骨延伸出画框，中央保留深水空间，远处须帘降低对比。原图等比显示并留出视差余量，没有把横图拉成长柱。
- 移除三块旧中景骨柱。旧深景中的前景细节继续使用原 PNG 和原坐标；仅旧深景与左侧第一片鲸须根部使用水色透明蒙版，限定开放水域、保护顶部结构。骨路和其他静态图保持原像素。该蒙版不作用于整屏、角色、鱼群或植物动画。
- 远景视差系数从 0.14 调为 0.06。R1-01 跟随镜头设为 0.88；其他房间默认仍为 1，镜头继续受房间边界约束。Tab 全景规则保持。
- 三组近处鲸须、鱼群、植物、气泡与光效沿用；旧远处鲸须降低不透明度以融入深景。新背景本身是静态绘画，不登记为新动作动画。
- 右侧通往须筛的通道使用已有 `doorways/tunnel.png` 独立显示内景，高 200、等比缩放。门槛上缘按画面中心下方的实际坡面贴地，不使用旧门点高度作为美术底边；避免横在角色腰部。保留向右穿行和 E 进入两种已有方式。

## 静动判断

| 元素 | 判断与原因 |
| --- | --- |
| 巨型颌骨、口腔深景 | static；硬结构，以绘画透视和小幅视差表达距离 |
| 骨路、墙、门框 | static；保留碰撞对应的原坐标，不随水流摆动 |
| 近处鲸须、植物、鱼群、气泡 | motion；沿用已接入动作和生命周期 |
| 旧深景的前景残片 | inspect → static；原图混有水色，不能整层删除 |

## 返修与边界

直接移除旧 ENV-DEPTH 会丢失路缘珊瑚和右侧门框，并暴露裁片边界，已撤销该做法。生成式透明提取保存在 `foreground-extraction-original.png`，但因黑色切口残留与配准误差未接入；提示词和拒用原因见 `foreground-attempt.json`。正式版使用原裁片的局部水色蒙版，不使用失败图。

中途曾按“鲸腹”理解发起另一张图；用户随后更正并确认地图位置，该稿未入清单或游戏。

没有新增房间、碰撞、能力或存档字段。无新增缺图替代机制；背景或门图缺失仍须修复资源，不能将缺图状态当作完成。

## 复验

1. `node tools/godot.mjs sync-art`、`check`、`test`。
2. 原生 `tests/whalebelly/ground_contact.gd`：左右走坡、跳跃、旧存档落地。
3. 查看左右边缘、坡顶、全景和门前画面，检查底图露边、前后遮挡与角色可读性。
4. 真实键盘走外伤坡→须筛→外伤坡，验证 E 和向右穿行、暂停及恢复。
