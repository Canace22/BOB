# 血巢潮群 · 玻璃虾与卷潮 V5

2026-11-16，按用户本轮原画重新设计单虾，再制作群体运动与特效。主参考为 `18_R2-04.png`，用户附件内容与该构图一致。旧的橙色硬壳个体、团块中心和随机抖动不再用于此 Boss；普通端足群及背景生态保留。

## 单虾先行

单虾是内置 imagegen 参考补绘，**不是原画精确抠图**。珊瑚红的短圆头胸、单眼、五节珍珠色腹甲、冷蓝尾扇、细足和短触须，优先保证游戏约56px总宽时的色块和轮廓。源图原件在 `images/`，同字节库副本在 `assets/runtime/sprites/bloodnest-animation-v5/`；尺寸、Alpha bbox、SHA见 [assets.json](assets.json)。运行副本由配方／sync-art等比缩至最大512，不把缩小副本称作同字节。

原件两次生成：

- 单虾：`exec-3426f2cf-84f0-4cb1-8e38-74e20035cfd1`，带本轮原画参考，transparent=true。
- 水丝：`exec-08fce790-3254-4441-aa84-f39a7f2ed20c`，独立透明位图，transparent=true。

完整制作提示词存 [prompts.md](prompts.md)。没有新增外部收费服务、视频模型或模型训练。`register.py`只登记原件度量与来源；源图不得覆盖旧V4素材。

## 元素与选型

| 元素 | 判断／依据 | 制作方法与约束 |
| --- | --- | --- |
| 单虾 | motion；原画可观察到分节腹甲、细足、触须，但静图不能证明动作周期 | 独立位图；群体类生物按项目允许边界用局部Shader摆足、尾扇与触须，眼与头胸保护；不是逐帧动作 |
| 群体 | motion；原画呈开放的卷潮，流向为本轮设计推断 | 44固定实例沿三股错层的开放水路游入、卷曲、淡出；循环入口预热，隐藏处回收；避免刚性的闭合花环 |
| 中心个体 | motion；替代旧团块中心的视觉选择 | 同族小个体，独立微游与呼吸，不新增女王、弱点或战斗阶段 |
| 水丝 | motion；原画可观察到蓝白流线 | 6条开放流线，Line2D只承载已入库透明位图；沿同一水路延展，薄而低透明，不画纯色几何代替素材 |
| 微泡／光屑 | motion；原画有微泡、暖冷反光 | 复用库内bubble与soft-particle，12微泡+14光屑固定池，有界渐隐，独立于伤害 |
| 场景／地面／HUD | static或保留原动态 | 本轮不改背景、平台、碰撞及UI；不用全屏扭曲制造运动 |

## 群体运动

待机以开放的S形水路进入卷潮，个体跟随切线转向、层次错相，水路两端透明回收。预警逐渐向实际攻击方向收束，横穿时形成三股有疏密的流线；收招平滑舒展回卷。单虾局部动作、水丝、微泡和光屑都读敌人已有的可暂停 `visual_clock`，没有独立累计时间。减半血后的旧预警／重复横穿继续由原AI驱动。

群体视觉、核心微动与特效是**位图＋程序驱动**；没有声称逐帧动画或用户审美已认可。使用mipmap缩小采样：首版高分辨率细长虾在小尺寸下呈锯齿细线，已改用短圆新虾并检查实机；未将增大实例数量当作修复方法。

战斗仅提取原有的位图构造为 `KitEncounterVisual.swarm_body`。旧AI其余代码、24HP、伤害、判定、三层水道、时序、授能和存档保持。冻结合同对**这一个精确的构造替换**展开回历史文本后仍比较旧SHA；没有更新旧基线来掩盖玩法变化。运行表核对只排除R2-04的sprites和swarm_visual，其他全部值需相等。
