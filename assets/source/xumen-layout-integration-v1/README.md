# 须门遗港 · 七房地图接入

本批依据[地图布局审阅 V1](../../../docs/鲸腹遗城原画集/须门遗港地图布局/地图布局.html)改造正式 `game/` 的七个须门遗港房间。审阅图非比例，实际间距按原角色跳跃、二跳、牵引、浮游与冲刺能力调整。原六条房间连接、三只普通蟹、一场母蟹战、护盾与浮游奖励保持原语义；没有新增潮汐开关或动作能力。

## 编辑入口

- 实际尺寸、地形、机关区域、门与输入验收路线：`game/content/whalebelly/layout/recipes.json`。
- 生成工具：`game/tools/build_xumen_layout.py`，使用 Pillow；从任意目录运行，输出七个 `r1/*.tscn` 及 `layout/rooms.json`。
- 运行加载：`CampaignWorld.load_rooms()` 按稳定 ID 覆盖原七房，再追加既有十二房。原 `game/art/whalebelly/rooms.json` 保留作历史输入，不能据此判断当前地图。
- 本目录 `input-rooms.json` 是改造前快照；`art-inventory.md`、`pixel-metrics.json` 与 `art-polish-notes.md` 记录实际查看和复用判断。
- `register-assets.py` 只登记并复制本批九张资源，避免全量同步意外重采样旧图；它不重建关卡。

## 七房走法

| 房间 | 本轮地图结构 |
| --- | --- |
| 外伤坡 | 两级登高、骨拱下转、出口下沉；失误回收台另有返程踏台 |
| 须筛 | 下槽、低顶短跳、回升出口；左右保留浮游支路与牵引支路 |
| 舌台 | 上路遇骨壁，下降折返、膜上下层与末端回升；护盾位于上方支台 |
| 负壳蟹 | 转折入场、中央连续战斗地面、两侧换位台；战斗边界平移而不改招式参数 |
| 流膜育窝 | 抬升台、低顶断口、落台调整与下沉出口；沿用原软床失误恢复 |
| 喷气孔上层 | 左右交替浮游、顶前中继与高处护盾；下方有独立返程落台，远闩保持关闭 |
| 鲸须记忆袋 | 两组牵引环、中途停顿台、骨柱绕行、背侧记忆奖励与下层返回 |

关键实测修正包括须筛低顶落台向左加宽 30px、外伤坡新增回收返程踏台、记忆袋第一返程台加宽。它们是把非比例剖面落实到实际角色尺寸的修正，不是角色数值改动。其余最终坐标以 recipe 为准。

## 位图与动态

新增三张透明位图：`images/bone-wall-original.png`、`thick-platform-original.png`、`low-roof-original.png`，分别提供实体竖墙、厚平台、低顶。原件保留；运行副本位于 `assets/runtime/scenes/xumen-layout-v1/` 与 `game/art/xumen-layout-v1/`，台账 ID 为 `xumen-layout-*-v1`。均按原生方向等比摆放，未将横图非等比拉成长墙。外部低 Alpha 柔光由 cutout Shader 丢弃，碰撞根据可见台面采样及保守实体核心建立。

| 元素 | 判断与处理 |
| --- | --- |
| 地台、实体骨壁、顶拱 | static；独立位图与物理轮廓，刚性结构保持静止 |
| 中空平台支架 | static；后置装饰，避让通路，没有伪造中空处的实心碰撞 |
| 承重膜 | motion；沿用下陷、下潜和回弹规则，网格细分后在固定两端之间形变，视觉与碰撞使用同一 sag 值 |
| 鱼群 | motion；复用已同步游动图集，逐帧动作加群体路径 |
| 垂须 | motion；复用固定根部的网格位图，随同一场景时钟摆动 |
| 气泡 | motion；复用有界回收位图实例 |
| 主角、蟹、母蟹 | motion；沿用当前正式动作与战斗适配器 |

外伤坡使用既有巨口颚骨背景。两处护盾使用既有弧形碎壳，记忆奖励保留珠状位图。门和封闭闩使用实际位图显示；限制规则仍来自原进度条件。

## 验收入口与边界

仓库根运行 `node tools/godot.mjs check`、`node tools/godot.mjs test`。专项脚本位于 `game/tests/whalebelly/`：

- `xumen_layout_routes.gd`：声明房间入口/进度夹具后只发原 Input，记录逐帧轨迹、健康、交互及实际 GPU 截图；落点默认必须站稳，空中经过点需显式标注。
- `xumen_continuous.gd`：从空进度第一房连续推进，跨门携带实际进度；没有逐房补能力、无敌或位置写入。
- `xumen_visual_qa.gd`：明确的房间与镜头夹具，检查当前位图、游动帧、群体数量、暂停保持和恢复，并保存全景与入口图。它不证明连续通关。

日志、轨迹与截图统一在 `game/build/qa/xumen-layout-integration/`，该目录不提交。当前通过项、失败修正和最终结果见 `game/progress.md` 的本批记录。实测使用独立 QA 存档；未覆盖真实玩家存档，也没有自动提交、推送或发布 Web。

最终结果：check 0 error，124项单测全通过；空进度连续主线50项、独立进程读档4项、七房动态/暂停35项通过。精简证据索引为[validation.json](validation.json)，七房当前全景保存在 `review/runtime-R1-*.png`，可由[实机地图页](../../../docs/鲸腹遗城原画集/须门遗港地图布局/实机接入.html)查看。

技术通过与用户审美验收分开：新结构位图仍为台账候选；本批未声称整套美术已获用户认可。使用 Dummy 音频驱动的测试只验证资源与运行逻辑，不代表听音验收。
