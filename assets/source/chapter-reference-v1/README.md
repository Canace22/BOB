## 接入边界

- 图片从 `assets/runtime/sprites/chapter-reference-v1/` 经 `game/art/manifest.json` 同步，禁止直接修改游戏副本。
- 只读章节状态切换显示，不拥有任务、存档、敌人生成或完成判定。
- 复用骨台、骨拱、住巢、菌床、阀叶与背景；承重结构使用独立支架图片，不竖向拉伸平台冒充立柱。
- 地图中的新增薄台仅供可选侧路，原任务底路和Boss脚线保持。最终正式地图仍需地编重新编排并验收。
- 本轮个人通用场景动态Skill主源未找到，按项目入口允许的制作合同执行。器官/骨梁/膜静态，复用既有水光与环境效果，不将静态图片位移登记为新动作。
