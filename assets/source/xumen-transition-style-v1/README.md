# 须门遗港 · 场景过渡样式 V1

本批仅设计原画。用户在精修过程中要求先设计过渡样式，因此暂停工程接入，不将上一批未提交Shader实验或平台素材视为已通过。线上运行版本仍以game/progress.md先前实际连通最终记录为准。

三张独立完整原画由内置imagegen绘制，参考现有鲸首/口腔设计和实际接缝截图；不是游戏截图、已分层资产或已验收碰撞地图。

1. T01：外伤坡→须筛，连续下颌路面与斜向骨拱，开放水域不换背景。
2. T02：须筛→舌台，以及舌台→守卫/食道的材质过渡家族；图以口腔向深处的变化为样板，不能当作E02/E03/E04三条边的精确工程定稿。
3. T03：须筛上层→上行支路，用同一骨质支撑长出不同大小的台面。图表达支撑/前后层和入口方向，未锁定现有E33/E35平台碰撞或新跳距。

查看docs/鲸腹遗城原画集/过渡样式设计/原画册.html。原件images/，完整英文提示词、来源、SHA256与生成原件路径见prompts.json。图册提供可切换路线/分层标记；标记是设计注释，不代表可玩关卡实现。图像中暖光统一解释为封闭菌灯，后续资产制作避免画成裸火。

## 后续接入合同

先按所选样式对具体一条边制作同镜头局部设计，保留原入口/出口脚底高度、512px主路间距、门槛与站立净空；概念图尺度压缩不得直接变成碰撞。远景先共用地标；可玩层给完整支撑；前景只压边，不挡落点。柔性物固定根部，鱼/气泡独立；避免背景烘焙重复。

原图若不能对应既有路线，先修图；不要只用模糊、透明渐变或前景遮挡掩盖实际接头。静态同视角对照通过后才进入分件/动态和正式接入。当前未实机验证这三张新样式，不提升为通用已成功配方。
