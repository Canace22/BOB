## 交付内容

- `inputs/`保存2026-11-14当前R1实机全景、七房数据及哈希。R1运行文件此后未变；这些图片用于对照原结构，不冒充本轮新关卡实机截图。

## 比例与验证边界

各房剖面采用1600×1000的统一画板，**非施工坐标**。路线折点是方向与空间层次，不是抛物线；通路交叉、贴近顶面的线也不能直接转换成角色脚点。

上一轮原角色平面样本：满跳约312px水平/161px高，短跳约124px/39px，晚二跳约520px水平；基础锚环搜索半径390px。它们仅用于排除明显的设计误解，不足以证明本版可达。门高差、骨柱绕过、低顶净空、膜下潜深度与回弹、浮游分段和返程落差须在样板中定标。不得按图上左右跨度直接施工。

本轮检查的是七房覆盖、原连接/奖励/敌人数合同、图像来源、浏览器功能和图示路线是否穿过刚性墙体。还没执行新关卡输入、战斗、碰撞或难度验收。承重膜等环境动件本轮只登记复用/配准要求，没有新增动画制作。
