# 尸蟹动作制作合同

本批从既有普通尸蟹基准 `assets/runtime/sprites/corpse-crab/idle.png` 补制；不是门庭负壳蟹Boss，也不改Boss造型和技能。

基准：低矮宽壳、象牙灰藤壶、暗红不对称双钳、两条眼柄、深色分节步足与珊瑚附着。近侧大钳是唯一低扫攻击钳，远侧小钳不变成第三只钳。朝左母版，两侧整体镜像；功能钳职责保持，不声称解剖学侧固定。AI复核与用户美术认可分开。

| 动作ID | 制作源/相位 | 游戏触发/时长 | 事件 |
|---|---|---|---|
| idle | life 0–3 | 无移动时循环 | 无伤害 |
| walk | walk 0–7 | 实际距离驱动，一周期40世界像素 | 受墙面/台缘约束 |
| tell | attack 0–2 | 进入攻击距离，0.70秒 | 固定面向，抬同一大钳 |
| active | attack 3–5 | 0.20秒 | 0.06秒低扫，前方判定一次 |
| recover | attack 6–7 | 1.10秒 | 收钳后可再次决策 |
| hurt | life 4–5 | 0.22秒 | 中断攻击，保留正常受伤/回魂接口 |
| dead | life 5–7 | 倒下0.50秒，留尸1.2秒，随后淡出 | 即时移除碰撞/判定，切房清理 |

3张8姿势表通过内置image_gen生成；具体模型名工具未暴露，实际提示词在prompts。它们是AI绘制姿势，非视频提帧、动捕或插帧。输出真实尺寸1774×887，不按请求布局盲裁；按显式分隔线避开第三格跨列的肢端，统一0.48源比例配准到256×256。保持式逐帧动画，不声称高帧率手绘。

资源输出在 `assets/runtime/sprites/corpse-crab-actions-v1/`，构建 `python assets/source/corpse-crab-actions-v1/build.py`（Pillow、NumPy）。源哈希与裁片/根坐标由构建记录。同步沿用manifest与sync-art。

本地已完成明暗底、正式房间尺度、双向七状态GPU复核；真实键盘战斗12项通过，含受击、击杀、暂停、过门及死亡复活。技术通过不等于用户美术认可，保持候选审美状态。逐项证据、参数、性能和限制见[接入说明](../../../docs/corpse-crab-integration.md)，线上状态以[进度](../../../game/progress.md)为准。
