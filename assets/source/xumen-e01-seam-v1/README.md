# E01 外伤坡→须筛样板

按已定T01与无缝接入合同制作。运行入口为 `game/content/whalebelly/main.tscn`；本批没有增加区域、玩法或改变碰撞。用户美术签收与技术验收分别记录。

## 可编辑文件

- `originals/`：内置imagegen实际输出5张原件，原文件不覆盖；`prompts.json`保存制作描述与来源。干净平台提取是生成式补绘，不声称逐像素保留原平台画片。
- `masters/E01-joint.ora`：2164×1536结构母版，远景/斜拱/骨路分层；坐标原点(845,-264.153)。独立前景原件和运行位图另存，位置(845,-530)。
- `masters/*mask.png`：两房像素所有权、鲸须支撑与相邻丘脊空间蒙版；未使用全局蓝色键。
- `build.py`：可复跑导出，使用Pillow/NumPy。新骨路按既有路面轮廓配准；干净支撑按原三平台顶面连续配准，未修改物理。
- `elements.json`：13类元素与实例规则，包含首选、备选、理由、位置、实际数量和不适用项；8张运行位图从assets同步到game/art/xumen-e01。

## 接入与验收

E01原地面碰撞X1645…2209/Y631.847，宽564、厚38保持。骨路画片扩大到X1100…2700以同时修两侧路面，核心可见顶面与碰撞误差0px。26地形和门槛保持。新远景为专用水域画片，其他边仍沿用旧资源，不能宣称整章已精修。

独立运动使用host.clock：22条鱼的泳姿与路径分开，3簇垂须48帧/12FPS/4秒错相，10气泡预热/渐隐/有界回收。独立前景小幅世界相机视差。只微调水域亮度，不扭曲地面。静态菌丛可保留静止。

跨房保留同一角色、速度、FX与弹体世界位置和寿命；弹体所有权迁入持久容器。提前准备E01可见邻房尸蟹而不启用邻房AI。相同水床采用章级单实例循环，避免同素材叠响/重播，不新增不同音色的区域混音。

本地check0错误、工程57/57、E01专项23/23、全连通38/38、独立读档2/2；Chrome往返12/12及56秒环境/暂停/练习冲刺/宽屏7/7。最后平台配准已GPU查看。详见game/progress.md与本地game/build/qa/xumen-e01。原生GPU视觉测试用Dummy避免本机WASAPI设备不可打开；浏览器实际音频stream保持playing，听感未重新人工签收。

## 失败与修正

1. 原旧图的水色多边形会随新远景暴露：改为空间选区、干净提取和专用远景，颜色键实验留档停用。
2. 生成素材不是精确碰撞图：按原顶面配准，保持物理字节不变；分段直接平移出现横缝后改为连续映射。
3. 原生Shader动态注入遇到只有vertex的材质：显式补fragment并在函数内部插入，GPU日志再次检查。
4. Web首次营地保存后立即刷新过早，异步刷盘尚未完成：保留失败报告，测试等待刷盘窗口后实际重载验证。没有更改玩家存档格式。
5. 播放时长、静态对照、路径、音频状态和性能各自留证，不相互替代。
