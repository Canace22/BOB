# 连续世界静态地形母版

2026-11-16，本地接入，未发布；用户整体观感待确认。

先将19房地形、连接道路与独立承重根放入同一世界坐标母版，再从同一节点树切片。`master.tscn` 保留完整远景和分层地形；`overview.png` 是缩略总览，不是运行贴图。`composition.json` 保存258个组成件的来源、世界变换与遮罩，`world-layout.json` 保存房间及脚线，`connections.json` 保存18条通道落脚点，`registration.json` 保存最终切片位置与SHA256。

母版初版复用既有位图；用户拒绝其矩形拼接后，当前追加[结构重绘V2](../world-seam-repaint-v2/README.md)的22张新画。原房地形优先，旧连接图只拥有原房矩形外的像素，V2重绘在完整上下文内取代这些裁断；实体道路不使用透明渐变交接。返程底路补齐已有承重根，胃枢底床增加已有实体岸台面，部分自然收尖处绕脚线等比重叠。R1-03会下垂的舌台膜保留实时层，鱼群、垂须、气泡、道具及敌人也不烘焙。

运行导出为61张非空区块，网格1536×1536，四边各2px采样余量，实际PNG为1540×1540。运行时按世界位置预取/卸载，切片无淡出材质；远景继续由独立世界层保持统一视差。区块加载目前为同步资源读取加提前驻留，未完成长期帧时间或显存专项。

在仓库根执行（`GODOT` 指向固定4.7.2引擎）：

```powershell
& $env:GODOT --audio-driver Dummy --path game --fixed-fps 60 -s res://tools/build_terrain_master.gd
python game/tools/verify_terrain_master.py
node tools/godot.mjs sync-art
```

必须等待构建成功后再校验或复制PNG，避免Windows读写锁导致导出失败。重新构建后同步维护manifest、catalog和registration中的区块清单及哈希。

当前像素校验：87对相邻区块的重叠采样最大差2/255；1598个原房脚线和476个房外通道落脚样本均有实体像素（不含实时舌台膜）。另用GPU实际D键验证育床30次接地及脚下Alpha。连接可达性、动态机关、整体画面仍须分别验收，像素采样不等于全图审美认可。最新证据与限制见[工程进度](../../../game/progress.md)。

返程透明修复：竖井重复台根使用metadata收集，避免Godot自动改名后只烘焙首块；127个台根（含水平接段）均进入母版。血巢潮群右端按用户选择保留尽头，使用同区软床位图等比旋转组成封闭肺膜，配实体边界，左侧原路返回。
