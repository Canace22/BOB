# 六条接续专用原画

在须门遗港精修图册中，补全E01、E02、E03、E04、E33、E35的独立接续设计原画。参考每条边两端已交付的新七房原画，联合重绘出口、过渡与入口，避免把独立横图拼起来冒充连续地形。

保持既有七房六边与能力门。不新增敌人、奖励或玩法。四段水平连接、两段上行支路分别画，共享巨颌骨/组织地标、光向、支撑和景深；注记与原画分离。图册要展示两端房间参考、接续原画和进入/经过/抵达的视觉说明，附分层、动态候选和后续接入验收。

本批仅设计原画，不改game/。新原件用内置imagegen，每张记录英文提示词、来源、任务ID、尺寸和哈希。原画中的暗孔不增加拓扑。概念不是可直接拼贴的贴图，也不代表实机跳距、动画或碰撞验收。
