# 泵庭执卫长柄动作候选

内置image_gen生成1536×1024透明4×4图集，完整提示在generation-prompt.txt。参考既有鳗图集的手绘材质与灰紫/象牙配色，独立制作窄直立、双手持长杆守卫；两栖外形是白盒候选，不固定正式族群。当前16关键姿势，非高帧完整动画，candidate待用户形象与手感认可。

四行分别为行走4步、长刺准备/蓄势/刺出/恢复、横柄架起/加载/推位/收柄、首刺准备/刺出/再拉柄/第二刺。二刺收招复用长刺恢复，不能把第16格刺出姿势冒充收招。

整图Alpha32检查有16个独立主轮廓。最后一格的杆尖跨名义格界约2px，因此atlas.json以主轮廓加3px余量取样，保持各格原root X=240及实际脚底Y，不修改PNG、不逐帧等高缩放，不把邻格杆尖带入上一姿势。源/runtime/game保持同RGBA和SHA256；统一108/220比例，体高约114px，杆端威胁宽按实际画面约115～125px加前踏运动，不用无形180px长判定。

安全线与窄道顶板是白盒调试设施，不作为正式环境美术。接入仅独立试验场，不替代第七章演出/正式角色定稿。
