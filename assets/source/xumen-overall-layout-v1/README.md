# 须门遗港总布局图

[图册入口](../../../docs/鲸腹遗城原画集/须门遗港精修设计/原画册.html#overall-layout)。这是工程展开布局示意，不是新场景美术；没有重画或替换14张已交付概念原画。

将现有7房、6边、51段台面放进同一张图，其中26段为连接碰撞快照。金色是首次主路，蓝色是A2浮膜回访，紫色是A3锚定回访；上层两处不连通，记忆袋盲端，章外出口单独标记。短冲跨缺口的虚线为移动指引，不是新增平台。支持放大、横向滚动、切换原画底图/物件标记/支路线，点击房间或边跳到原画。

- `build_layout.py`：从现有数据生成可编辑SVG和HTML。
- `总布局.svg`：可独立打开的布局图，点击房间/边返回图册；内嵌样式与可编辑图层。
- `section.html`：插入主图册的交互版片段。
- `manifest.json`：坐标来源、哈希与范围。
- `verify_layout.cjs`：真实浏览器验证。
- `review/`：本地截图和自动结果，依仓库存储规则不入库。

在仓库根目录运行原图册`assets/source/xumen-keyart-v2/build_atlas.py`即可同步生成本图；需要Pillow。运行`node assets/source/xumen-overall-layout-v1/verify_layout.cjs`验证图层、放大、跳转及手机滚动。`game/`无修改，不需要重建或部署游戏。
