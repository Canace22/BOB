# 鲸落万物生 UI V1 图标母版

2026-11-04。来源：同工作区 `outputs/鲸落万物生_UI_V1/assets/icons/` 的原创常规 UI 矢量图形；参考其游戏界面设计稿，未使用《空洞骑士》原作图形。

`icons/*.svg` 为可编辑母版，由 `game/art/manifest.json` 逐项同步到 `game/art/ui/`；不通过程序几何伪装角色、地形或正式场景美术。运行用 leaf、echo、shell、ornament；其余为该套共生视觉语言保留的图标，不代表共生玩法已实现。

字体沿用项目 Noto Sans SC / OFL 来源；此轮子集改为 Regular 400，解决原可变字体默认 Thin 100 在亮水体上难读的问题。中文字形覆盖由现有测试核验。

接口、数据差异、测试与发布边界见 [UI 系统说明](../../../docs/ui-system.md)。源和运行副本对应，后续先修改本目录再运行 sync-art。
