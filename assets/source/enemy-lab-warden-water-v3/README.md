# 泵庭执卫 · 随身压囊水术样板

内置image_gen沿既有执卫身份生成1536×1024透明4×4图集；完整提示generation-prompt.txt。前三行12个关键姿势分别为三连水弹、转柄水龙卷、水遁与凝形，最后4格是独立水弹/水龙卷/水迹/压囊道具，不将道具格计作角色逐帧。角色统一108/220比例、原格rootX240、脚底Y，不逐帧等高缩放；仍是candidate动作样板，非高帧完整动画。

首次输出白色背景实际Alpha最低144，不能当透明素材使用，保留water_actions-background-rejected.png。用内置image_gen执行background-fix-prompt.txt去白底修正，当前PNG抽样背景Alpha0；生成式返修不是对原像素精确抠取。最终source/runtime/game保持同RGBA与SHA256，区域/Alpha32边界与props在atlas.json。半透明水体保留，未按颜色阈值删掉浅水像素。

三招都由执卫自己的压囊/骨柄释放，不引用场景膜泵或泄压瓣。水弹24px、速度330/s、三次0.22s间隔；龙卷高130px、水平追击上限220/s、900/s²转向加速度、寿命2.2s，不上天追人。水遁的水迹/半水体为已有绘画姿势，位置连续推进；水弹与龙卷复用已入库位图+显式clock Shader“程序驱动”。

黄色弱点只在三招tell后45%窗口染亮画面中压囊的既有像素，与actual weak_window相同；保持原Alpha。每个准备姿势有独立局部位置，兼容朝向镜像，囊体实际受击范围同步包含在本体唯一hurt_rect中，不创建重复伤害目标。背侧两次轻击或一次3伤害重击可失压，中断后立即熄灭提示。阶段/碰撞/动作由同一Boss执行器持有，不依赖关卡F操作。

默认平地为Boss技能验证，退出线/窄道与膜泵留在可手选的关卡样板。正式族群/故事、完整角色动画和场景接入未定。实机截图/日志只留game/build/qa，当前证据见game/progress.md。
