# 泵庭 · 导压、膜泵与泄压交互样板

内置image_gen沿既有执卫身份生成1536×1024透明4×4补充图集。完整提示在generation-prompt.txt，原图pump_actions.png和源/runtime/game同RGBA与SHA256。前8格为导压/反抽各4关键动作，后8格为4个膜泵状态、2个泄压瓣状态、2张独立水流；不能把道具格计成角色动画。

角色统一108/220比例，以原格rootX240与脚底Y锚定。膜泵四状态和泄压瓣两状态用同一384×256画布，固定比例、固定中心，不按每帧bbox重缩放；水流仅取独立区域。膜泵为状态关键图候选，局部骨框细节仍可能随生成状态漂移，不声明正式高帧连续动画或结构完全锁定。骨台和窄道沿用既有白盒碰撞，没有制作正式场景背景。

## 静动判定与所有权

| 元素 | 判定 | 方法与边界 |
| --- | --- | --- |
| 骨台、窄道顶板、安全线 | static | 既有白盒几何/物理，跟随关卡常量，不随泵时钟形变 |
| 膜泵 | motion | 四关键状态固定画布切换，压力与恢复由场景统一时钟驱动，停止战斗后无害循环 |
| 泄压瓣 | motion | 关闭/张开两状态，实际F操作与3秒卸压状态绑定；不是击碎设施 |
| 出口泵流 | motion | 已入库水流位图，单精灵+局部UV Shader，外围Alpha限定；预备泡沫/全流分开亮度，实际80×220范围 |
| 地面反抽 | motion | 两张水平水流实例朝进水口会聚，警告0.7秒后控制1秒，只影响低处角色 |
| 正式管路连接/整间泵庭 | inspect/未制作 | 本轮只验证一组交互样板，不扩成完整第七章场景 |

场景EnemyLabPumpCourt发布压力、伤害事件与pump_drift，角色自己的_before_move/move_and_slide执行位移，移动后归还基础速度，不能把外流水速每帧累加成无限加速。固定3个水流精灵，没有无界粒子或每帧纹理回读；Shader使用显式clock，暂停后不漂移。表现仅显示实际压力，不另算伤害。

本机个人通用scene-environment-motion主源未安装，本轮按仓库保留的production-contract/motion-recipes执行项目范围样板，不宣称已加载个人最新版。当前状态candidate，技术验证与用户手感/美术认可分开，尚待试玩。制作源、时间与运行证据见game/progress.md，本目录不入库截图/日志。
