# 拾潮者攻击视频 V01

用户要求设计几组攻击动作并制作视频。本批3组独立参考视频，沿用会话已确认的Seedance2.0、6秒、720P、3:4与角色参考节点。原画由用户提供用于本角色制作。当前任务不修改游戏攻击逻辑；三组均已生成并完成解码与抽帧检查，状态为参考候选。

|动作|设计用途|主要姿态|设计时间|
|---|---|---|---|
|踏步横扫|地面短击候选|后压扭腰→小踏步蹬地→横扫伸展→收叉回位|预备0.6–1.5s，出击1.5–2s，终点2–2.3s，3.4s回稳|
|蓄力重劈|重攻击候选，不等同于当前重鸣AOE|屈膝双手举叉→前踏斜下劈→低姿缓冲→回稳|预备0.6–1.8s，出击1.8–2.2s，缓冲2.2–2.6s，3.6s回稳|
|腾空下刺|空中下劈候选|蹲压→小跳收腿→骨叉朝下→落地吸收冲击|预备0.6–1.2s，起跳1.2–1.8s，下刺1.8–2.1s，2.6s落地|

表格时间是生成设计，不是已测得的伤害事件；后续接入必须根据实际视频姿态重新标注前摇、有效帧、后摇。6秒是观察片长，不能把它直接当游戏普攻时长。原12FPS要求属于上一轮跑步接入，本轮交付视频保留生成帧率。

三组共用固定朝右三分之四机位、米灰背景、较宽安全留白，不加特效以检查本体发力；保持同一短柄U形骨叉与持物手，保留预备、出击、恢复。原画节点skills_img_0bebad861f已在画布中，不重新上传或生成角色。

画布：独眼提灯者-Idle，workflow 8f27cc11-039d-4cdb-8423-7271b5c5682e。完整提示词分别在attack-01-sweep.txt、attack-02-heavy.txt、attack-03-dive.txt；参数见brief.json，submit/result记录包含任务与节点ID。实际检查已写入review.json。

## 实际产出与检查

三段均为834×1112、145帧、24FPS、6.041667秒；所有帧解码成功。`*-source.mp4`完整保存生成原片；同名无source后缀MP4为无重编码去音轨版本。每段按12个时间点抽帧检查动作和构图，未将抽帧检查宣称为逐帧美术签收。

**踏步横扫**：可见踏步与前向挥扫、回稳；实际预备比提示更长，持叉经过头上，最大幅度时骨叉/披风出画，胸肩与持物细节有变化。作为动作方向参考，完整游戏素材验收未通过。

**蓄力重劈**：可见举叉蓄力、向下重击与收势；预备含单脚腾空，骨叉在顶部及左右边缘裁切，挥击约3.2秒出现白色光痕，未完全遵循无特效约束。作为重击参考，需后续构图及武器稳定性返修。

**腾空下刺**：可见下蹲、小跳、骨叉转向下、落地缓冲与回稳；跳跃峰值头顶贴边/轻微裁切，红绳与持叉细节漂移，动作比设计时间延后。三组中下刺过程较完整，仍为参考稿。

没有新增自动返修或重复生成；没有把这些参考视频接入游戏。本批记录设计、任务、原片、静音预览、封面和检查结果。后续优先修复运动包围范围与持叉稳定性，再截取攻击有效片段。
