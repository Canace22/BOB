接续蒙版、世界位置、显示范围在 specs.json 与 render_seams.py；房间源图与新原件不可覆盖。后续只移动蒙版边界或定向补绘有问题的一处，不能重新解释整区。当前仍是静态概念接续，不是分层引擎资源、玩法或无缝运行验收。原画外围画幅边缘并非整个鲸头外轮廓。

重新生成：先运行 register.py，再执行 ../xumen-keyart-v2/build_atlas.py；浏览器运行 node assets/source/xumen-seam-repaint-v2/verify.cjs 与 review.cjs。capture.cjs 仅首次截取输入，已有 before.png 时不会重写，避免把修后图当修前参考。review/为本地可复跑证据，不当作正式美术原件。
