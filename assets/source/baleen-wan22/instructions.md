# 四组垂须 · ComfyUI + Wan2.2 5B + Krita

输入：本轮用户红框截图reference/marked-regions.png。四组对应BALEEN-LEFT/CENTER/RIGHT/DISTANT；已有批准原画分件位于../baleen-blender/paint，继续沿用坐标与根部。

动画设计（proposed）：水下缓慢侧摆，根部锁定，末端逐渐增加幅度；左侧6–10px、中央4–7px、右侧5–9px、远景1–3px。保留纹理与细丝；建筑、水面、道路不随动画形变。幅度是制作初值，验收记录实际测量。

执行顺序：
1. 本地ComfyUI API读取节点与模型版本、队列；中央49帧384×320样片，Wan2.2 TI2V 5B官方FP16文件以fp8_e4m3fn加载，20步，cfg5，固定种子。保存prompt_id后查询原任务，不重复提交。没有第三方计费。
2. 样片审阅后同法生成其他三组；每组先保存原始PNG与24FPS源视频。画面锁定，黑色背景，固定根部，禁止新增物体。
3. 实际解码视频，N=ceil(解码帧数/FPS)×12；49/24=2.041667秒，因此每组最终36张、12FPS、3秒。记录重定时、循环修复或视频运动投射，不宣称直接原速抽帧。不能用重复末帧伪装流畅。
4. 提取透明动件并保持原画比例、锚点和根部；如生成发生形体漂移，保留失败源片，按视频运动场驱动批准原画，明确标为派生序列。Krita实际导入逐帧动画、12FPS、保存可编辑KRA和复核截图。
5. 同一Godot工程内接入独立元素；固定镜头、根部漂移、帧数/播放帧率、透明边缘、两次循环与相机移动验收。只替换通过样片，原Blender母版保留。

失败分支：保留任务ID、工作流和错误；不自动无限重试，不改换付费服务。渲染成功不等于画面通过。当前主工程还有其他任务的未跟踪角色文件，本轮不修改或提交它们。
