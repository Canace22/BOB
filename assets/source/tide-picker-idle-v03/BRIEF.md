# 拾潮者 Idle V03 执行包

范围：将本聊天的提灯守望视频制作成唯一 Godot 工程 WhalebellyRuins 的实际玩家待机动画。仅替换 idle；保留移动、攻击、跳跃、碰撞、存档、原图对照与静态截图库。

输入：reference.png（用户完整原图），source.mp4（Seedance 2.0，任务 vj_f85f7ee4-8f48-4eb8-aa99-8107706fc8dc，画布 8f27cc11-039d-4cdb-8423-7271b5c5682e）。视频145帧、24FPS、834×1112；包含边缘裁切，不能直接作为正式全身精灵。

制作：使用本机 helpers Python / OpenCV / Pillow / SciPy，读取视频位移，将运动重投影至完整原画；头盔和双叉使用刚性运动，脚部固定，循环位移以平滑周期包络闭合。此为视频驱动的二维位图烘焙动画，不是未经处理的AI抽帧，也不是逐帧手绘。无新增付费生成。

导出：72帧，12FPS，6秒循环，256×320统一画布，脚底锚点(128,300)，透明PNG图集与Godot SpriteFrames。源、母版运动场、运行资源分别保留。游戏角色目标高度沿用每房80–110世界像素；左右沿用现有控制器翻转约定，不宣称独立左向原画。

阶段：A 输入及工具验证 → B 小样透明边缘/完整轮廓检查 → C 动画导出 → D 主关卡接入 → E Godot4.7.2导入、状态切换、暂停、循环、实际截图与播放验收 → F 台账、文档及本批Git提交。

验收：alpha与完整边界、接地、头盔/双叉一致；6秒循环；实际主场景idle→run→idle/跳跃/攻击；暂停保持；原图对照不受影响；不写真实玩家存档。失败只修本资产或接入，不重建工程、不覆盖历史动画、不发布Web。
