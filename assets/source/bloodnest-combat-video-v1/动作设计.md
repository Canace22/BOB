# 血巢虾群 · 攻击与受击表现设计 V1

状态：设计与视频执行提示词已准备，专用新画布及参考节点已创建。MiniMax H3因厂商余额不足失败后，经用户确认改用Wan 3.0，在原节点完成两段10秒720P视频。原输出附音轨，已copy视频流生成无声审阅版。受击片镜头／人物／局部反馈仍有偏差，详见[生成结果与验收](README.md)；不把概念视频登记为实机效果。任务与来源见[execution.json](execution.json)。

## 视觉主旨

玻璃虾组成有方向、有疏密、有前后层次的活水流。攻击像卷起后突然舒展的绸缎，受击像水面被划开后重新合拢。美感来自延迟传递、曲线和透明层次；攻击接触的一瞬必须干脆。

沿用本轮已制作的珊瑚红头胸、珍珠腹节、冷蓝尾扇与深红单眼。单体仍可识别；虾群不能融成肉块、绳索或单一发光体。不新增武器、技能和攻击模式。

参考：`../whalefall-v5-2-complete/references/18_R2-04.png`；单体：`../bloodnest-animation-v5/images/glass-shrimp.png`；已接入V5的水丝与微泡。原画定风格和空间关系，单虾图定身份；旧V5视频不作为攻击／受击最终表现。

## A · 攻击：蓄潮—穿潮—舒展

当前战斗合同：预警1.00秒、横穿1.50秒、收招0.70秒；半血后沿用已有0.75秒预警和重复规则。所有时间是既有AI事实；以下细分是呈现设计。

| 相对时间 | 身体与群体 | 特效与阅读重点 |
| --- | --- | --- |
| 预警0.00–0.35s | 前排先转头，腹节微收，后排逐层跟随；开放卷潮仍留空隙 | 游丝由松转紧；原方向带继续承担危险层提示 |
| 预警0.35–0.85s | 三股虾流错位收束成扁梭，前紧后松，触须与尾足被水压带向后 | 头胸暖红略集中，尾扇保留冰蓝；2–3条细水丝勾勒流向，不闭合成圆环 |
| 预警0.85–1.00s | 轮廓清楚，前排方向稳定；尾端仍微动，避免定格整片 | 头部边缘出现短而细的月牙水光，不画巨型光刃 |
| 横穿0.00–0.12s | 前后排快速拉开，主流向明确；主体仍按原AI速度横穿，不另加突进位移 | 银蓝细线短促拉长；亮度集中在前缘，尾迹透明 |
| 横穿0.12–1.30s | 同向游动叠加细小上下波，三股不排成等距直线；前实后虚 | 细水丝、微泡、极少暖色闪屑随流后拖，保留大量暗部 |
| 横穿1.30–1.50s | 前排先弯出弧线，后排继续赶上，形成舒展尾卷 | 尾迹减亮、断开，不能留下新的伤害区域 |
| 收招0.00–0.30s | 虾流像丝带松开，前后排依次转向，显露可近身的空隙 | 微泡向上、水丝继续向前，形成不同惯性 |
| 收招0.30–0.70s | 从开放弧线回到疏密相间的卷潮 | 光屑稀疏淡出；不突然爆散、不整团缩放归位 |

接触目标时，仅在既有命中时刻补一个短促、局部的骨白／冰蓝水花与涟漪。位置跟随真实接触点，不贯穿全屏，不增加攻击长度、伤害或停顿。参考视频重点展示攻击本体，碰撞实现仍以正式工程事件为准。

## B · 受击：局部点亮—破群—回流

| 命中后时间 | 身体与群体 | 特效与阅读重点 |
| --- | --- | --- |
| 0.00–0.05s | 受力点附近少量虾的壳缘先亮，主流向继续 | 短骨白接触弧＋一枚薄冰蓝弯月，亮区局限在命中附近 |
| 0.04–0.12s | 3–6只邻近虾按受力方向偏开约自身宽度的15–30%，触须后甩、尾扇短收 | 一道折射波沿群体传开；不整群同帧发白 |
| 0.08–0.25s | 形成约一个虾身宽的局部缺口，后层仍可见，前层反应稍后到达 | 4–8枚细小壳光／气泡向外，迅速变暗；没有血浆、碎尸和火焰 |
| 0.18–0.45s | 缺口被邻近水流柔和补齐，偏开的个体以弧线归队 | 水丝先折弯再拉顺，残余光屑落后消散 |
| 0.45s后 | 回到当时应处的待机／预警／横穿姿态 | 命中特效清除，不残留假弱点或持续伤害圈 |

攻击中受击仍沿原水道横穿：局部破群和亮波叠加在既有动作上，不触发新的硬直、击退、无敌或打断。连续命中按最近命中位置更新局部波，特效用有界池，避免整群反复闪烁淹没轮廓。当前设计不扩展死亡／阶段切换演出。

## 分层与运动所有权

1. 后层：透明水丝、少量微泡，不盖住虾的眼与头胸。
2. 本体：玻璃虾局部足／触须／尾扇动作与流路，保留前后层透明差异。
3. 接触层：跟随命中点的短弧、壳缘高光与折射波，不做全屏白闪。
4. 前层：极少短寿命光屑，不能变成持续烟雾、满屏雪点。

现有44实例、24HP、伤害、三层水道、授能和存档均保持。视频画面只用于设计参考，不承诺生成模型精确保持44只；工程实例数与时序另验。群体运动、局部动作、特效与镜头各只有一个时间／位移来源。

## 两段生成视频的分镜

候选方案为两段各10秒、固定横版镜头；这是内容设计，不代表已批准或已提交生成参数。

**攻击参考**：0–1.8s舒展待机；1.8–2.8s蓄潮；2.8–4.3s由右向左穿潮；4.3–5.0s舒展；5.0–6.8s待机；6.8–7.8s反向蓄潮；7.8–9.3s由左向右穿潮；9.3–10s舒展。画面保持可见边界，不追镜、不切镜。

**受击参考**：0–2s卷潮待机；2s左侧接触弧命中；2–2.45s局部破群／回流；2.45–5s重新流动；5–6s蓄潮；6–7.5s向左横穿，在6.6s从下前方命中并局部反馈，整体运动不中断；7.5–8.2s收招；8.2–10s回卷。只表现受力与群体，不新画攻击者或新角色。

生成源：单虾参考、原画场景参考、动作说明文本分别进入画布节点，再连到视频节点。画面不带HUD、字幕或标尺；验收用本地时间轴，不要求模型写字。

## 视频验收

- 身份：眼、短圆头胸、腹节、尾扇一致，无融合、复制头眼、大虾怪化。
- 攻击：预警方向能读出，横穿前实后轻，左右两向一致，收招顺流舒展。
- 受击：明确发生一次局部接触、缺口和补位，攻击中受击不停止整群运动。
- 美术：手绘半透明原画风，冷暖克制，主体清楚，背景与地面无整体漂移／液化。
- 技术：实际解码时长／分辨率／帧率、代表帧和完整播放单独记录；AI视频不登记为已接入游戏资产。失败先定位问题，保留任务ID，不擅自反复扣费重试。
