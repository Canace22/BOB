# 须庭角色逐帧样板 · 2026-11-04

本批新建食腐甲与补巢者两个身份，使用内置 `image_gen` 生成透明动作原画，不使用旧 NPC 改名，不把整图位移当作自身动画。运行图集在 [runtime](../../../runtime/story-c01/characters/animations.json)。当前样板已通过本地场景接入与真实Web路线，线上待核实；用户整体审美认可另记，不由生成、技术检查或通关代替。

## 制作与来源

- 已查看 [首房原图](../../xumen-reference-environment/original/reference.png) 与 [须筛场景](../../r1-chapter-scenes/generated/R1-02-clean.png)，用于画法、象牙壳材质、深蓝暗部和暖灯参考，不把旧地形拓扑带入新章。
- 原始工具输出原样保存为 `forager-generated.png`、`mender-generated.png`；完整提示词分别为 `forager-prompt.txt`、`mender-prompt.txt`。两个角色各一次生成，食腐甲先行检查后再生产补巢者。
- 请求 2048×2048，实际两图均为 **1254×1254**。不能直接按 4×4 精确等分给引擎；裁切边界明确为 `[0,314,627,940,1254]`，按原顺序抽取 16 格。
- [export-atlases.ps1](export-atlases.ps1) 使用 System.Drawing 逐像素复制，**不缩放、不拉伸、不改变 alpha**，保留逐帧 PNG。只做固定平移及补透明画布；各行共享一个人工核对的接地基线，不按每帧可见框独立缩放或归一最低点。
- [provenance.json](provenance.json) 保存源/运行/全部帧 SHA-256、裁片边界、逐行平移与原点，`*-frames/00.png` 至 `15.png` 为生成动作的实际顺序。

## 运行合同

两者均为 1344×1344 PNG、4×4 图集、336×336 格、右朝向，脚底根点 `[168,300]`。`reference_height` 是第 0 格可见本体测量高度，不是画布高度；宿主以同一缩放系数处理所有帧。

| 角色 | 基准本体高度 / 目标高度 | 动作与循环 |
| --- | --- | --- |
| 食腐甲 | 143 / 70 px | feed 0–3，4 FPS；walk 4–7，8 FPS；attack 8–11，8 FPS，一次；hurt 12–13，10 FPS，一次；retreat `[14,15,13,14]`，7 FPS |
| 补巢者 | 186 / 90 px | mend 0–3，4 FPS；talk 4–7，4 FPS；walk 8–11，6 FPS；idle 12–15，3 FPS |

食腐甲另提供 `warn=[8,9]`，4 FPS 一次，`lunge=[10,11]`，8 FPS 一次，方便宿主把预告与实际近扑时机分开。完整 `attack` 包含预告；先播 `warn` 再播完整 `attack` 会重复预告，应按实际战斗阶段选择。退步循环复用新制作受击/退步行中的第 13–15 帧，是有限帧重组，不宣称新增四个退却姿态。

`StorySpriteAnimator.configure(atlas, actions, display_height, reference_height, Vector2(root[0],root[1]))` 配置显示；`set_action` 相同动作不重启，明确传 `restart=true` 才重播。一次性动作停在末帧并发送 `action_finished`；状态转换由宿主负责。`animation_paused=true`、默认的可暂停处理模式下树暂停、`playback_speed<=0` 都保留当前帧与时钟。宿主在对话期间仅让补巢者使用 `PROCESS_MODE_ALWAYS` 播放交流动作，暂停菜单仍冻结它；行走实际受阻时宿主应选静息或暂停，播放器不推断物理位移。

## 检查证据与边界

1. 已解码两张 RGBA 原图，各 16 个格子；每角色导出帧的文件 SHA-256 各有 16 个唯一值，无整帧完全重复。
2. 已查看本地 `*-generated.png.backgrounds.png` 的亮底/墨蓝底合成：壳、触肢、菌灯轮廓可辨，没有可见矩形底、地块或跨格肢体。透明图直接预览中的红黄噪点来自透明像素的显示方式，实际 alpha 合成没有对应色块，未因此删改真实边缘。诊断合成图只保留本地，用 [inspect-atlas.ps1](inspect-atlas.ps1) 重建。
3. alpha≥32 下食腐甲第 0 行基线均为 290；走路行 286–287，近扑行 288–289，受击行 287。采用每行 `[290,287,289,287]` 的共同基线。补巢者采用 `[284,285,285,284]`；交流行允许 1 px 脚部变化，保留动作本身。
4. 本地 `preview.html` 是自包含实际尺寸动作预览，含明暗底、翻面、暂停，重建用 [make-preview.ps1](make-preview.ps1)。[浏览器检查脚本](check-preview.mjs) 在独立 Chromium 上已执行：两图实际加载、8 个动作面板都有真实像素变化，连续 12 次采样覆盖循环，暂停时钟和全部面板像素不变，继续后恢复，翻面及明暗底可用，无页面异常。纯验收 JSON、预览 HTML 和阶段截图只保留本地，不作为入库来源。已查看本轮 `game/build/qa/story-c01-art/` 的阶段截图及明底镜像截图，触肢/腿部姿态与方向可辨；这是有限帧样板播放，不宣称视频级平滑或完整场景验收。
5. 本批主代理运行 Godot 测试 **64 项全部通过**，包括 [食腐甲与交互回归](../../../../game/tests/test_story_forager.gd) 的 6 项：实际 `StoryForager` 在独立碰撞地面上归巢并保持存活、仅结算一次；预告后绕到背面不再被反向命中，正面每扑最多命中一次；非致死受击使用 `hurt` 原画；暂停冻结归巢物理、时钟和帧，恢复继续；真实宿主的对话暂停保留补巢者动作，暂停菜单冻结；交互键同一tick释放后仍等待物理帧边界，避免关闭后立即重开；两侧归巢、指路和主动跨出口分阶段保存。测试存档独立。

## 可复用经验

生成器请求的网格尺寸不是输出尺寸保证。先读真实宽高、记录裁切边界与逐行地线，再以一个源比例和固定原点补画布，能避免直接 hframes 切分造成串格以及逐帧紧裁导致的壳体缩放跳变。透明源的 RGB 在某些查看器里会显红黄噪点，必须先做真实 alpha 明暗底合成再决定是否返修；本批合成表证明无需全局阈值去边。
