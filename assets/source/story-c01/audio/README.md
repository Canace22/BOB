# 须庭 · 循歌与共鸣声音

本批为项目原创的离线合成声音设计。全部波形由本目录 Python 脚本用正弦叠加、包络、轻微频率变化和短延迟生成，没有使用录音、下载素材、第三方采样包或外部旋律。**`whale-call.wav` 是幻想世界中的循歌提示，不是鲸类真实录音，也不声称复现任何物种叫声。** 原创制作源和导出交付 BOB 项目随游戏使用、修改和重新导出；没有外部音源授权依赖。

## 产物与设计

- [`whale-call.wav`](../../../runtime/story-c01/audio/whale-call.wav)：3.2 秒，三段低沉的起伏短句；约 82–110 Hz 的基频和弱二、三次谐波，让低鸣在小扬声器上也有上方泛音。段间留白、缓起缓落和克制延迟用于呼应深海与鲸体内部空间。目标听感是温暖、遥远、不刺耳；不是警报，也不是持续环境底噪。
- [`resonance.wav`](../../../runtime/story-c01/audio/resonance.wav)：0.55 秒，约 294 Hz 与上方纯五度的短促柔和共鸣，45 毫秒起音、指数衰减与末端渐弱，用作主动交流的反馈，避免金属尖响。
- 两项均为 44.1 kHz、单声道、16 位 PCM WAV，不循环。无需外部运行音源或合成插件。

## 重建与验证

仓库根目录执行，Python 3 标准库即可：

```sh
python assets/source/story-c01/audio/build_audio.py
python assets/source/story-c01/audio/build_audio.py --check
```

首条命令重建两项 WAV 和本地技术报告 `validation.json`（按仓库资源存储规范忽略，不提交）；第二条只读校验格式、样本与同版脚本重建结果，检查无削波、峰值/RMS、相邻采样步长、首末零采样与前后 10 毫秒的低能量渐变，不写文件。脚本不使用随机数；报告中的 SHA-256 绑定本批导出。跨平台数学库的舍入差异若导致极少数 PCM 样本不一致，应使用目标环境重建并重新核对声音，不能忽略差异后声称字节一致。

## 验收边界与接入

- 技术检查：本批已经运行生成与只读重建检查，两项均通过。低鸣峰值 −10.173 dBFS、RMS −21.298 dBFS；共鸣峰值 −12.766 dBFS、RMS −25.190 dBFS。两项均为零削波、首末零采样，最大相邻采样变化分别为 0.006287 / 0.011993（满幅归一化），首尾渐变通过。完整数字及 SHA-256 可用上述命令重新生成。
- 听感：**待试听**。技术指标不能证明声音悦耳、符合剧情或在耳机/扬声器中均适合。接入后仍需复核低鸣可辨识度、与现有水声/动作声的关系、共鸣反馈音量和频繁触发时的舒适度。
- 游戏接入：已同步至章节运行目录，主任务独立本地Web完整路线15项通过且无引擎/浏览器错误，属于本地加载及触发接入证据，不等于已经试听。**听感、用户认可及线上资源仍待验**。最新路线、源码与发布证据统一见[工程进度](../../../../game/progress.md)。
- 混音起点建议：播放器先设置低鸣 `-10 dB`、共鸣 `-14 dB`，根据现有环境声实听调整；这不是已验证的最终值。低鸣仅在叙事提示时播放，共鸣在交流触发时播放，不将两项当作可连续叠加的环境循环。
- 静音时保留文字方向与交互反馈。环境/游戏暂停时停止或暂停声音，恢复时不累积重放；同一提示避免每帧触发。

本批成功验证的可复用方法是：短叙事提示的制作源可用标准库保持可重建，技术报告将波形检查与听感/接入分开记录。具体频率、长度和响度仅属于本批候选，迁移到其他对象需要重新试听。
