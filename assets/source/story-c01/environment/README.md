[manifest-additions.json](manifest-additions.json) 是提交给接入者的8项增量：3件新图，5件旧资产（骨台、骨根、住巢、营地、菌床）直接引用原件。它不是游戏自动加载入口，正式同步清单由主任务统一登记。

[build-scene.mjs](build-scene.mjs) 只重建明确节点、等比变换、裁片、标记和碰撞，不生成图像像素。工程中的 `story_environment.gd` 提供 `WORLD_SIZE`、`SURFACES`、`get_surfaces()` 和 `get_marker_position(name)`；运行内不硬编码玩家或宿主节点路径。

## 静动扫描与选型

| 元素 | 判断及理由 | 方法与备选 | 当前边界 |
| --- | --- | --- | --- |
| 洞顶、远处须板根、远景巢穴 | static；低对比远景和硬骨结构 | 新绘宽景；固定坐标，若需视差再补隐藏面 | 不把烘焙静物称动态 |
| 道路、骨台、硬骨根、中央须板 | static；实际承重、碰撞分隔 | 既有合格位图等比裁片/拼接，新补中央结构；不用程序占位 | 需引擎截图复核顶面和接地 |
| 住巢、营地、聚食菌床 | static；本章最低场景叙事 | 旧原件等比摆放；灯体保持静止 | 未新增灯体动作或菌床状态 |
| 三簇柔性垂须 | motion；固定根部、自由软梢 | 既有48帧图集；复用BaleenFrames，错相0/13/29，统一外部时钟 | 新实例根点、循环与暂停待本章验证 |
| 两组16条鱼 | motion；自身尾摆与路径不同职责 | 复用ChapterFishGroup与已有32相位鱼图集；若需避障才做行为 | 只做装饰，不参与战斗 |
| 两域13个气泡 | motion；浮升生命周期 | 复用EnvironmentBubbleEmitter，预热/有界回收，关闭自身时钟 | 不用气泡冒充回流 |
| 9个污絮 | inspect→motion候选；要明确折返而非仅上浮 | 新透明污絮+11秒椭圆回流，旋转沿轨迹切线；备选为独立局部水流帧 | 必须在右侧实机判断线索可读，未验收前不称完成 |

总时钟由StoryEnvironment拥有；`animation_enabled=false` 或速度0保持姿态；子件采用外部时钟，不双重推进。SceneTree暂停继承父级，恢复无需补发。所有重复实例固定上限，不随运行无限增加。
