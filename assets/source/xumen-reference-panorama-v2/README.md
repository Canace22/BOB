# 原房构图保真总览

[当前实景总览](../../../docs/鲸腹遗城原画集/须门遗港精修设计/原画册.html#real-scene)。此前生成全景简化了原房间，现降为折叠历史稿。本批不用生成模型重画七房，直接保留用户本轮提供的完整位图。

8张附件对应7房，图1/图3为外伤坡的两个版本，可切换；默认图3。`inputs.json`登记原路径、尺寸与完整哈希，`inputs/`保留原字节。原图中的拱路、须筛层台/三环、舌台下层/奖励高台、蟹场侧台、育窝三沟三软床、上层大平台和记忆袋四环均完整保留。

`assembly.json`保存7个原尺寸image元素和6条接续的位置；`原图保真全景.svg`是可编辑排布母版。房间仅按现有世界原点定位，图内浏览缩放不改源图。

2026-11-06后续接缝返修：[六处上下文补绘](../xumen-seam-repaint-v2/README.md)已叠合在本母版中，替换旧矩形接口。新增精修前后切换和E01/E02/E03/E04/E33/E35放大定位。源图不变，但接口边缘会被补绘覆盖；原13图核对已扩展为19图（7原房＋6底层接续＋6补绘层）。这是静态概念接续，用户审美和Godot验收未完成。

当前主展示继续加入[过渡结构V3](../xumen-transition-polish-v3/README.md)：4新局部绘画和2复用轮廓层，修正骨梁根部与上下层封闭结构带，实际SVG引用25幅（不等于25份新素材）。可切本轮、上一版及最初拼接；原房源文件保持不变。

图册支持全区总览、11584px原尺寸查看、逐房聚焦、房名开关和外伤坡版本切换；下方有逐房完整图与设计保留清单。点击房名后在图内横向/纵向滚动，不会换成重新生成的房间。
