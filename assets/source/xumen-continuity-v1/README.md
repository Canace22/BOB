# 须门遗港 · 连续空间设计接入 V1

本批将已交付的连续世界概念用于正式七房的**视觉衔接和地图空间布局**。主入口仍是`game/project.godot → content/whalebelly/main.tscn`。

## 实现范围

- R1-02至R1-07增加同源口腔纵深原画：按区域取不同横向位置，保留原远景和四层遮挡，开放水域以柔边混合。
- E01/E02/E03/E04/E33/E35的两侧共12个独立连接场景：门边水域原画片、鱼群、气泡和小幅视差。每条连接仍指向原目标，不产生新房间。
- 起始房保留已认可的完整原场景，仅增加E01连接动件；共用背景不会以不可见遮挡层冒充接入。
- 过门增加0.24秒实机画面混合；暂停停止进度，结束释放快照纹理。该混合是短暂换场效果，不是关卡背景。
- C地图以鲸头原画承托七房：主路在口腔下层、06在背侧旧伤/鼻道上层、07在须根旁；只显示已发现节点，原能力门信息保留。06的连线从侧面绕行，避免示意成嘴直通鼻。

**仍然是原七房分房加载。** 没有宣称整章全局碰撞无缝，也没有把新全景直接铺成可玩地图。原道路、跳台、Boss、奖励、能力门、检查点和V6数据不变；R1-05章末及06远侧闩仍保留原后章边界。复杂的完整连接走廊、自然门框替换与重排碰撞不在本批完成结论中。

## 原件、母版、运行

- `originals/seams-clean.png`：内置image_gen按三带原画定向清除角色、蟹、奖励及鱼/气泡副本；原参考仍在`world-continuity-v1/images/06-r1-seams.png`。
- `originals/continuous-oral-depth.png`：同工具新绘的无角色/无平台远景；完整提示词和来源保存在`generation.json`。
- `master/`：3份OpenRaster分层母版、SVG道路选区、Alpha蒙版；可在Krita等工具编辑。没有把静态贴图平移登记成新的角色动画。
- `runtime/`：制作导出包含分层候选；**游戏清单只选择11张**：3片Glimpse、1张共用深景、6张安全混合蒙版、1张地图原画。其余是制作中间分层，未计为引擎实际显示。
- `layers.json`/`elements.json`：原图裁片坐标、图层所有权、12处放置坐标、运动方法。刚性道路来自原房间，图层拆分不赋予新碰撞。
- `game/content/whalebelly/environment/continuity/`：12个实际被七房引用的场景；`campaign_continuity.gd`绑定宿主与只读状态。鱼用现有32相位位图与独立路径，气泡沿用预热/边缘渐隐/有界回收；垂须沿用原房固定根部网格或既有帧动画。

## 失败与定向修正

1. 首版把道路像素带入远景，形成假平台，拒用；改为只提取清理图的低对比水域，禁止出现在门脚线附近。
2. 更换大远景会暴露旧World/Reward裁片中的烘焙水色边界；没有扭曲/硬裁整个地形，而是导出各房静态轮廓保护蒙版，使新远景在开放水域显示，在旧裁片边缘退回原画。
3. 移除未使用层后，视差脚本仍访问旧Foreground节点，实际运行报错；已定向删除访问并重跑，不能以该轮55个断言通过冒充零报错。
4. 首版能力门测试继承QA全能力开关，导致误判；关闭QA全解锁后重跑真实门条件。没有修改能力判断迎合测试。
5. 并行QA读档抢用了同一QA存档，旧读档夹具失败；独立顺序检查保存-退出-重启，正式玩家存档未使用。
6. 最初浏览器营地测试只移动固定毫秒，未走到营地；改为只读位置观察下的真实按键行走。完整结果见本地最终报告。

## 接续与复验

1. 先查看`production.json`、`acceptance.md`和`game/progress.md`，复用原件，不重跑生成。
2. 修改母版后运行`build_layers.py`、`node tools/build-xumen-continuity.mjs`、`node tools/godot.mjs sync-art`。导出保护蒙版需要现有七房的原图层。装配工具不改变碰撞或门数据。
3. 工程check/test，GPU `xumen_continuity_qa.gd`，原`campaign_route_test.gd`和`chapter_branches.gd`。QA读档顺序运行，不与其它写QA存档的流程并发。
4. 实机证据只留`game/build/qa/xumen-continuity/`，不提交视频/截图或构建缓存；源码、图源、母版、引用场景、制作方法入库。

新连通几何仍属后续工作。此处成功配方只覆盖共用远景的安全混合、原图动件复用及暂停/资源释放，不能升级为全局无缝地图的成功经验。
