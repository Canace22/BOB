# BOB 首批 2D 素材入库独立验收

检查日期：2026-10-27。只读核对项目规则、原始素材包、导入清单、来源文件及静态图集；本次检查未修改项目，也未生成新美术。

结论：12 项素材可按「静态资源验收通过、尚未接入游戏」入库。其中 11 项是独立透明 PNG 精灵，1 项是不透明单屏背景；11 项精灵另有 4096×1024 静态图集。最终检查未发现阻止这一范围入库的问题。这不是用户美术确认，也不代表两版游戏的动画、碰撞、交互和性能验收完成。

## 五项检查与证据

1. **风格与用途**：对照 `assets/art-style.md`、V2 角色原画、当前 V5.2 参考、素材总览和 R1 确定性拼装图。靛蓝海底、象牙骨壳、克制的琥珀生物灯光、青色披风与绘画质感保持一致。拾潮者的单圆镜、U 形骨鸣器与单灯可辨；生命碎片为三腔，营地一个封闭菌灯，空壳无灯。V5.2 主角与早期 V2 的侧鳍和灯具细节不同，本批明确以用户提供的 V5.2 为来源，不应把两代造型混用为动画帧。
2. **文件与追溯**：12/12 导入 PNG 的尺寸、SHA-256、alpha≥8 包围盒均与清单相符；11 件含透明 alpha，背景完全不透明。每项 `assets/source/<id>/provenance.json` 的 ID、runtime 路径、尺寸、bbox、pivot、世界尺度、SHA、来源与集成状态均与 `assets/catalog.json` 一致；引用图和全部提示词文件存在。膜缘鳐和生命碎片包含修正提示词，废弃版本留在 `references/revision-inputs/`，没有把废稿列为运行素材。
3. **尺度与挂点**：图集 11/11 frame 按清单的指定尺度轴等比归一为 128 px/U，尺寸符合取整公式。11/11 sourceRect 与原图可见 bbox 相符，normalized pivot 与 `(原图 pivot−bbox 起点)/bbox 大小` 一致。飞行鳐为中心点，地面角色、壳体等保留落点约定，锚环使用孔中心。原始 PNG 未被缩放覆盖。拾潮者左腰灯、右手工具具有解剖方向含义，不能以水平镜像替代完整左向资产。
4. **图集裁片与透明边缘**：独立 Chromium Canvas 用相同高质量缩放、相同目标画布坐标重建各 frame，与导出 atlas 比较，11/11 的 alpha 和预乘 RGB 差均为 0。图集只含 11 件精灵，不包含背景；frame 全部位于边界内，无外扩区重叠。修复后 11/11 的 2 px 外扩逐像素等于边缘像素复制，外侧剩余 2 px padding 均透明。深色和浅色底的可视检查没有矩形底色或宽边污染。
5. **状态边界与交付语义**：12 项 `integrationStatus` 均为 `not-integrated`，`qa.scope` 明确只覆盖静态图像与确定性场景合成，并保留用户美术确认尚未进行的说明。图集 `animations` 是空对象，类型是静态 atlas。单张透明 PNG 本身即可作为 sprite；本 atlas 是多个不同静态对象的打包文件，不是行走、攻击或游泳的动画精灵表。

## 本轮发现并闭环的问题

最初的 atlas 外扩阶段沿用了高质量插值：把 1 px 边缘复制成 2 px 时混入相邻像素，11 项边缘 alpha 最大差值为 30–61。主流程已在主体缩放后关闭 `imageSmoothingEnabled` 执行外扩，并在下一个主体前恢复。对重建后的图集复测，11 项边缘复制全部准确，主体像素也保持准确；此问题已关闭。

入库目录在复核期间按项目约定收平了首版 `v001` 层；本报告最终检查基于 `assets/runtime/sprites/<id>/`、`assets/source/<id>/` 和 `assets/runtime/sprites/whalefall-static-atlas/`，清单及来源路径已同步。

## 已注明的使用限制

- 主角、敌人及幼体各为一个姿态；没有移动、战斗、受击、游泳和转向动画，也没有动作事件或逐帧碰撞数据。
- 膜缘鳐的翼膜基本不透明，尚未拆为可单独调整透明度的层；营地的灯与壳体也合在一张图内。
- R1 平台是独立可重叠摆放部件，没有无缝平铺保证；顶边有细微起伏，进入游戏后需按实际轮廓和玩法确定碰撞。鲸须是 R1 装饰中景，不能当站立台面或直接复用于不相符的器官区。
- 图集验证覆盖静态文件和裁片，不覆盖真实引擎采样、mipmap、渲染排序、运行性能或交互手感；背景是单屏图，不是无限循环纹理。
- 来源记录如实保存了用户指定设计与生成方式，没有额外声称已获得未提供的第三方授权证明。
