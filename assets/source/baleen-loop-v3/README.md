## 动作设计与制作

1. 保留 V2 干净的 `paint-00.png` 原绘画，统一缩到336×336，再放入384画布，四边预留24像素。八张关键姿态为这份绘画的派生姿态，不称作八张新手绘。
2. 顶部附着线固定。沿细丝长度逐步增大横向位移，并让相位向下延迟；小簇之间加入平滑的相位差。下段先弯，尖端随后达到更大的摆幅，再延迟回摆。
3. 用周期函数烘焙73张24FPS指导帧，实际调用本地 ComfyUI 0.42.0 / Wan2.2 TI2V 5B。模型用FP8加载，20步、CFG2.0、denoise0.10，任务ID `9532be3c-4e0c-4fcb-ac02-f6edfac3bfe5`。保留工作流与全部原始输出，无新的云端付费请求。
4. 将模型色彩反映射到绘画坐标，拟合两个周期谐波，再以22%权重混入原画的材质残差。透明轮廓沿用指导原画；根部不加入模型变化。此法保留材质细化并限制闪烁，最终不是原视频直接抠帧。
5. 实际模型片为73帧/24FPS=3.041667秒。遵循 `ceil(实际秒数)×12`：输出48帧、12FPS、4秒；将设计的一轮均匀放慢到4秒。相位为 `2π×frame/48`，末帧之后直接接第一帧，不追加重复端点。
6. 通过真实 Krita CLI 将分层ORA转成原生像素块，再组织时间轴；实际由 Krita 导出全部48帧，与PNG逐像素比较。Krita版本5.3.4.1。

制作脚本：[baleen_loop_v3.py](../../../tools/baleen_loop_v3.py)。动作参数和相位关系在 `movement()` 中；循环材质系数保存于 `metadata/periodic-material.npz`。重新生成会覆盖本目录的派生产物，继续手工修绘前应保存独立KRA副本。
