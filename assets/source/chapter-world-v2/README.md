# 须庭与折井 · 章节场景和居民

本批为两章重新制作场景与小角色，替换旧 R1 场景拼接。叙事来源为用户两份初稿；美术遵循[全局风格](../../art-style.md)，与新负壳守卫共用象牙骨壳、青灰生物和暖灯色。

`garden.png` 为鲸须门庭远景，`well.png` 为食道膜褶远景；`kit.png` 提供两块地面、侧台、支撑、门拱、灯、住巢、壳闩。四房路线用这些独立位图等比摆放，碰撞与平台表面单独对齐。背景不承担可走路径，不使用程序纹理补地形。

`scavenger.png` 有 4 个步态与 4 个扑咬阶段；`residents.png` 上排为补巢者 4 个编织姿势，下排为老守护者 4 个支撑姿势。救巢事件将这四姿势与独立住巢位移组合，不能把住巢的程序位移计作新增逐帧角色动作。

[原始提示词](prompts.md) 保留本次内置 ImageGen 调用与修正链，源图片保留不覆盖。首次 kit 有半透明灰底，首次居民图也有底色；最终采用真正透明的修正版。已在实际背景下看透明边缘，未将 alpha=0 的隐藏 RGB 当成可见红黄边。

[extract.py](extract.py) 使用 Pillow 确定性裁片，记录在 [extraction.json](extraction.json)，输出 [运行目录](../../runtime/sprites/chapter-world-v2/)。总计 26 张：2 张背景、8 张场景物件、8 张食腐甲动作和 8 张居民动作。制作得到用户授权用于 BOB；没有外部采购素材，也不声称额外的第三方许可。

实际四房主路、两处高台回声、短桥、两只食腐甲、补巢者和救巢已走通。地面模块交界仍有可见拼接纹理，人物动作过渡有限；用户美术与趣味性评价待试玩。台账状态保持 `needs-review`，接入状态单独记录为 `integrated`。
