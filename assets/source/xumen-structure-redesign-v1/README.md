# 须门遗港 · 柱体重设计 V1

用户否定四张截图中的大帽、长尖底直柱及方块拼装。本批替换七房14处实体障碍的绘画，保留当前19房规则、复杂路线、前中后景、门条件、敌人、能力和V6存档。全部运行表与批前快照相等。

## 新造型与来源

- 骨质区域：层状颌骨裂壁、厚断颌低拱，去掉蘑菇帽与长尖底；较高结构从洞顶整体延续。
- 流膜育窝：红褐厚褶组织代替通用骨柱，保留原软组织背景。
- 来源：outputs 的07_R1-01至13_R1-07原画及用户圈选图。原画是画风／器官参考，圈选图用于记录被否定特征。新素材属于参考重绘，不是原画像素提取。
- 生成原件、候选、完整提示与定向修形记录保留在bone/、soft/；用户输入原样保存在refs/。骨壁经过两次定向修形，先前候选不覆盖。
- 三件已在场景使用：bone-ridge、bone-vault、tissue-ridge。tissue-vault只入库候选，未用于当前场景。四件均未获用户审美签收。

静动判断：承重骨壁、厚组织体本轮为static，确保碰撞边缘稳定；原鱼群、鲸须、垂挂物与水层动态保留，未新增摆动结构或玩法。附生物随主图静止，不宣称独立动作。

## 接入方式

最终尺寸、可见Alpha边界、实心矩形、SHA256与运行路径见[selected-assets.json](selected-assets.json)。四件原件、素材库和game副本字节一致；verify-assets.py只读核对，不编辑图像。实心core最低Alpha分别243、241、240、243，不能称为严格255不透明。

唯一布局生成器仍为game/tools/build_xumen_layout.py，结构装配委托build_xumen_structures.py，数据源为game/content/whalebelly/layout/structure-art-v1.json。按实心core覆盖原碰撞，而非按含透明余量的整画布拟合。采用等比缩放，紧凑横结构允许90度旋转；不用非等比拉伸。高位主体由一张完整图延续到洞顶，避免横向拼接线。少量后置原生裁片用透明淡出连接。

原14处碰撞轮廓、平台和安全落点冻结；素材外缘不是新增可站面。像素覆盖测试按真实父链变换、旋转、offset和region反向取样，不再假设图片只有平移缩放。旧anatomy-fracture、porous-wall、cavity-roof家族已无七房实际渲染引用；原件保留并在台账降为候选。
