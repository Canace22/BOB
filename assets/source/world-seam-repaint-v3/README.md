# 主干新布局连接结构重绘 V3

按用户选择采用主干须门新布局，重新注册22处连接上下文，覆盖18条通道（4条竖井各有两端）。输入来自同一新世界母版，不能复用旧坐标参考。

`inputs/` 保存1536×1024原始地形参考；`candidates/` 保存ImageGen实际输出；`production.json` 保存完整提示词、生成输出位置及输入/候选SHA256。运行副本在 `assets/runtime/sprites/world-seam-repaint-v3/`，registration记录等比世界坐标与对应basis。所有空水区域保留透明，步行脚线必须有实际承重像素。外缘只接回同坐标原像素，重叠重绘按距中心权重选唯一所有者。

返修记录：须门支路一处脚线缺少支撑，经ImageGen局部补绘；该结果又带入大面积近黑不透明底，固定镜头检查发现后再次用ImageGen清底。`attempts/`保留两次问题输出，`repair.json`和`background-repair.json`保留具体指令。脚线与空水背景必须分别检查，不能用其中一项推断另一项通过；像素验证工具已增加大面积不透明黑底审计。

静动判断：岸台和承重根为static，进入母版；舌台中部是实时承重膜，保持Mesh与机关碰撞；鱼群、垂须、水光、气泡、敌人保持原场景实例。本批不新增环境动作。个人通用场景Skill本机未安装，按项目保留执行合同验收。

复跑顺序：同步本批参考及重绘 → `build_terrain_master.gd` → `verify_terrain_master.py` → 维护V2区块清单与哈希 → 再同步、导入 → 实机路线。禁止同步与导出/测试同时访问同一批PNG。脚线采样和运行路线是技术证据，用户整体美术认可另行记录。当前结果见 [game/progress.md](../../../game/progress.md)。
