## 新飞怪：逆流灯鳍

小型敌对幼鳐，灰粉身体、透明青灰脉络双鳍、琥珀喉光，区别于远景鱼群。拟定2HP、横掠伤害1HP（当前5格生命制的最小伤害档）、击退≤24px。同屏最多2只、最多1只攻击。

巡航无伤→收鳍＋喉光预告0.65秒→固定方向横掠0.55秒→展鳍恢复0.75秒→冷却2.8秒。横掠不临时追踪改线。两次短击或一次叉鸣弹处理；不引入新货币。命中后保持现有1.2秒无敌，回收面不叠同次环境扣血为拟定新规则，需工程阶段统一。

## 文件与恢复

- `design.json`：候选落点、能力门、飞怪位置/稳定ID、数值和边界。
- `inputs/`、`input-manifest.json`：现图册七房真实截图、运动参数/布局快照、被拒须筛候选及哈希。保留原件。
- `images/`、`generation.json`、`art-manifest.json`：8张最终概念图、9次真实调用的英文提示词/生成编号/来源。敌人板是4个动作设计姿态，不是动画帧。
- `render_challenge.py`：可编辑叠合蒙版、候选路线注记、图册卡片与版本开关。SVG仅承载真实位图及技术注记。
- `review/`：实际浏览器组合截图、跳跃解析筛查、回归结果。没有Godot实机证据。
- `instruction.md`、`acceptance.md`、`progress.json`：执行/返修指令、验收范围和下一动作。

## 静动元素与未来制作方法

| 类别 | 判断 | 首选方法 | 备选与理由 |
| --- | --- | --- | --- |
| 骨根台、侧墙、回收台 | static | 分层位图＋独立碰撞制作 | 模块裁片；地形不能随水摆动 |
| 奖励、门、锚环 | static/interact | 复用原稳定ID和状态 | 不据绘景中的亮点新增拾取物或门 |
| 灯鳍身体、双鳍、尾端 | proposed motion | 固定鳍根的分段网格/骨骼；尾端延迟；自身动作与路径分离 | Krita关键帧；鳍轮廓变化不能只平移一张图 |
| 原垂须、植物、远景鱼、气泡、局部灯 | inherited motion | 沿用已有成功资产和机制，按新台面补底与清理烘焙 | 新图里的动态形象仅静态设计，不可直接重复叠加运行体 |
| 地形前后边与暗前景 | static/parallax | 分远/中/可玩/前景，保留镜头余量 | 先静态对照，再调视差，避免遮挡落点 |

新敌人的动画选型仅为候选；本轮不将它写入已成功动态配方。下一工程任务需重新对齐台面、跳跃/攻击范围、摄像机和相邻门点，并实际试玩后才能判定难度公平。
