## 风格偏差与应保留的内容

1. **统一薄台替代器官差异**：上轮所有房都用相似浅粉顶唇和薄灰孔底，舌台、骨台、膜台的轮廓差异消失。原画并非没有红色，而是暗红组织表面、灰白承重骨与阴影有层次。仅全局调色不能修复剪影和厚度。
2. **同款柱/支架反复出现**：上轮竖柱像软褶或绳纹短棒，Y形下托像花枝镂空装饰；原画侧墙是厚多孔连续骨壳，有附壁台、粗根、壳群和阴影。低顶平行露出数条相同粉唇，仍有堆叠感。不能继续用重复柱子来“补完整”。
3. **空间被拆成蓝底上的孤岛**：原画有顶/侧/底相互构成的器官包围，平台深处连入骨根或膜层；上轮大量岛状台露出等权细边。保留复杂碰撞，但通过同源、错层、降低背景对比的厚断面恢复归属，不能把旧整张道路画回却让玩家穿空。
4. **生态附着丢失**：原画台沿有藤壶/菌簇、垂挂、少量暖光；上轮平台多是光洁同纹理。应优先复用原来生长在台边的位图片段，密度有轻重；别新增满屏灯或鱼来补空。
5. **前中后景重心改变**：原图黑近景、压暗洞顶/侧壁衬出可走顶沿；上轮大面积等亮蓝色远景主导，画面像架空关卡。主角路径需要保持清晰；近景回收只在不遮脚下、跳跃缺口及关键交互的范围内。

保留复杂地图、原动作/能力、三只普通蟹、一只Boss、奖励和六连接；本次美术意见不要求把新碰撞退回原画中的平路，也不据概念图擅增怪、门或机关。
