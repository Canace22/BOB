## 实际改动

- 七房继续使用原来的深水与器官背景、角色、蟹、母蟹、门和奖励。组织岸与舌台改回带灰白多孔断面、藤壶和垂挂生态的原素材；R1-03活动膜使用原承重膜基态，沿用同一固定端Shader和碰撞形变量。pressed图留作来源对照，没有叠加另一套形变。
- 母蟹战场恢复红组织顶面和厚骨断面，后置的大幅原生台体补足下部体积。喷气孔局部使用灰白硬骨；育窝使用软膜台。旧统一粉台不再承担七房全部地形。
- 实体墙以新不透空骨质核心配准原矩形碰撞，外层自然破口和叉肩连接洞顶、平台根部。外层附着没有新增碰撞；实体核心与非碰撞生态装饰分开记录。
- 顶障使用原生单块厚顶横向接合，移除重复粉色顶唇。洞顶框景使用透明新位图，从场景上边缘自然露出；没有把含烘焙水色的旧矩形裁片直接贴回。底部仅保留不遮当前落点的暗近景。
- 鲸须／垂藤优先采用各房原分件，须筛加宽其标志性的鲸须帘；鱼的身体图集、群体路径、气泡和固定根部动态继续使用原系统与同一可暂停时钟。

`game/tools/build_xumen_layout.py` 仍为唯一七房生成入口。更换贴图时读取冻结的 `content/whalebelly/layout/physics-v1.json`，不再从新图重新采样碰撞。配方几何哈希不匹配会停止生成，必须明确审阅下一次地图变更；本轮没有改recipes的地形、门、奖励或敌人。
