# 右向受击、冲刺与调息

以右向待机原图 `../raw/idle-v01.png` 为主参考，内置 imagegen 独立绘制三条三姿势序列。提示词在 `prompts/`，透明原图在 `raw/`。叉始终由角色右手持握，灯仍挂左髋。

冲刺原稿最后一张跨步过大，改用 `../registered/idle-00.png` 作脚位参考，另绘 `raw/dash-recovery-v02.png`。这张保留站立足迹、前倾身躯和回落披风，接回原待机；原三格源保留以说明前两姿势的来源，最后一格未用于游戏。

`register.py` 按实际透明间隔记录显式裁框，受击/调息按近侧脚踝与脚底注册，空中冲刺按骨盆根注册；不是假设生成结果等格。三格源共用 0.375 倍率，单张恢复姿态按参考画布倍率 384/1254 还原，头盔约 85、灯约 40 源像素。脚踝人工定位误差约 ±8 原图像素（约 0.83 世界像素）；这些测量不等于实际脚滑已验收。

各动作 `platform-options.json` 记录真实 Framecraft 处理参数：原尺寸、Alpha 阈值 8、锐化 0、50 FPS。受击 180 ms、冲刺 220 ms、调息 1100 ms，持帧展开后分别为 9/11/55 个播放单元，每组仍只有三张不同姿势。`export_delivery.py` 从平台实际处理结果选回三张 PNG 和逐帧时长。

工程保存/重开、PNG ZIP 逐字节、384 画布、无空帧和边缘裁切检查已通过。最终工程分别为 `hurt/.../9ddbf23c9fa34074a03a9b8fafb7765a.framecraft`、`dash/.../f57f2b53027f42e5ae0139b8b93dd0a6.framecraft`、`heal/.../f456fb5b4bee4b60bb1531cbf379c767.framecraft`，完整路径在对应 `platform/projects/`。游戏检查见仓库进度；用户美术确认待实际试玩反馈。
