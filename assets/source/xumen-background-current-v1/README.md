# 须门遗港 · 母蟹房清理与背景动态水光

用户要求删除母蟹房截图中的骨柱／横块，同时增加其它背景动态。R1-04的Wall5与Wall6已按现有removed机制停止生成，贴图、洞顶连接和碰撞一起移除。至此七房全部14处新增柱块均已删除；原器官背景、鲸须、前景、平台、门、敌人和19房规则保留。完整rooms.json与批前SHA一致。

## 背景动态与静动判断

| 对象 | 判断／依据 | 方法与取舍 |
| --- | --- | --- |
| 原骨架、器官壁与战斗台 | static；原画与用户保留要求 | 不位移、不扭曲、不参与全屏明暗处理 |
| 远水散射光 | motion；本轮氛围设计 | 在原画偏蓝区域做低强度明暗流动；亮度由源像素得到，不绘制新地形。备选全屏折射会扭曲Boss与平台，未用 |
| 独立柔光束 | motion；已有纯光RGBA | 复用UNDERWATER-SOFT-LIGHT.png，内部轻微流动与低频呼吸；等比缩放，方向与外轮廓位置固定。备选带环境像素的旧BEAM裁片会露接缝，未用 |
| 原鱼群、气泡、悬浮微粒、鲸须 | motion；前批已验证 | 保留摆尾、路径、回收与固定端；本轮回归 |

先只在母蟹房启用并查看GPU样板，通过后扩至七房。每房3个柔光实例，有效Z=-27，位于原中景和战斗层后方；母蟹房光强0.08，其他房0.12，后两束依次减弱。所有实例共用原512×768纹理，无新生成位图或新发光几何；源记录在../xumen-soft-light/，当前库／game副本SHA相等，见source-contract.json。

远水着色保留原像素及Alpha，用偏蓝程度作为柔和权重，最大曝光变化受water_strength=0.065限制；54秒回到原曝光。没有背景骨骼UV扭曲、屏幕采样或全屏滤镜。光束仅自身纹理有小幅内部流动，周期18／27／36秒，相位错开。参数在game/content/whalebelly/layout/atmosphere-v1.json，母版构建为build_xumen_background.py；原唯一关卡生成入口保持。

XumenBackgroundCurrent只登记Far/Depth中的两张绘画材质；LayoutEnvironment用同一可暂停的主线时钟推进它与已有WhalebellySoftUnderwaterLight，后者明确external_clock=true。源Shader默认water_strength=0，其他区域旧用法不自动增加水光。
