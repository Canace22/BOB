# 19房分层生态动态 V1

范围：当前19房，保留平台、碰撞、连接、进度及核心玩法。原有七房鱼泡、肺心双层端足群、血巢战斗玻璃虾与归海幼体继续保留；本批补局部附生菌群、边缝逸泡、营养微粒以及后区稀疏群游。

观察依据：各房原画及当前全景，见production-plan.json。骨架、器官主体和地形记static；独立生态记motion；未清底的原画烘焙鱼影记static，不能当作新增动画。所有新运动参数均为proposed初值，由实机样板后调节，不是从静态原画测得的速度。

源：已有入库2D位图和32帧鱼图集；不新建付费视频任务。实现使用Godot的独立房间时钟、预热固定池、透明边界回收与固定根菌群Shader。设计图由内置image_gen逐房生成，完整提示词在prompts/，原始输出另保留于工具默认目录；R2-03复用此前已生成方案。

设计图是概念方案，与实际碰撞不构成逐像素合同；图中细节如摄食、额外触手、密集群流不自动成为新玩法或已完成动画。运行实现与验证状态见production-plan.json及工程progress。用户审美仍待反馈。

## 运行资源与运动合同

- 暖色附生菌复用`art/world-kit/habitat-fungus-bed.png`，冷色和肺心附生菌复用`r2-pearl-stalks-v4.png`；已有来源/许可见全局manifest/catalog。按实机曲面插值定位，等比缩放，底部25%固定，只对末梢做3.5源像素的UV微摆和7%以内局部RGB变化；11秒摆动/22秒微光，安静房14/28秒。Alpha不作全局呼吸，绝不移动鲸体结构。
- 小鱼复用三种既有32帧图集，由ChapterFishGroup独立摆尾和开放迁移；育床复用端足位图及既有游动Shader。固定池、边缘透明回收和错相预热；新小鱼每房6–14只，端足12只。原画烘焙鱼影仍为静态，未冒充新增帧动作。
- 气泡复用reference_environment/bubble.png，边缝窄域、每束3或5只、3–7px、9或13px/s基速，实际Z=2低于主角。微粒复用fx-particle-soft.png，局部场每房5–16只、3–7px。现有七房氛围不重复接管。
- 每房一个新增生态时钟，子组件外部驱动，不存储时间、不写能力/存档/敌人；暂停、禁用、零速和邻房休眠保持当前姿态。查询进度的原有端足淡出、Boss、归海幼体保持原合同。
- 所有参数为本批建议初值；允许后续按审美调密度/路线，不自动扩写新玩法。

## 证据与限制

本地`game/build/qa/ecology-19-v1/`包含19房普通/全景/4秒差分截图、report.json、输入通路日志、资源审计和育床32秒渲染演示。演示为12fps离线采样实际GPU画布，只推进新增生态，演员/镜头和其余效果冻结，不是自然试玩或性能测试。600秒seek仅验证池数量和有限坐标，不当作十分钟人工观看；未宣称全场景无缝循环或长期稳定帧率。

设计图原件19张（18新生成，R2-03复用前稿），尺寸、SHA、参考及提示词索引见designs.json；全部1536×1024。原始参考与设计板不加入游戏资源清单。本批无需新运行贴图和全量sync-art。

内置图像工具未返回费用明细，费用记unknown；未调用外部Canvas付费视频生成。原始工具输出保留，designs.json中的original_output与项目副本SHA一致。

技术结果见production-plan.json；AI已看逐房设计与19房实机拼板、育床0/10/20/31.9秒关键帧，浏览器筛选和放大通过。短时关键帧复核不等于逐帧人工审核或用户审美签收。图中部分细节文字及生态扩想由生成模型绘制，实际房间名称、实现范围以图集卡片为准。
