# 须门遗港 · 深海氛围 V1

用户要求补充鱼群、气泡等，营造深海氛围。范围为当前须门七房；19房规则、平台、门、奖励、碰撞与已删除柱体均保留。本批完整运行表与批前字节一致。

## 元素识别与选型

| 元素 | 判断与来源 | 方法／取舍 | 空间层 |
| --- | --- | --- | --- |
| 骨架、器官壁、平台 | static；原画与当前场景 | 保留既有位图与碰撞，不随水流变形 | 原三层与可玩层 |
| 银鳍、青背、微光鳍鱼 | motion；已认可的三种32相位游鱼图集 | 复用摆尾＋独立群体路径；没有重绘鱼或把静态横移称为摆尾。备选粒子鱼不便保持动作身份，未用 | 远水小鱼＋中景银鳍／青背＋稀疏微光鱼 |
| 气泡 | motion；已有12px透明气泡 | 固定池、开场预热、上升、边缘淡入淡出与回收；备选GPU粒子不如当前固定池便于精确重载检查 | 中景两列上升流，近景疏泡 |
| 悬浮微粒 | motion；库中已接受的软光粒子PNG | 缓慢向右下漂移、小幅摆动、边界淡出；共享时钟，不增加发光块或满屏雾 | 中景，人物后方 |
| 鲸须／垂挂根 | motion；原固定端位图 | 原有动作与附着保持，不重新生成 | 原中景 |

三种鱼源见../fish-schools-v01/，本批直接复用清单中的Framecraft运行副本。气泡与微粒同样来自现有库；[source-contract.json](source-contract.json)记录5张图的实际来源、尺寸、SHA与副本一致性。没有生成或编辑游戏位图，无新增图集；颜色和比例由节点参数表达。

## 参数、层次与接入

新配方在game/content/whalebelly/layout/atmosphere-v1.json；唯一关卡生成入口仍为build_xumen_layout.py，表现构建委托build_xumen_ambience.py。先只启用外伤坡做样板，确认真实像素、暂停、回收与重载后再启用七房。

普通房为47条鱼（18远景、14银鳍、10青背、5微光）、31个气泡、42粒微粒；仅载入当前房间，固定上限120个装饰精灵。母蟹房降为28鱼／18泡／25微粒，共71个。图集是3种，鱼群节点是4个，不能把实例数当资产数。各房由尺寸、相位和seed形成不同分布；迁移边界隐去后回收，非画面内突然跳回。

远鱼继承Far/Depth视差，有效Z=-28；中景鱼Z=-13、泡流Z=-14、微粒Z=-12。近泡Z=2，人物Z=3，原前景仍Z=10。近泡有真实靠前层次，但仍在玩家后面，保住面罩、脚底与战斗轮廓。原景深、骨架和器官图层保持，不叠加旧平路或已删除柱体。

ChapterFishGroup新增可选尺寸、颜色、周期、第三鱼种、群形与迁移参数；默认值保留旧区域行为。KitDriftField新增external_clock，默认false，本批true；由LayoutEnvironment单独推进，避免自身_process与主时钟重复累加。气泡本身已有同样的外部时钟选项。动作帧、路径、气泡和微粒暂停时保持姿态，恢复继续，不重排实例。

## 返修与验证

样板发现互补的小数x/y序列让放大的鱼排成斜线，改成固定的非相关云状队形，不逐帧随机抖动。全区检查发现母蟹大房间的微粒在全景镜头缩得不可见，按实际房宽补偿尺寸；保持低密度，没有放宽像素可见检查。

本轮check零错误（原有5条长脚本警告），134单测通过；环境专项105项、原GPU环境暂停35项、三层／遮挡／边界镜头84项、原Input连续主线50项通过。最终日志无ERROR或SCRIPT ERROR。早期样板的场景小数序列化与QA数组类型问题已修正，阶段失败日志保留，最终结果独立记录。

专项实际隐藏鱼群、气泡和微粒，与同一暂停帧做GPU差分，确认各自贡献画面；检查实例上限、600秒加速回收、换边透明度、统一时钟、暂停恢复、同一时刻重复更新、整房重载和人物绘制层。加速seek不冒称600秒人工观看。已查看样板、母蟹全景、须筛游玩镜头，后续静帧和连续帧观察写入validation.json；技术通过不等于用户审美认可。
