## 本批实际修正

原画三层已经接入，但上一批仍有悬浮薄台与重复骨柱感。这次以已有V5.2参考素材补足六房24处可玩台地下部的骨／组织体积，密集路线与单向踏台保留通行空间；食管软膜房不加硬骨台体。膜、主角、敌人、门和奖励没有改规则。

复用位图等比放置，以原透明轮廓和裁片退让连接；不使用纯色块画地形，也不纵向拉伸横图。新增部分只在原脚面下方显现，隐藏可能形成第二条假踏面的顶亮边；不能把非碰撞装饰画到走跳、下落或牵引路径中。旧平台下方的重复通用骨柱换出，实体墙的现有连接结构保留。整根悬根放大连接实体墙的试验抢占了须帘构图，已撤回，没有把该试验当成通过的美术。

远景保持原位图和色相，做小幅水下景深衰减，降低远骨细节同可玩顶边争夺注意力。原前景、中景、背景、鲸须／垂藤、鱼群和气泡仍沿用上一批配准与同一暂停时钟。

本批没有生成新位图。原Middle／Far／Foreground为既有原图分层；舌台、骨台等独立件是库内按V5.2原画制作的既有参考重绘，不能统称从原画逐像素抠出。它们的原始来源和状态不因本次复用自动升级为用户认可。
