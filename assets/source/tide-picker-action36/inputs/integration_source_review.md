# 36项视频接入前抽帧复核

已查看36条原始片每0.5秒的10帧，共360张。实际尺寸与帧率见JSON；所有视频为24fps、121帧（约5.0417秒）。33与35为1470×630，其余为1280×720或1920×1080。

选段、事件时刻和初始站姿锚点是抽帧估计，事件精度约±0.25秒，锚点约±画幅2%，未作逐帧抠像或循环播放验收，不能直接当作正式动画元数据。

复杂素材优先返修：wall_slide墙与手脚重叠；wall_jump右墙向左弹离后又朝右；anchor烘焙固定吊环/绳；slit紫膜遮身体且叉拖后；swim水纹覆盖胸部；tram手与读卡器重叠；interact和pogo含测试目标。普通色键不能恢复被遮画素。

短冲应排除3秒后的坐滑刹停。普通横击主要在2.35秒以后。上涌与深潮啸身体可考虑复用，但特效必须独立。整段5秒不可当游戏动作时长。

本复核没有改动工程、运行素材或源视频；接触表位于integration_review，逐项建议在integration_source_review.json。
