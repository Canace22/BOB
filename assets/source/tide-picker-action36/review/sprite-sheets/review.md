# 补制关键姿势表处理记录

2026-11-04。这批是内置图像模型补制的关键姿势表，**不是从原动作视频提取的帧**。提示词及原始生成来源由主任务归档。脚本为 `../../build_sprite_sheets.py`；不改运行时 animations.json，由主任务核对后接入。

## run-v1：拒收完整跑步循环

原图1774×887、4×2格、RGBA。最大连通体清理可以除掉叉口等处独立红色碎点，身体、装备较旧模糊视频更清晰。统一scale 0.4、每格root (242,416)，未逐帧高度归一。第4/8相位的双脚腾空保留。

但上排与下排近/远腿关系重复，不能证明左右腿交替的完整跑步周期，循环呈现同一支撑腿重复风险。生成了8相位预览GIF/MP4与深浅底接触表，不作为正式跑步验收通过。脚本对该版本拒绝runtime导出。等待定向修订图，而不是用插帧掩盖步态错误。

## run-v2：姿态改进，支撑腿关系仍未通过

已查看第二版原图，按相同固定scale/root重新提取注册。第7格出现抬膝、第8格腾空跨幅增大，确有源姿态修改；但第5/6格仍为亮色近腿向前支撑、暗色远腿向后摆，与第1/2格相同。第8格也保持近腿向前，不能据此认定两个相反半周期已经成立。版本v2拒绝runtime导出。历史证据分别保留在 `run-v1-*`、`run-v2-*`。

## run-v3：可进入主场景的8姿态候选

第三版修订后，第1格浅色近腿前伸着地，第5格深色远腿前伸着地，两个半周期的支撑关系可区分。已逐格查看原图与注册后的深浅底表，身体/装备清楚，独立alpha红点被清理，未对整条红绳作颜色删除。按固定scale 0.4与root (242,416)导出8帧本体图集；源图补制身份和SHA256进入来源清单。

接触相位的脚底位于注册画布y256–258（0–2资产像素差），第4/8相位则位于y238/y244，是源姿态的腾空，不能按每帧脚底重新贴地。逐相位检查3→4→5及8→1，上身未出现整图尺度突变；腿部跨相位位移较大，属于夸张离散姿态，不声明解剖学精确或插值光滑。默认12fps只是主场景样板候选。

`run-registered.jpg`、`run-preview.gif`、`run-preview.mp4` 当前对应v3。子任务尝试使用内置浏览器播放GIF，但IAB不可用且浏览器清单为空，故**未获得UI连续播放验收**。源姿态/透明资产可进入父任务主场景样板，真实循环观感、与物理移动速度匹配、左右镜像仍由主场景操作验证。本次已将v3写入runtime/run-body.png，但未改animations.json。

## parry-v1：源姿态与透明边缘通过，游戏行为待验收

原图1536×1024、3×2格。虽然文件有alpha通道，图中仍有暗色渐变背景，不能直接作为透明角色资源。

六格分别经过BiRefNet General Lite CPU分割，缓存复用同一模型/源像素。先保留最大角色连通体，再用最近被拒绝背景像素估计局部背景，处理软边反混；没有用全局红/金色阈值删除装备。全局背景色反混会给渐变底的头盔边缘带来白边；局部反混在深浅底对照上更干净。试验性最近前景颜色扩张会破坏红绳细节，未采用。

统一scale 160/435、每格root (250,460)。所有格共用一个脚底基准，没有逐格高度归一。以预乘alpha方式缩放，避免透明底RGB污染缩小后的轮廓。输出六帧，16fps候选播放率；顺序为防御、抬叉、向前推叉、收叉、恢复、警戒。短叉、红绳、披风、腰灯、脚部均在深浅底全帧表中逐项复核，未保留源背景，也没有旧视频的珍珠道具。

`parry-body.png`与 `sprite-sheet-actions.json` 只表示这次源姿态和透明资产处理完成。实际技能时长、格挡窗口、命中、受击中断、左向镜像及主场景手感必须由共享角色实测；不要把候选16fps直接当技能有效窗口。证据 `parry-registered.jpg`、`parry-preview.gif`、`parry-preview.mp4`，预览不等于实机录屏。

## 可复跑

使用既有隔离Python依赖（action36-deps + animation-repair-packages）。

```powershell
python build_sprite_sheets.py --keys parry --write-runtime
python build_sprite_sheets.py --keys run --write-runtime
```

运行时仅覆写所指定动作的body图集；不触碰用户存档或游戏代码，不写animations.json。省略 `--write-runtime` 则只生成预览和来源元数据。
