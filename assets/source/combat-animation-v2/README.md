# 战斗动作与起手表现 V2

人形敌人的慢蓄势、快速释放与按真实命中点取帧见[蓄势与爆发节奏](humanoid-timing.md)。这是现有帧的时间编排，保持动作比例及原技能执行时序。

动作切换时的显示比例修正见[统一动作标尺](scale-registration.md)，本轮只校准原图的显示单位，不增加动作帧；封梁卫为最初优先复核对象；老守护者蓄力切入缩小的后续复核改用完整中性身体站高，保留旧帽壳估值作排除证据。

最新补查见[敌人动作返修](followup/README.md)：主要攻击之外补齐捕食者回挂、老守护者独立回稳，并重绘大甲压砸与负壳顶壳的弱准备动作。下文53项/33套为第一批次的历史检查点，不代表所有连续状态已补齐。

本批依据当前主角与八类章节敌人的既有身份补绘，重点是可读的准备动作、连续释放及回收。原件由内置 `image_gen` 生成或定向修复；没有调用外部生成API。模型名称未由工具暴露。生成式返修可能重绘细节，不声称像素不变；确定性导出相对选定原件的像素一致性另行检查。

## 时序与身份合同

普通近战默认从50ms改为100ms，主线场景、CampaignProfile与白盒同值，总时长不变。其余释放、命中、伤害、冷却、位移、红招、黄色弱点、格挡和后跳窗口仍读原逻辑；组合容错60ms、预输入200ms保持。起手FX与新图只读阶段，不发技能、不完成任务、不写存档。

准备/释放/回收显式分段。已有长蓄阶段、小循环、坠潮实际落地与独立FX分别读取，不能为了多放图片提前出现攻击弧或落地冲击。主角整身镜像沿用既有约定，不声称角色自身左右装备制作了两套。角色新图仍需检查两手两脚、握叉手、腰灯、红绳、重心与完整武器路径。

泵庭每帧压囊有独立局部锚点，实际青囊必须在后侧。水龙卷首版第三行三帧把囊转到身前，已保留失败并定向返修，不能通过错误高亮锚点掩盖。普通身体的关节、爪、武器、披风是真实绘图，不把缩放、形变、静图交叉淡化或重复槽位登记为新动作帧。
