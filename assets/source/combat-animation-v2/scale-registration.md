# 动作显示比例校准

本轮修复不同技能切换时敌人忽大忽小，优先依据用户指出的封梁卫。没有补绘或改变PNG，没有逐帧按Alpha包围盒自动缩放，也没有修改碰撞、伤害、位移或技能时钟。

## 问题与统一单位

原导出把每套动作首帧整体高度写成reference_height，旧待机却有自己的作者标尺。首帧武器位置、姿态及绘图像素密度不同，导致同一角色的动作使用不同身体单位。封梁卫初步壳盔模板比较显示，五套技能比旧待机小约4%–9%；完整中性站姿比较还揭示了旧待机reference_height并不等于实际实体高度的问题。

`scale-registration.json`逐PNG保留原作者标尺、原图与待机图SHA、选定参考矩形、来源帧及人工复核说明。八类敌人35个在用身体图集分别登记：甲壳类对比甲壳，捕食者对比伞膜，鳗对比头颈，执卫/守护者对比头壳。封梁卫五套动作的第一帧都经复核为武器不超出头顶或脚底的相同中性站姿，最终用壳盔顶到着地脚的垂直距离作标尺，并以壳盔模板作形体复核；不把出招过程中的蹲下、抬刃或倾身当身高。

封梁卫旧待机Alpha>32实体高度221像素，作者标尺200；102世界像素的profile得到112.71像素实体站高。五套图集的中性站高据此对齐，整张图集只使用一个固定比例，准备、挥击、收招及格挡都沿用该比例。动作内部的真实重心/四肢变化保留。

## 排除一次错误测量

不旋转的壳盔模板最初把旧受击姿势测成0.825倍。逐像素看标尺网格后发现它混入转头、帽檐变扁与俯身的透视差异，不能据此把整个人放大21%。该探针保存于excluded_legacy_probes，最终没有旧受击缩放修正，运行visual/adapter的受击比例保持原样。旧走路四姿势壳盔匹配差异约±1.5%，也不改。模板匹配分数或框不能单独当成身体缩放的证据。

## 生产与复跑

- `measure_scale.py`只输出离线候选测量及标框图到game/build/qa，不写认可数据。匹配旋转、攻击武器或局部纹理的候选必须目视排除，不能自动逐帧采用。
- `register.py`在合并normal/special/followup后，按PNG路径应用经复核的固定reference_height；原标尺保留为source_reference_height。当前PNG与待机基准SHA不符即中止，要求重新复核，不悄悄沿用旧校准。
- 第一章食腐甲基于另一套旧待机来源，chapter_height有独立配准；登记chapter_reference_height后由原入口换算，保持原先的世界尺寸，不把试验场的标尺套到首章。
- 运行逻辑仍是target_height/reference_height，只读数据；没有增加帧循环内的图像回读、模板检测、包围盒测量或动态缩放。

## 验证

`test_enemy_animation_scale.gd`用冻结的待机单位与原图SHA复现问题；修正前解剖标尺用例失败，修正后35张图集均对齐，另检查封梁卫整套动作比例恒定、物理根与碰撞不变、旧受击不会因透视误判被缩放。原生GPU阶段截图、实际I/J/S+L/绕背交战、第一章独立入口与完整回归分别记录在本轮game/progress.md，不能互相替代。静态标框与站姿对照不证明每个源动作的所有绘图均无残余形变，最终连续观感仍需用户体验。


## 老守护者蓄力切入缩小：中性身体标尺复核

用户实机指出蓄力时缩小。与真实旧待机22同脚线对拍，确认部分动作在第0张中性站姿就缩小，不能用后续蹲姿解释。先前仅壳盔模板的固定校准不够：相似的帽壳局部不代表整个身体单位一致。六条旧帽壳估值保存在各记录的`superseded_hood_calibration`，不能把之前“35张均对齐”的技术合同当作整体观感已通过。

重新以中性站姿壳顶到脚底配准：旧待机壳顶y=7、脚底y=199，跨度192，原作者reference_height=190。横扫、前刺、反压、撑跃、复制的入口中性帧跨度分别184、192、200、179、202；回稳用末帧203。逐张排除更高的叉尖：撑跃顶42而不是图像最高38，回稳顶44而不是最高36。`reference_body_landmark/source_body_landmark`记录此选择。每个PNG固定reference_height=190*来源中性跨度/192，其全部准备、释放、回收帧共享；不用蓄力蹲姿反向强制站高。

源PNG、整体解剖比例、接地pivot、真实AI时间与判定保持；上轮撑跃第11张pivot.y=241仍生效。回归在改数据前复现4个中性动作偏差，修正后五个入口与旧待机跨度差<1%，35张SHA与固定单位合同、封梁卫固定比例/物理根和旧受击保护继续通过。实际GPU与完整回归见game/progress.md本轮记录。站高复核不证明各张源绘画的所有局部都无变化；继续保留蹲姿/转身原绘图，不用实时包围盒缩放掩盖绘画问题。
