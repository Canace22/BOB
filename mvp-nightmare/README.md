# 鲸腹遗城 · 深处的来客

一个用于体验《小小梦魇》式探索、环境解谜与紧张节奏的单人短篇 MVP。三个连续关卡从安静探索推进到潜行和逃离，采用 3D 场景与侧向透视镜头的 2.5D 玩法。新版本独立放在 `mvp-nightmare/`，原有 `mvp/` 保留。

在项目根目录执行以下命令，然后用桌面浏览器打开 [http://127.0.0.1:4174](http://127.0.0.1:4174)，点击「走进深处」。需要 Node.js、npm 和支持 WebGL 的浏览器，当前使用键盘操作，尚无移动端触控。

```sh
cd mvp-nightmare
npm install
npm start
```

首次安装需要联网下载 Three.js；运行时从本地加载依赖，不使用 CDN。不要直接双击 `index.html`。PowerShell 中端口被占用时，可用 `$env:PORT=4180; npm start`，并打开对应端口。

本版保留源码与本地运行能力，但已从当前 GitHub Pages 发布包移除。公开试玩与发布方式见根目录 [README](../README.md#发布到-github-pages)，当前站点只发布 V2 2D 版本。

## 怎么玩

| 按键 | 操作 |
| --- | --- |
| A / D 或 ← / → | 左右移动 |
| W / S 或 ↑ / ↓ | 走向场景深处 / 回到前侧 |
| 空格 | 跳跃 |
| Shift | 按住奔跑，跳得更远 |
| E | 读取刻痕、拾取物品、操作机关、进入出口 |
| 按住 E + A / D | 靠近木箱后搬动，松开 E 放手 |
| C 或 Ctrl | 按住蹲下；在骨龛深处蹲下可以藏身 |
| H | 查看当前关卡提示，可能透露解法 |
| R | 从最近的检查点重试；死亡时也可按 Enter |
| Esc | 暂停 / 继续 |
| F | 切换全屏 |

靠近可交互位置时，画面会出现提示。物品也有纵深位置，左右对齐后可能还需要用 W / S 靠近。右上角可以开关声音，切换窗口或离开页面会自动暂停。

## 三关的节奏

| 关卡 | 主要体验 |
| --- | --- |
| 失声门庭 | 放慢脚步读刻痕，搬动木箱打开通路，再穿过低矮骨缝，熟悉探索与交互。 |
| 听骨廊 | 观察看守苏醒的节奏，在骨龛中躲藏，寻找电芯并送到升降门。 |
| 最后一次心跳 | 从刻痕中理解机关顺序，唤醒潮泵后奔跑、跳跃，逃离回潮。 |

每关有一段可选回声，共三段；不收集也能通关。抵达出口后按 E 前进，最后显示回声数量、本次重试次数和游玩时间。

<details>
<summary>卡住时展开：完整解谜路线</summary>

1. **失声门庭**：靠近木箱，按住 E + D 将它放到发光秤盘上，松开 E。跳过箱子后向右走，按住 C 穿过骨缝。后侧的微光处用 W 靠近、E 收集回声，再到最右侧按 E 进入下一关。
2. **听骨廊**：等看守闭眼再走，在它醒来前进入骨龛，用 W 走向深处并按住 C，直到状态显示「已藏好」。中间骨龛里按 E 取电芯，利用后续骨龛继续穿行；最右侧电芯槽按 E 接通升降门，再到出口按 E。只在通道上蹲下还不算藏好。
3. **最后一次心跳**：依次操作第二枚、第一枚、第三枚阀门。输错会清空当前顺序，可重新尝试。接通后按住 Shift 向右跑，接近断口边缘时按空格，途中跳过低矮障碍；抵达最右侧升降井后按 E 完成短篇。

</details>

## 重试和存档

进入关卡、通过第一关机关、拿到电芯、启动潮泵时会记录检查点。死亡或按 R 后回到最近的检查点；已完成的对应关键步骤与已收集回声会保留。启动潮泵后重试会直接开始逃离，无需重解阀门。

存档保存在当前浏览器的本地存储，使用独立键 `bob-nightmare-25d-v1`。标题页的「继续旅程」恢复检查点和回声；「走进深处」开始新一轮并覆盖这份存档。更换浏览器、地址或端口后可能看不到原存档。原版 MVP 的存档不受影响。

## 实现范围

场景与角色由 Three.js 的 3D 几何体构成，透视镜头固定朝向、随角色横向移动。关卡限制了活动范围，W / S 的有限纵深直接用于物品交互和藏身；这是侧向推进的 2.5D 原型，没有自由旋转镜头或完整 3D 漫游。

关卡数据描述机关、平台、断口与物品，游戏逻辑负责移动、碰撞和机关状态，渲染层据此更新画面。当前用简化几何、程序灯光和合成音效验证玩法、节奏与空间感，角色动画和环境美术仍是原型水平。

## 检查与验收

`npm run check` 检查脚本语法。自动游玩使用 Playwright，需要先保持 `npm start` 运行，再在另一个终端进入 `mvp-nightmare/` 执行：

```sh
npm install --no-save playwright
npx playwright install chromium
npm test
```

使用其他端口时，运行 `BASE_URL=http://127.0.0.1:4175 npm test`。以下是手动验收重点；这份清单本身不代表测试已通过。

1. 开始游戏后能左右移动、跳跃和前后移动；W / S 应改变角色纵深，靠近后侧物品才出现交互提示。
2. 第一关木箱压住秤盘后开门；松手可跳过木箱，低矮骨缝需要蹲下通过。
3. 第二关暴露时警戒会上升；进入骨龛深处并蹲下后显示「已藏好」，可等待看守闭眼再行动。
4. 第三关错误顺序重置阀门，正确顺序启动追逐；能奔跑跨过两个断口，抵达出口完成短篇。
5. 取得电芯或启动潮泵后死亡、重试、刷新再继续，都应恢复相应检查点；暂停时场景停止推进。
